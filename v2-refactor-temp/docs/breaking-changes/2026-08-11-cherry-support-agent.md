## What changed

Cherry Studio now presets a dedicated Cherry Support Agent for product help, setup guidance, troubleshooting, FAQs, and feedback. Existing users inherit Cherry Assistant's current model when Cherry Support is first created; new users configure both official Agents during onboarding.

## Why this matters to the user

The About > Feedback > Use Agent entry now opens a fresh Cherry Support conversation instead of Cherry Assistant. Cherry Assistant remains the general-purpose built-in Agent and can be configured independently afterward.

## What the user should do

Nothing - the new Agent and feedback entry are configured automatically.

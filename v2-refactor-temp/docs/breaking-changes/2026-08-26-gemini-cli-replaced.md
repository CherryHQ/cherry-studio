## What changed

Code Mate no longer offers Gemini CLI to new users and now offers Antigravity
CLI instead. Existing Gemini CLI installations remain visible and usable.

## Why this matters to the user

Users without Gemini CLI installed will see Antigravity CLI in the Code Mate
tool list. Existing Gemini CLI users will see a discontinuation notice on its
detail page but can still launch, upgrade, or uninstall it.

## What the user should do

Use Antigravity CLI for new setups. Existing Gemini CLI users may continue
using their installation or migrate when convenient.

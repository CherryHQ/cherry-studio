## What changed

The English and Chinese privacy policies now describe the built-in model relay,
upstream model providers, third-party service billing, and related liability
boundaries. Existing users with anonymous data collection enabled must
acknowledge the August 20, 2026 policy before analytics can resume.

## Why this matters to the user

Affected users will see the existing non-dismissible privacy policy update gate.
Their current anonymous data collection choice is preserved.

## What the user should do

Review the updated policy and either acknowledge it or disable anonymous data
collection to continue.

## Notes for release manager

The latest acknowledged policy version changes from `20260531` to `20260820`.

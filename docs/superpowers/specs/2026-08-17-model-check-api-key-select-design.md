# 模型检测 API 密钥下拉对齐设计

## 目标

- “检测所有模型”视图选择单个 API 密钥时，与单模型检测视图使用相同的下拉样式和内容。
- “选择要使用的 API 密钥”在所有语言中不带末尾冒号。
- 保留现有单模型、全模型检测参数和结果逻辑。

## 设计

在 `ModelCheckDialog.tsx` 内保留一个 API 密钥下拉组件，由单模型视图和全模型视图共同使用。组件只接收已启用的密钥条目，选项和当前值均只显示脱敏后的 API 密钥；触发器、下拉选项、字体、尺寸、搜索阈值和空结果文案完全一致。

全模型视图仍保留“单个/所有”分段选择。选择“单个”时渲染共享下拉；选择“所有”时不渲染下拉。密钥选择状态及 `startHealthCheck` 参数保持不变。

## 文案

更新 `settings.models.check.select_api_key` 的各语言值，仅移除末尾冒号及其前置空格，不改变其余措辞。

## 测试与验证

不采用 TDD。删除只约束内部实现、不能保护检测业务契约的测试：模型列表变化时保存表单、超过五个密钥显示搜索框、按模型可见名称搜索。保留密钥选择、检测参数、禁用状态、错误详情及跳过规则等测试。

实现后运行剩余的聚焦组件测试、Web 类型检查、i18n 检查及目标文件 lint/format，并在已跟踪的 Electron 实例中检查两处下拉。

## 范围外

- 不改变检测并发、超时、跳过或结果逻辑。
- 不修改其他设置页的 API 密钥控件。
- 不运行全量测试。

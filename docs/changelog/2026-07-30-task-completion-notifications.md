## What changed

Successful Agent tasks and assistant responses now show a completion card when another conversation is active. When Cherry Studio is in the background, the existing notification preference controls whether a system notification is sent.

## Why this matters to the user

Users can tell when work in another session finishes without repeatedly switching between sessions or bringing Cherry Studio to the foreground.

## What the user should do

Nothing — in-app completion cards are automatic. Enable Conversation Completion Notifications under Notification settings to receive background system notifications.

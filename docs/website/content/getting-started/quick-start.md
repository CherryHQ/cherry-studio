# 快速开始

按照下面的步骤，几分钟内完成模型配置并发送第一条消息。

{% stepper %}

{% step %}

<a id="1-an-zhuang-cherry-studio"></a>
<a id="1-安装-cherry-studio"></a>

## 安装 Cherry Studio

从[官方下载页](https://cherryai.com.cn/download)获取与你的系统和芯片匹配的安装包。遇到系统权限或安装问题时，查看[下载与安装](../cherry-studio/installation/README.md)。

{% endstep %}

{% step %}

<a id="2-xuan-ze-mo-xing-fu-wu"></a>
<a id="2-选择模型服务"></a>

## 选择模型服务

打开【设置】→【模型服务】。如果还没有 API Key，可以先查看[模型服务快速参考](../pre-basic/providers/quick-reference.md)，根据访问地区、模型能力和隐私需求选择服务商。

{% endstep %}

{% step %}

<a id="3-tian-jia-bing-qi-yong-mo-xing"></a>
<a id="3-添加并启用模型"></a>

## 添加并启用模型

进入服务商配置页，填写 API Key，点击【获取模型列表】，添加一个对话模型并打开右上角的启用开关。详细说明见[模型服务设置](../pre-basic/settings/providers.md)。

{% endstep %}

{% step %}

<a id="4-fa-song-di-yi-tiao-xiao-xi"></a>
<a id="4-发送第一条消息"></a>

## 发送第一条消息

返回【对话】，新建助手或打开默认助手，在输入框上方选择刚添加的模型，然后发送消息。

{% hint style="success" %}
能够正常收到回复即表示基础配置完成。
{% endhint %}

{% endstep %}
{% endstepper %}

## 接下来可以做什么

* 浏览[功能总览](../cherrystudio/preview/README.md)，了解对话、绘画、翻译和笔记等功能。
* 使用[工作 / 智能体](../advanced-basic/agent.md)处理文件和多步骤任务。
* 创建[知识库](../knowledge-base/knowledge-base.md)，让助手基于自己的资料回答问题。

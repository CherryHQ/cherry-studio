# Contribute to Mobile Documentation

Find mobile documentation and feedback entry points here. For usage guides, start at the [mobile home](README.md). For connection, model, or tool problems, follow [troubleshooting](troubleshooting.md) first.

## Improve Guides and Translations

If steps, screenshots, or translations differ from the current app, follow [Contribute to Documentation](../contribution/docs.md) to update mobile pages in the website repository. Include the operating system, app version, interface language, and affected page URL so reviewers can check the scope.

Chinese and English guides use screenshots in their corresponding interface language. Before submitting screenshots or logs, hide keys, accounts, and private conversations. Do not include real health or location records.

The current feature baseline is **0.3.0**. Use **WebP** for new images and animations; animated WebP can explain a sequence. Chinese and English assets should cover the same feature. Prefer animated WebP recorded from the real App so readers see the actual entry points and tap order; normalize the status bar and blur keys, accounts, and private content. Record the capture version and keep image/full-size links in the matching language directory.

## Report a Reproducible Problem

Use [Effective Questioning Methods](../question-contact/ask.md) to organize the steps, expected result, actual result, and checks already attempted. Report documentation problems in the [website repository Issues](https://github.com/CherryHQ/cherry-studio-website/issues). For app usage problems, follow the feedback guidance in [mobile troubleshooting](troubleshooting.md).

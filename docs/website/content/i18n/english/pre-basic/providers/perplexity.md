# Perplexity

The **Sonar** series from Perplexity focuses on **search-augmented conversation** — responses incorporate real-time web retrieval, making it suitable for scenarios requiring the latest information.

## Get an API Key

* Open Perplexity's [API settings page](https://www.perplexity.ai/settings/api) (registration/login required)
* Generate and copy an API Key

## Configure in Cherry Studio

1. Open Cherry Studio's [Model Service Settings](../settings/providers.md) and find **Perplexity** in the built-in list
2. Enter the API Key you just obtained
3. Click **Fetch Model List**, add models such as Sonar, and enable the provider switch in the top-right corner to start using it

{% hint style="info" %}
Perplexity models have built-in web retrieval capabilities, so no additional configuration for online mode is required. For more information, see the [Perplexity official documentation](https://docs.perplexity.ai/home).
{% endhint %}

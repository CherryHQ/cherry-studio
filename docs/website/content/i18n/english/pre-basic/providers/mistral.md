# Mistral

Mistral AI is a representative of European open-source large models, offering series such as Mistral / Codestral, balancing performance and openness.

## Get API Key

* Open the [API Keys page](https://console.mistral.ai/api-keys/) in the Mistral console (registration/login required)
* Create and copy an API Key

## Configure in Cherry Studio

1. Open [Model Service Settings](../settings/providers.md) in Cherry Studio and find **Mistral** in the built-in list
2. Enter the API Key you just obtained
3. Click **Sync models**, add the models you need, and enable the provider switch in the top-right corner to start using it

{% hint style="info" %}
For more information, see the [Mistral official documentation](https://docs.mistral.ai).
{% endhint %}

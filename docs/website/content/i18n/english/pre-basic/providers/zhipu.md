# ZhiPu (Z.ai)

ZhiPu AI builds the **GLM** series of models. Sign up on **Z.ai**, its global platform. In Cherry Studio, ZhiPu uses an **Anthropic-compatible endpoint**, so it works for **Cherry Agent** as well as regular chats.

## Get an API Key

* Sign up on [Z.ai](https://z.ai/) and create a key on the API Keys page

## Configure in Cherry Studio

1. Open [Model Service Settings](../settings/providers.md) and find **ZhiPu** in the built-in list
2. Click **Add API key**, paste your key, then click **Save and close**
3. If your key comes from Z.ai, replace the **API Host** with the address given in the [Z.ai API documentation](https://docs.z.ai/); keys from one platform don't work on the other's host
4. Click **Sync models**, add the GLM models you need, and turn on the provider switch in the top-right corner

{% hint style="info" %}
Some GLM models support built-in **web search**. See the [Z.ai documentation](https://docs.z.ai/) for current models and pricing.
{% endhint %}

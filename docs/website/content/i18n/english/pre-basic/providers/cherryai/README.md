# CherryAI (Free)

**CherryAI** is Cherry Studio's built-in free model service. It requires no third-party registration or API key and is intended for trying chat and basic text tasks.

### Where to use it

Open `Settings → Model Provider` and find **CherryAI** in the built-in list. The service is preconfigured with the app and usually requires no additional setup.

### Currently available model

According to the current CherryAI server configuration, CherryAI provides only **Qwen3-8B**.

{% hint style="warning" %}
Model availability, free quotas, and rate limits may change with the server configuration. Refer to the model that is actually shown and available in Cherry Studio. This page is not a promise of long-term availability.
{% endhint %}

For other models or a more stable service, use [CherryIN](../cherryin-1.md) or another [provider](../README.md).

## Qwen3-8B

**The well-known MaaS service platform "SiliconFlow" provides free access to the Qwen3-8B model**. As a cost-effective member of the Tongyi Qianwen Qwen3 series, Qwen3-8B delivers powerful capabilities in a compact size, making it an ideal choice for intelligent applications and efficient development.

***

**🚀 What is Qwen3-8B?**

Qwen3-8B is an **8-billion parameter dense model** from the third-generation large model series of Tongyi Qianwen, released by Alibaba in April 2025. It is licensed under the **Apache 2.0 open-source license**, allowing free use in commercial and research scenarios.

* **Total Parameters: 8 Billion**
* **Architecture Type: Dense (Pure Dense Structure)**
* **Context Length: 128K tokens**
* **Multilingual Support: Covers 119 languages and dialects**

Despite its compact size, Qwen3-8B performs stably in reasoning, coding, mathematics, and Agent capabilities. Its performance rivals that of larger previous-generation models, demonstrating high practicality in real-world applications.

**📚 Strong Training Foundation: Big Wisdom in a Small Model**

Qwen3-8B was pre-trained on **approximately 36 trillion tokens of high-quality multilingual data**, covering web text, technical documentation, code repositories, and synthetic data from specialized domains, ensuring broad knowledge coverage.

Its post-training phase introduced a **four-stage reinforcement process**, specifically optimizing the following capabilities:

✅ Natural language understanding and generation\
✅ Mathematical reasoning and logical analysis\
✅ Multilingual translation and expression\
✅ Tool calling and task planning

Thanks to the comprehensive upgrade of its training system, **Qwen3-8B's actual performance approaches or even exceeds that of Qwen2.5-14B**, achieving a significant leap in parameter efficiency.\\

**💡 Hybrid Reasoning Mode: Think or Respond Quickly?**

Qwen3-8B supports flexible switching between **"Thinking Mode" and "Non-Thinking Mode"**, allowing users to choose the response method based on task complexity.

Control the mode using the following methods:

* **API Parameter Setting**: `enable_thinking=True/False`
* **Prompt Instructions**: Add `/think` or `/no_think` to the input

| Mode | Use Cases | Examples |
| --------- | -------------- | ----------------------------- |
| **Thinking Mode** | Complex reasoning, math problems, planning tasks | <p>- Solve geometry problems<br>- Write complete project architecture</p> |
| **Non-Thinking Mode** | Quick Q&A, translation, summarization | <p>- Check weather<br>- Translate between Chinese and English</p> |

This design allows users to **freely balance response speed and reasoning depth**, enhancing the user experience.

It excels particularly in Chinese understanding, supporting Simplified Chinese, Traditional Chinese, and Cantonese expressions, making it suitable for markets in Hong Kong, Macau, Taiwan, and overseas Chinese communities.

# Free Web Search Mode

Want the AI to search the web without paying? Cherry Studio offers two **free** options, neither of which needs a paid API:

## Option 1: The Default Exa MCP (Works Out of the Box, No Key)

By **default**, Cherry Studio sets the search provider to **Exa MCP**, which uses a public endpoint and **needs no API key**. Once installed, just click the 🌐 **globe** icon in the chat input box to turn on web search for the current conversation — no extra setup required.

See [Web Search Mode](README.md) for details.

## Option 2: SearXNG (Self-Hosted, Completely Free)

If you're willing to deploy it yourself, **SearXNG** is an open-source metasearch engine that runs entirely locally or on your own server, with no limit on calls and more control over privacy.

For deployment and setup steps, see [SearXNG Local Deployment and Configuration](searxng.md).

{% hint style="info" %}
Want stronger search results, or a service that **requires a key** such as Tavily? That means configuring a different search provider in [Web Search Mode](README.md), which falls outside the "free" options.
{% endhint %}

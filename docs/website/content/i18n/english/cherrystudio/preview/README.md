# Features Overview

Cherry Studio is a desktop AI client that brings together core capabilities such as **chat assistants, agents, painting, translation, knowledge bases, notes, file management and a coding companion**. Through the [API Gateway](../../advanced-basic/developer-tools/api-gateway.md), [Channels](../../advanced-basic/automation/channels.md) and [Scheduled Tasks](../../advanced-basic/automation/scheduled-heartbeat.md), it also extends AI into automation and cross-platform scenarios.

The table below lists the main features covered in this section and where to find them:

| Feature | Summary | Entry |
| --------------------------------------- | ------------------------------------- | ------------ |
| [Chat](chat.md) | Create chat assistants, talk to different models, and use knowledge bases | **Launchpad → Chat** |
| [Work](../../advanced-basic/agent.md) | Work is the agent: it carries out tasks on its own — reading files, running commands, multi-step reasoning | **Launchpad → Work** |
| [Paintings](drawing.md) | Use text-to-image models | **Launchpad → Paintings** |
| [Translation](translation.md) | Fast side-by-side translation | **Launchpad → Translation** |
| [Mini Apps](../../cherry-studio/preview/app/README.md) | Run frequently used websites, or install local mini apps that can call Cherry AI | **Launchpad → MiniApp** |
| [Knowledge Base](knowledge-base.md) | Vector search over documents, URLs and notes | **Launchpad → Knowledge Base** |
| [Files](files.md) | View attachments from chats, paintings, knowledge bases and more in one place | **Launchpad → Files** |
| [Code Mate](code-cli.md) | Install, configure and launch AI coding CLI tools | **Launchpad → Code Mate** |
| [Notes](notes.md) | Built-in Markdown notebook for jotting and organizing; can be exported to a knowledge base | **Launchpad → Notes** |
| [Quick Assistant](kuai-jie-zhu-shou.md) | A mini question window opened with a global hotkey | Global hotkey |
| [Selection Assistant](selection-assistant.md) | Call AI from a floating toolbar after selecting text in any app | Floating toolbar after selecting text |

For more advanced capabilities, see the [Advanced Tutorials](../../advanced-basic/capability-map.md) section.

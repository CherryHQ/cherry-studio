# 思源笔记配置教程

支持将话题、消息导出到思源笔记。

## 第一步

打开思源笔记，创建一个笔记本

<figure><img src="../../assets/dd6bc4a7ef5d1aebb8b2d312.webp" alt=""><figcaption><p>点击新建笔记本</p></figcaption></figure>

## 第二步

打开笔记本打开设置，并复制 `笔记本ID`

<figure><img src="../../assets/722fb2171c5a8f812383d0f8.webp" alt="" width="400"><figcaption><p>打开笔记本设置</p></figcaption></figure>

<figure><img src="../../assets/c312b9bc99f830ab1b41ac10.webp" alt=""><figcaption><p>点击复制笔记本 ID 按钮</p></figcaption></figure>

## 第三步

复制笔记本 ID 填写到 Cherry Studio 设置里

<figure><img src="../../assets/60c706fa714b477ba0c07dcf.webp" alt=""><figcaption><p>将笔记本 ID 填写到数据设置里</p></figcaption></figure>

## 第四步

填写思源笔记地址

* **本地**\
  通常为 `http://127.0.0.1:6806`
* **自部署**\
  为你的域名 `http://note.domain.com`

<figure><img src="../../assets/f902908da13e276e7d4d361a.webp" alt=""><figcaption><p>填入你的思源笔记地址</p></figcaption></figure>

## 第五步

复制思源笔记 `API Token`

<figure><img src="../../assets/7279410a41255ae1b9eb7d42.webp" alt=""><figcaption><p>复制思源笔记令牌</p></figcaption></figure>

填入 Cherry Studio 设置里并点击检查（配置项都在上面第四步那一页）。

## 第六步

恭喜你，思源笔记的配置已经完成了 ✅ 接下来就可以将 Cherry Studio 内容导出到你的思源笔记中了

<figure><img src="../../assets/7e5e081609aca42b45bca666.webp" alt=""><figcaption><p>查看导出结果</p></figcaption></figure>

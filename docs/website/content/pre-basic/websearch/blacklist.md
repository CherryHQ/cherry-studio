# 网络搜索黑名单配置

不想让某些网站出现在联网搜索的结果里？在 `设置 → 网络搜索` 的 **黑名单** 里逐条添加要屏蔽的网站即可。规则写法参考 [ublacklist](https://github.com/iorate/ublacklist)。

## 手动配置

在黑名单输入框里 **按行** 添加规则，支持两种写法：

* **匹配模式**（[match pattern](https://developer.mozilla.org/zh-CN/docs/mozilla/add-ons/webextensions/match_patterns)）：如 `*://*.example.com/*`
* **正则表达式**：如 `/example\.(net|org)/`

添加后，命中规则的网站就不会再出现在联网搜索的结果里。

## 订阅来源

在 **设置 → 网络搜索 → 黑名单订阅** 中输入 uBlacklist 格式列表的 HTTP(S) 地址，然后点击 **添加**。应用会立即获取列表。每个来源会显示有效规则数、上次成功更新时间及刷新错误。空行、注释和无效规则会被忽略；每个来源最多保留 5,000 条规则，响应大小上限为 2 MB。

点击 **刷新** 更新来源，或点击 **删除** 移除来源。应用运行时还会每 24 小时刷新一次。刷新失败时保留上次成功获取的规则，离线时仍可使用缓存。删除来源不会更改手动添加的黑名单规则。

获取列表时使用应用的代理设置和绕过规则，超时为 15 秒。为保证连接安全，目标域名需要能在本机解析，HTTP 代理需要允许 CONNECT 到目标端口。代理失败时不会自动改为直连。应用中允许访问私有网络的设置仍然生效。

从 v1 升级时，会迁移仍然存在的来源地址和缓存规则。部分早期迁移可能已经清空旧订阅数据。如果升级后的来源列表为空，请重新添加订阅地址。

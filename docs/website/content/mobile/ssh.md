# SSH 远程服务器

SSH（通过认证连接远程服务器的方式）可用于浏览、预览和传输服务器文件，也能让智能体执行远程命令。它直接连接你配置的服务器，与 Cherry Studio [电脑智能体](remote-chat.md)和[远程桌面](remote-desktop.md)不同。

## 保存一个连接

1. 从侧边栏打开 **插件**，在 **SSH 连接** 分组添加连接。
2. 填写名称、服务器主机名或 IP、端口和用户名；端口默认 22，以服务器实际配置为准。
3. 选择密码或私钥认证，在专用字段填写凭据；私钥有口令时也需填写。
4. 按页面保存，并检查连接。首次使用时核对服务器指纹，再确认信任；指纹变化时先确认是否确实换过服务器或密钥。

认证过程中可能出现服务器要求的补充认证弹窗。密码、私钥和验证码应在专用表单中提交，不要发进聊天；这些认证回答不作为智能体输入或对话工具结果。

保存配置不代表服务器已连通。手机网络、服务器 SSH 服务、端口和账号权限都需要可用；手机上的 localhost 指向手机自身。

## 浏览、预览与传输文件

打开保存的连接并进入文件浏览，按目录查看文件。支持的文件可以预览；上传时选择本机文件，下载时确认服务器源路径与本机保存目标。

预览只是查看，不代表已经把完整文件长期保存到文件库。传输完成后按返回结果核对目标位置。服务器文件操作会直接影响服务器，不会因为关闭预览或删除聊天而撤销。

## 在对话中使用服务器

1. 选择标准模式和支持工具调用的文字模型。
2. 在 **＋ → SSH** 选择已保存的连接，插入本次任务的服务器引用。
3. 写明路径、范围与目标，例如：

> 查看这台服务器当前工作目录下的 README，概括启动步骤。先不要运行命令或修改文件。

> 列出 /var/log 中最近修改的文件，先报告结果，不要删除。

选择连接本身不会执行命令。需要命令、上传或改写文件时，明确要求操作对象，再核对审批中的主机、账号、命令、工作目录和输入。

## 审批与有限诊断授权

SSH 操作保留独立审批，普通的“自动批准”不会直接绕过。命令审批可能提供当前会话、当前连接的一小时诊断授权；它只覆盖受限的简单诊断命令，不是允许任意脚本、组合命令、路径操作或写入。到期或换会话/连接后重新处理。

对需要修改、重启或删除的操作，仍应以实际审批和执行结果为准。取消或断线时，远程动作可能已经开始，先检查结果再重试，避免重复执行。

## 恢复备份或更换服务器后

[备份](backup-and-restore.md)保留 SSH 连接配置，**不包含密码、私钥或私钥口令**。恢复后重新填写凭据；主机指纹、服务器账号和路径也应重新核对。

文件浏览、认证或执行出错时，先看连接页诊断和返回错误，区分网络、主机信任、认证、路径与文件权限问题。

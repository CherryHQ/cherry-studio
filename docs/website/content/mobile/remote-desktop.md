# 查看与控制远程桌面

远程桌面通过 **UU 远程** 打开电脑屏幕与控制界面；Cherry Studio 负责保存关联并发起打开，UU 负责实际画面、连接和控制。它与在手机发送文字任务的[电脑智能体](remote-chat.md)是不同功能。

## 准备条件

* 手机安装 **UU 远程 4.42.0 或更新版本**，目标电脑也已配置 UU 远程。
* 在 Cherry Studio 中[配对电脑](desktop-sync.md)，从侧边栏的设备选择器切换到该电脑。
* iPhone / iPad 画中画另需 **iOS / iPadOS 18 或以上**及支持的设备。画中画不可用时，可选择明确提示的全屏方式。

Cherry Studio 能检查是否可打开 UU，但不能替你确认安装的 UU 版本，版本应在 UU 中核对。

## 首次关联与打开

1. 在已选择电脑的设备菜单中点击 **远程桌面**。
2. 按提示前往 UU，选择应与这台 Cherry Studio 电脑对应的 Windows 或 macOS 设备。
3. 完成关联后，按 UU 的界面建立远程连接。后续可从同一入口直接打开画中画。
4. 需要改成全屏时，按提示确认；全屏打开后手动切回 Cherry Studio。

UU 中选到哪台电脑由你确认。保存的关联标识不能证明它就是 Cherry Studio 配对的物理电脑；选错时到 **设置 → 设备互联 → 目标设备** 重新关联。

## 不能打开画中画

检查 UU 安装与版本、手机系统和硬件支持，按页面选择全屏替代方式或取消。取消不会自动同意全屏。

**成功唤起 UU 不等于远程控制已连接成功。** 账号、网络、电脑在线情况及实际控制权限应在 UU 中检查。退出 Cherry Studio 的电脑配对也不等于撤销 UU 中的远程控制授权。

# 生成与修改文件

智能体可以把回答保存为文字文件，也能创建和修改真正的 Word、Excel、PowerPoint 文件。先使用**标准模式**和支持工具调用的文字模型，再说明成果格式、内容与保存位置。

## 把回答保存成一个文件

明确要求保存，并提供文件名，例如：

> 把刚才的出行建议整理成 Markdown 清单，保存为“周末出行清单.md”，提供可打开的文件。

> 根据我上传的采购清单创建“预算.xlsx”，按分类汇总金额，保留明细工作表。

等待工具完成，打开返回的文件卡片，也可从侧边栏 **文件** 找回。生成中的文字或一段代码块本身不代表文件已保存。

## 选择什么格式？

| 你要的结果 | 建议格式 | 说明 |
| --- | --- | --- |
| 普通文字、笔记或清单 | TXT、Markdown | 方便复制与继续编辑 |
| 简单表格数据 | CSV | 不含多个工作表、样式或图表 |
| 带段落、标题、表格与图片的文档 | DOCX | 真正的 Word 文档，可在支持的软件里继续编辑 |
| 工作表、公式与表格数据 | XLSX | 真正的 Excel 工作簿；需核对公式结果 |
| 可编辑的演示文稿 | PPTX | 使用文档工具创建文字、图片和支持的幻灯片内容 |
| 网页、信息卡或强调页面外观的演示稿 | HTML | 可预览，并可[转换成图片或图片式 PPT](html-export.md) |

旧版“内置工具只能保存文本”的说明已不适用。文本写入工具仍限制单个 UTF-8 文件 **1 MiB（1024 × 1024 字节）**；Office 工具使用自己的文件格式与限制。仅把文本扩展名改成 `.docx`、`.xlsx` 或 `.pptx` 仍不会得到有效文档。

原生 PPTX 与 HTML 转换的 PPTX 不同：前者可包含可编辑对象，后者每页是一张画面。请根据后续是否要逐项编辑来选择。

## 按工作区路径保存

从对话 **＋ → 文件夹** 关联工作区，再要求“保存到 notes/会议纪要.md”。新成果进入当前工作区；未关联时进入文件库根目录。也可以要求智能体先创建一个文件夹。

多个对话可关联同一文件夹；更换关联不会搬移旧文件，见[文件库与共享工作区](file-library.md)。

## 让 AI 读取并修改已有文件

1. 通过 **＋ → 文件** 添加文件，或从工作区选择材料。
2. 先让智能体读取结构，再说明要改什么、保留什么。
3. 打开结果文件，检查实际内容后再分享。

例如：

> 读取这个 Word 文档的标题和表格，把第二节交付日期改为下周三，其他内容保持不变。

> 在这个 Excel 工作簿中，只修改“预算”工作表 B5 的数量，保留其他工作表和公式。

在 Word、Excel 或 PowerPoint 预览中，还可以选择段落、单元格或幻灯片，将具体选择带回对话继续处理。选择用于明确上下文，并不表示改动已经执行。

PDF 可提取文本、进行支持的识别与预览，但不等于内置工具可以任意改写 PDF 原版式。复杂排版、宏、外部链接、图表或其他不受支持的结构应逐项核对；失败时按工具说明缩小改动范围。

### 修改会覆盖原文件吗？

* 修改较早的文件会保留源版本，结果以新文件或当前逻辑文件的新版本返回；历史消息仍引用当时的内容。
* 同一轮任务中刚创建的草稿可以继续调整，不一定每改一次都增加一个独立条目。
* 修改导入副本不会同步改写手机其他目录或云盘中的原文件。

不要只凭文件名判断是否覆盖。以返回的文件卡片与文件库中的实际结果为准。

### 为什么说找不到要替换的文字？

文本替换需要准确匹配原文。内容已变、重复句子或空格标点差异，都可能导致失败。让智能体重新读取并确认位置；处理 Office 文件时优先按段落、工作表与单元格、幻灯片等结构说明目标。

## 读了一部分，等于读完整个文件吗？

不等于。大文件、分页读取与解析都有各自限制。要求智能体说明读取范围，继续处理未覆盖的部分；源文件已被截断或页面未识别时，需要补充或拆分材料。

Office 工具可检查文档结构与文件包有效性，但文件有效不等于内容正确。Excel 中“没有公式缓存”也不同于公式错误：应使用能重新计算公式的软件打开后核对，不能把缺失缓存当作零值。

工具仅访问当前对话获准使用的附件、成果和工作区资料，不能扫描整个手机。

## 找回、预览和分享

从 **文件** 打开成果，可预览支持的文档；Word 预览可适应屏幕并缩放，选择需要的部分后可继续提问。不支持或过大的文件可用其他应用打开。

预览中的复制可能只包含显示的部分；**分享原文件**用于传递完整文件。共同的分享面板提供 **保存** 和 **分享**，目标与临时文件规则见[分享与导出](sharing-and-export.md)。

重要成果应保存到 App 外，并确认接收软件能打开。文件读取、文本与 Office 创建/编辑一般直接执行；文件移动、删除或外部服务操作遵循各自审批，见[工具说明](using-tools.md)。

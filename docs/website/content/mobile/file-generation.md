# 生成与修改文件

除了直接回答，智能体还能把文字保存为文件，让你预览、继续修改，再分享出去。这适合清单、会议纪要、表格数据和简单网页。

## 把回答保存成一个文件

选择支持工具调用的文字模型，在消息中明确要求**保存文件**和文件名：

> 把刚才的出行建议整理成一份 Markdown 清单，保存为“周末出行清单.md”，并提供可以打开的文件。

Markdown 是可以保存标题、列表和表格的文字格式。只要简单文字，也可以要求保存为 `.txt`。

生成过程中显示的文字预览，是正在准备的文件内容，不是已经保存的文件。等待操作完成，点击生成的文件卡片打开；也可以从侧边栏的 **文件** 中找回。

如果回答只有代码块，没有可打开的文件，可以继续说：“请把这些内容实际保存到文件中，不要只在回答里展示。”

## 选择什么格式？

| 你要的结果 | 建议格式 | 示例 |
| --- | --- | --- |
| 普通文字 | TXT | “保存为通话记录.txt。” |
| 带标题、清单和表格的文章 | Markdown | “保存为会议纪要.md。” |
| 用表格软件处理的数据 | CSV | “列为物品、数量、备注，保存为采购清单.csv。” |
| 带排版的页面或演示稿 | HTML | “生成一个可独立打开的 HTML 文件，保存为项目介绍.html。” |

内置文件写入工具保存的是文字，单个文件最多 1 MB。**把文件名改成 `.docx`、`.xlsx` 或 `.pptx`，不会自动变成真正的 Office 文档。** CSV 可用表格软件打开，但不包含工作簿中的多个工作表、格式和图表。

需要 PPT 时，可以先制作 HTML 演示稿，再使用[HTML 转图片与 PPT](html-export.md)。如果某个插件提供其他文档创建能力，则以该插件实际支持的功能为准。

## 按工作区路径保存

先在对话顶部关联文件夹，再要求“把总结保存到 notes/会议纪要.md”。新输出会放入当前工作区；没有工作区时放在文件库根目录。多个对话可关联同一文件夹，便于继续处理资料，详见[文件库与共享工作区](file-library.md)。

## 让 AI 读取并修改已有文件

1. 在对话中点击 **＋ → 文件**，选择已有文件或上传文件。
2. 明确指出要改哪一部分、改成什么，哪些内容保持不变。
3. 打开修改后的文件，核对结果。

例如：

> 修改我上传的采购清单.csv，把“雨伞”这一行的数量从 1 改为 2，其他行保持不变。

> 将刚才生成的会议纪要.md 中“下周一交付”改为“下周三交付”，其他内容不变。

文字文件可以直接修改；PDF、Word、Excel 等文档可以在支持范围内提取内容供模型阅读，但内置编辑工具不能直接修改它们原有的版式和文件结构。可以要求“提取内容后整理成一份新的 Markdown 文件”。附件格式和读取限制见[对话与文件](chat-and-files.md)。

### 修改会覆盖原文件吗？

* 修改上传的文件或之前回答生成的文件，会保留旧内容并生成新版本。文件库显示同一逻辑文件的当前版本，历史消息仍引用当时的版本；不要把它理解为每次都另列一个带 `v2` 名称的文件。
* 在同一次回答中，智能体可以反复调整刚生成的草稿，最终显示一个文件，不会每改一句就生成一个新版本。

这不是持续同步：修改 Cherry Studio 中导入的副本，不会同时修改手机其他位置或云盘中的原文件。

### 为什么说找不到要替换的文字？

编辑需要匹配文件中的原文。文字已经变化、同一句出现多次，或标点空格不同，都可能导致无法确定位置。让智能体先重新读取相关段落，再指定更完整的句子或上下文；只有确实要修改所有相同内容时，才要求全部替换。

## 读了一部分，等于读完整个文件吗？

不等于。大文件可能分多次读取，文档提取本身也有限制。需要全文检查时，可以要求：“继续读取尚未覆盖的部分，并说明还有哪些内容没有读到。”如果源文档已经被截断，继续读取也不能恢复未提取的部分，应拆分文件后重新提供。

读取工具可使用当前对话可访问的附件、生成文件及所关联工作区的资料，不会扫描手机里的所有文件。换一段对话时，可再次附加文件，或关联同一个[文件夹工作区](file-library.md)。

## 找回、预览和分享

从侧边栏打开 **文件**，可以切换列表或网格，按类型查看文件。点击文件进入预览；不支持内置预览的格式可交给系统中的其他应用打开。

预览页右上角 **更多** 菜单提供分享、用其他应用打开等操作；文本文件还可复制文字。长文件只显示部分内容时，复制也只复制显示的部分，分享则使用完整原文件。

文件保存在本机。重要内容请通过系统分享保存到手机文件或其他存储位置，再确认能够打开；清理本机文件或卸载 App 前尤其如此。导出聊天与分享文件是不同入口，分享问答见[分享与导出](sharing-and-export.md)。

内置读取、创建和修改文本文件通常直接执行，在 **需要时确认** 模式下也不逐次询问。详见[工具审批说明](using-tools.md)。

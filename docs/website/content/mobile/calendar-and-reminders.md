# 日历与提醒事项

日历适合安排有开始和结束时间的活动；提醒事项适合记录需要完成的事情。你可以让智能体先查安排，再按要求创建或修改，不必记住工具名称。

内置日历使用手机系统可访问的日历，支持 iOS 和 Android；内置提醒事项当前只支持 iOS。飞书、钉钉等服务中的日程和任务使用各自的[插件](plugins.md)，不会因为授权了手机日历就自动接通。

## 使用前准备

1. 选择支持工具调用的文字模型。
2. 编辑当前智能体，在 **系统** 区域开启 **日历** 或 **提醒事项**。
3. 按提示授权，或进入 **设置 → 系统权限** 查看读写权限。
4. 希望创建、修改或删除前先审批，将智能体的工具审批方式改为 **需要时确认**。

读取权限与写入权限可能不同。可以创建日程不代表能读取全部日程；只读日历也不能用来创建或修改活动。

## 查明天的安排

先问清可用日历，多个账号或同名日历时尤其有用：

> 列出手机中可用的日历，以及哪些可以写入。先不要做修改。

接着指定范围：

> 读取“工作”日历中明天的日程，按时间排序，列出开始时间、结束时间、标题和地点。

查询有时间范围和条数限制：单次时间跨度最多 90 天，日程或提醒事项单次最多返回 200 条。需要更多内容时按周或按月分开查询；一次返回的列表不一定就是全部记录。

## 创建一个日程

> 在“个人”日历中，明天北京时间 15:00 到 15:30 创建“整理旅行资料”，地点写“家中”，备注写“确认票券和住宿”。

说清 **日期、时区、开始与结束时间、日历名称**。跨时区旅行或远程会议时，使用“北京时间”“东京当地时间”等明确表述。

保存后可以继续问：“重新读取这个时间段，确认刚才的日程是否存在。”如果工具提示结果不确定，先查看系统日历，再决定是否重试。

### 能邀请参会人、设置重复或提前提醒吗？

当前内置工具没有参会人邀请、重复规则和独立的提前提醒设置。创建带有会议名称的日程不会自动发出邀请。需要这些设置时，在系统日历中完成，或使用支持对应操作的办公插件。

## 修改或删除已有日程

先查找，再描述唯一对象，避免只有“改一下明天的会议”：

> 找到明天“个人”日历中 15:00 的“整理旅行资料”，先告诉我当前时间和地点。

核对后再发：

> 把刚才这条改到 16:00—16:30，地点和备注保持不变。

删除也先核对标题、日期和所属日历。删除聊天记录不会恢复已经删掉的日程。

## 用提醒事项管理待办（iOS）

| 目标 | 可以这样提问 |
| --- | --- |
| 选择清单 | “列出我的提醒事项清单，告诉我哪些可以写入。” |
| 新增事项 | “在‘个人’清单中添加‘寄快递’，截止时间为明天北京时间上午九点，备注‘带上退货单’。” |
| 查看未完成事项 | “列出这周‘个人’清单中未完成的提醒事项，按截止时间整理。” |
| 调整日期 | “找到刚才的‘寄快递’，把截止时间改为明天下午两点，其他内容不变。” |
| 标记完成 | “把刚才确认的‘寄快递’标记为已完成。” |
| 删除事项 | “删除刚才确认的那一条‘寄快递’，不要删除同名的其他事项。” |

标记完成会保留事项并改变状态，删除会移除事项。工具可以设置开始时间、截止时间与文字备注；需要到点通知时，请在系统提醒事项中确认提醒设置和通知权限。

**地点文字只是备注，不是“到达某地时提醒”的触发条件。** 复杂重复或地点触发提醒请在系统提醒事项中设置。按日期查到的结果也不等于整个清单，没有日期的事项可到系统 App 中核对。

## Android 为什么跳到系统日历？

部分 Android 设备无法直接完成日历操作时，App 会尝试打开系统日历页面：

* **新增页面**：核对日期和内容，选择目标日历，手动保存。
* **已有日程页面**：检查当前值，手动完成剩余修改；你在聊天里要求的改动不一定已填入。

页面打开后，Cherry Studio 无法仅凭这一动作确定你是否保存。若提示“结果不确定”或写入超时，原操作可能已经完成，先核对日历，避免再次新增造成重复。

## 找不到日历或事项

先在系统日历或提醒事项 App 中确认账号和目标记录存在，再检查 Cherry Studio 的权限、查询日期和所选日历。企业账号、只读订阅日历和未同步到手机的资料，可能不在可操作范围内。

工具是否需要确认，见[让 AI 使用工具](using-tools.md)；系统权限与数据用途，见[数据、隐私与权限](data-privacy.md)。

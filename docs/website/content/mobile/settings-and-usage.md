# 设置、用量与后台回复

从侧边栏打开设置，管理阅读、模型、语音、系统权限和本机数据。备份、DeepSeek 导入与缓存清理集中在 **设置 → 数据**。

## 主题、语言与字号

在 **设置 → 通用设置** 选择主题、应用语言、字体大小、分享水印和文档解析器。界面语言与官网文档语言分别设置；水印只影响后续分享，本机保存不加水印，见[分享与导出](sharing-and-export.md)。

通用设置还包括：

| 选项 | 作用 |
| --- | --- |
| 回车发送 | 调整键盘发送方式，按页面说明操作 |
| 多模型回复卡片 | 在卡片与普通回复展示间选择，不改变已保存内容 |
| 分支对话树形视图 | 在树形与按最近活动平铺的列表间切换，默认开启，不合并分支 |
| 自动折叠过程 | 调整思考和工具过程的阅读展示，不删除执行记录 |
| 生成时保持屏幕常亮 | 仅在应用前台生成时尝试保持常亮，默认关闭，不延长后台执行 |

更改按各自操作保存，出现失败提示时重试。多模型和分支的实际使用见[对话分支](conversation-branches.md)。

## 默认模型与绘图模型

在 **设置 → 默认模型** 分别设置默认文字、绘图和翻译模型；翻译未单独设置时回退默认文字模型，详见[翻译](translation.md)。

该页还提供自动命名与命名模型设置。命名模型用于为会话取标题，不会替换智能体回答问题的模型。选择的模型仍需符合对应服务的实际用途权限。

已有智能体保留自己的模型，修改全局默认不会批量覆盖它们。组织空间可能限制模型选择或编辑；列表为空时先检查当前账号、模型服务和加载状态，见[账号与组织](accounts-and-organizations.md)。

## 查看用了多少模型额度

可从设置中的 **AI 用量** 或首页用量入口查看，按页面切换概览、分布、性能与历史，并按时间、服务商或模型筛选。单条回答也可查看输入输出量、请求次数、耗时与费用。

**Token（模型计算内容长度的单位）**不等于字数；历史、思考、工具往返及多模型并行都可能产生用量。

* 服务商返回的金额与根据模型价格估算的费用有不同来源，留意标签。
* 缺少价格只代表无法完整估算，不等于免费。
* 删除聊天不会退回已发生的费用；重新回答和追加模型是新的请求。
* 这里是本 App 记录的用量，不是整个第三方账户的余额或正式账单。

社区账号的 CherryAI 套餐与额度由账号服务返回，与本机用量统计分别展示；能否发送仍由实际权益与额度检查决定。不要用侧边栏显示过的旧余额推断每次请求都能通过。

## 离开应用后继续生成

打开 **设置 → 通知** 查看后台运行状态与系统限制：

| 项目 | 用途 |
| --- | --- |
| 后台运行 | 显示当前执行保护与省电限制状态 |
| Android 电池及厂商设置 | 前往系统检查电池优化、自启动和后台限制；具体选项由设备系统提供 |
| iPhone / iPad 实时活动 | 控制锁屏与灵动岛上的任务状态展示，**不是后台执行开关** |
| 回复完成通知 | 系统允许时通知后台完成的回复 |

支持时会优先使用系统持续处理能力；不可用时，其他回退方式需要按提示明确同意。首次引导与任务提示可能要求你先阅读后台说明，不能把关闭说明、状态卡或通知当作取消执行。

系统通知权限与 App 内偏好分别管理。实时活动主要在离开页面后展示；正在查看的任务完成时通常不会重复通知。点击任务通知可返回对应内容。

## 锁屏后为什么还是中断？

后台运行受系统时长、电池、网络与进程限制，**没有持续运行保证**。实时活动只展示状态；前台屏幕常亮也不能延长锁屏后的执行时间。较长任务尽量保持前台。

请求断开后可能显示重试，待发队列可在重开应用后恢复；被系统结束时仍以已保存的内容为准。先查看当前回复、队列与审批，再决定重发，避免重复任务或费用。

电脑执行的任务不因手机断开自动停止，见[电脑智能体](remote-chat.md)。[后台朗读](voice.md)与生成任务也分别受系统控制，不能相互当作运行成功的证明。

## 文档解析、备份与反馈

* **设置 → 通用设置 → 文档解析器**：选择后续文档读取方式，见[对话与文件](chat-and-files.md)。
* **设置 → 数据 → 备份与恢复**：创建完整备份或替换恢复，见[备份教程](backup-and-restore.md)。
* **设置 → 数据 → 导入 DeepSeek 数据**：从官方导出下载链接导入，不会合并替换现有会话，见[导入教程](deepseek-import.md)。
* **设置 → 数据 → 清理对话运行缓存**：先结束执行与排队任务，再确认清理。聊天记录和文件保留，继续旧对话时会重新准备，第一条回复可能稍慢；不是清空聊天。
* **设置 → 语音**：语音输入、音频转写和朗读分别配置，见[语音教程](voice.md)。
* **设置 → 关于我们**：查看版本、反馈与反馈记录；失败时也可先做[错误诊断](diagnostics.md)。

## 隐私与系统权限

**隐私设置**分别管理匿名使用数据与错误报告；**系统权限**管理相机、日历等设备访问；**账号与组织**管理当前身份与空间。三者不能互相代替，详见[数据、隐私与权限](data-privacy.md)。

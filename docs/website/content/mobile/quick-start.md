# 快速开始

先准备一个可用模型，让它回答一条简单消息，再添加文件、技能或其他工具。

## 1. 选择配置方式

首次安装后，应用会依次引导你完成欢迎、隐私选择、设备权限、通知与后台说明、账号和模型准备。权限与登录可按页面跳过，之后可在设置中补充；已有配置的设备不会因此重新开始整套引导。

* **使用自己的模型服务**：选择 **连接服务商**，继续第 2、3 步。
* **电脑已经配置好**：选择 **从桌面端同步**，完成[配对与配置导入](desktop-sync.md)，再选择模型。
* **已有可用的社区订阅账号**：登录后按账号实际权益选择授权模型，不必把它当作普通 API 密钥服务商重复添加。
* **使用组织或私有部署**：按[账号与组织空间](accounts-and-organizations.md)登录，使用组织提供的模型与智能体。

账号或模型列表正在加载、读取失败时，应等待或重试，不能据此判断没有权益。暂不配置也可以进入 App，稍后从 **设置 → 模型服务** 添加服务；未选可用模型前不能发送有效的模型请求。

## 2. 填写并保存密钥

填写平台提供的 **API Key（调用模型服务的密钥）**，或使用该服务商页面实际提供的账号登录方式。自定义服务商还要核对基础地址与接口。

新建时按向导继续完成创建；已有服务商按各字段自动保存，密钥编辑弹层仍需点击自己的 **保存**。登录密码、网页聊天会员和接口额度不是同一回事，以平台实际支持为准。

## 3. 添加模型并启用服务商

同步模型列表，勾选常用文字模型；获取失败时可用准确模型 ID 手动添加。等待首次模型资料准备完成，确认服务商已启用。

首次使用向导确认模型后会设置默认模型并带你进入对话，**不会自动发送测试消息**。之后可在对话的模型选择器或当前智能体编辑器中更换。组织管理的模型列表可能只允许选择，不允许修改。详见[服务商与模型](providers-and-models.md)。

## 4. 发送第一条消息

使用初始智能体，选好模型后，发送：

> 用三句话介绍你能帮我做什么。

收到回复说明这次连接与模型可用。没有回复时，先用不带附件的短消息缩小范围，再打开错误详情中的[检查与 AI 诊断](diagnostics.md)，或按[常见问题](troubleshooting.md)排查。

同一个智能体可以开启多段不同主题的对话。改变长期风格时修改智能体指令；只针对这次问题的要求直接写在消息里。

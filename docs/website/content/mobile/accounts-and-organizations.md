# 账号与组织空间

移动版可以使用自己的模型服务，也可以登录 Cherry Studio 社区账号、组织账号或私有化部署。**登录身份、模型额度和本机数据空间是不同的事**：个人资料与历史保存在本机，模型及组织资源按当前服务的实际授权提供。

## 登录与切换入口

从 **设置** 顶部的个人资料进入账号区域，也可在首次使用引导中登录。

* **Cherry Studio 账号登录**：按账号页面完成登录，并选择社区或有权限进入的组织空间。
* **私有化部署登录**：填写组织提供的服务地址、用户名和密码；不是填写模型服务商的 API Key。
* **暂不登录**：可继续在个人本地空间配置自己的模型服务。

社区或组织账号可以使用 **切换组织** 选择可用空间，也可切换账号。私有部署使用 **切换账号** 连接其他身份或服务。浏览器授权结束后应回到 App 查看结果；打开登录页不等于已完成登录。

## 切换后，我的聊天在哪里？

| 空间 | 数据与资源的归属 |
| --- | --- |
| 个人本地空间 | 未登录或使用社区账号时，仍使用原来的本机个人数据；社区账号切换或退出不会自动清空这些聊天 |
| 组织或私有部署空间 | 按组织服务与身份使用独立的本地空间，展示该空间的聊天、文件、智能体和组织资源 |

切换空间会重新载入对应数据，**不会把各空间的聊天自动合并，也不会把个人文件搬到组织中**。暂时看不到原对话时，先确认当前空间；不要因此直接删除数据或用另一空间的备份覆盖。

退出组织会切回个人空间；再次进入同一组织身份后，可重新访问原来属于它的本机数据和资源。这里的“本地空间”不等于跨手机云同步，换机仍需按[备份与恢复](backup-and-restore.md)处理。

## 社区账号与 CherryAI 模型

已有有效权益的社区账号，可通过受管理的 **CherryAI** 服务使用授权模型，并看到服务返回的套餐与剩余额度。当前显示可用的模型和用途由账号服务决定，不能靠本机修改名称、价格或能力标记解锁。

* 等待账号与模型列表加载；失败时先重试，不要把失败解释成“余额为零”。
* 发送仍需满足模型、用途、有效期与额度要求，显示过模型不代表之后的每次请求都可用。
* 自己添加的 API 服务商继续使用其自己的凭据和计费方式，不会因登录社区账号自动获得额度。
* App 内的额度展示不是第三方模型服务的完整账单；已有社区权益也不代表任意模型或插件都免费。

## 组织配置为什么不能编辑？

组织端提供的模型服务、模型、智能体、指令、技能或工具可能被锁定或隐藏。它们由组织管理；手机展示与使用已下发的资源，不把本机编辑页当作组织配置的管理后台。

受管理智能体可能允许在指定模型中选择，或调整模式、工具审批等本机可编辑项；以当前页面实际开放的字段为准。缺少资源、访问被拒绝或需要新增权限时，联系组织管理员在对应服务端处理。

## 退出登录与恢复备份

退出社区账号不会自动删除个人本地聊天，但账号授权模型可能不可再用。退出组织有单独确认；不要把退出登录当作删除组织数据或撤销所有第三方插件授权。

组织备份只可恢复到**相同组织身份**，个人备份恢复到个人空间。组织下发的模型、密钥和工具不随备份带走，恢复需要联网重新取得；详见[备份教程](backup-and-restore.md)。

# 分享与导出

先在来源中选择内容，再到共同的预览面板选择格式，最后决定 **保存** 还是 **分享**。两种操作的目标不同：保存把成果留到相册或文件库，分享把临时成果交给系统分享面板。

## 分享一条或多条消息

1. 从回答操作区或消息菜单点击分享。**当前对话直接进入选择状态**，输入草稿保留，不再跳到独立的摘要选择页。
2. 勾选问题和回答。选择一个问题时，会连同它当前显示的已完成回答一起选中；取消问题不会自动取消已选回答。
3. 可使用全选，最多 **128 条可导出消息**。选择期间不能切换同一问题下的其他回答，先退出选择再更换分支。
4. 点击 **分享**，打开预览，再选择图片、HTML 或 Markdown。
5. 检查范围和内容后，点击面板中的 **保存** 或 **分享**。

只导出选中的内容，并按当前对话路径的时间顺序整理。未完成、缺失或已变化的消息可能使本次准备失败，需要回到来源重新选择。长回答在选择状态下可能折叠，但 HTML / Markdown 读取的是所选完整正文。

## 把译文一起分享

开始选择前，在原对话展开需要的译文并选好语言。分享会携带与原文匹配、当时已展开的译文；收起、未完成或已经过时的译文不导出，也不会临时发起翻译。详见[翻译教程](translation.md)。

## 选哪种格式？

| 格式 | 适合用途 | 输出范围 |
| --- | --- | --- |
| 图片（PNG） | 把简短内容发到聊天里直接阅读 | 一张有高度上限的内容卡片；过长的正文、代码或表格会截断并以省略号结束 |
| HTML | 保留所选完整正文、代码和较丰富排版 | 需要用浏览器或兼容软件打开 |
| Markdown | 保存完整文字、代码和表格，便于继续编辑 | 具体显示取决于阅读器 |

**聊天图片不再默认分页，也没有“单张长图 / 分页”切换。** 当前整张卡片最高 3600 逻辑点，输出上限为 1080 × 10800 像素，页脚也计入高度。需要完整长文或代码时选 HTML / Markdown，或缩小选择范围。

文件、图片组和 HTML 转换可能各有多个预览项，它们的分页不等于聊天卡片恢复了旧的分页规则。引用和来源仍应打开原网页核对。

## 选择页与预览的格式提示不一致怎么办？

当前在原对话中完成选择，所有非空且有效的选择都可进入图片、HTML、Markdown 预览。

## 思考和工具过程会一起发出去吗？

**不会。** 现在导出问题、最终回答、支持的静态图片、附件说明、来源及匹配的展开译文，不提供“包含思考内容”开关。思考、中间过程、工具名称与执行记录、耗时、用量和诊断数据不进入这些导出格式。

要单独反馈错误或诊断信息，请使用[诊断与反馈](diagnostics.md)，不要把聊天分享当作完整执行日志。

## Markdown 里的图片能离线看吗？

导出可以嵌入支持的本地图片，但文件可能变大，部分阅读器不显示嵌入内容。GIF、WebP 或其他不支持嵌入的内容可能只保留不可用说明；动画效果不应靠聊天卡片保存，需要[分享图片原文件](image-generation.md)。

远程图片可能仍依赖原链接；附件说明也不等于已打包附件原件。要交付完整文件，应另外分享原文件，并在接收端确认。

## 图片导出失败怎么办？

失败后**保留所选格式并提供重试，不会自动换成 HTML 或 Markdown**。处理原因后重试，或主动选择另一种格式。格式切换会取消过时的准备工作，以最终选择和实际预览为准。

长内容建议保持前台。关闭预览返回原来源，修改消息范围需回到对话重新选择。打开或关闭系统分享面板都不能证明目标应用已经保存或发送成功。

## 去掉分享水印

**设置 → 通用设置 → 分享水印** 控制后续对外分享的水印，默认开启。已经保存或发出的内容不会随设置改变。

预览里的 **保存** 使用无水印成果：聊天图片保存到相册，HTML / Markdown 保存到文件库；分享可按当前全局设置带水印。不要把“分享”和“保存”当作同一个动作。

## 文件库与原文件分享

在 **文件** 中可选择一个或多个文件分享，共同面板按原顺序预览。文件库的分享入口发送原文件，不显示 HTML 转图片/PPT 的格式切换。

* **分享**不自动把临时导出结果加入文件库；需要留存时明确点 **保存**。
* 图片组可在预览中切换项目，保存原图到相册；分享位图时可按全局设置加水印，本机保存保持无水印。
* 大文本的复制可能只使用当前显示内容，分享原文件用于传递完整原件。
* 批量准备中某个文件失败时，先解决错误或重新选择，不要把打开面板当作全部交付完成。

## 将 HTML 文件转为图片或幻灯片

打开 HTML 文件进入**文件预览**，再点击分享，在支持转换时切换 **原始文件 / 图片 / PPT**。这与文件库列表里的原文件分享不同。详细步骤见 [HTML 转图片与 PPT](html-export.md)。

转换后的 PPTX 每页是一张图片；要编辑文字与表格，应让智能体[直接创建原生 Office 文件](file-generation.md)。

## 分享生成的文件或演示稿

打开结果文件，再选择保存或分享。仅保存在 App 文件库中的内容仍属于本机应用数据，卸载前应保存到外部位置并确认可打开。保存部分成果不能替代[完整备份](backup-and-restore.md)；文件夹、回收站与版本规则见[文件库](file-library.md)。

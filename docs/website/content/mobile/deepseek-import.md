# 导入 DeepSeek 对话

此功能把 DeepSeek 官方导出包中的可读取对话带入移动版，用于查阅和继续讨论；它不是登录 DeepSeek 账号，也不会自动替你配置 DeepSeek 模型服务。

## 准备导出下载链接

在 DeepSeek 的数据导出功能中申请导出，取得 ZIP 导出包的**完整下载链接**。应复制实际下载地址，保留其完整参数；普通网页、单条会话分享链接和手机本地文件路径不能代替它。

链接可能包含有时效的访问凭据，不要公开发到问题反馈或聊天中。过期后应从 DeepSeek 重新取得新链接。

## 在 App 中导入

1. 打开 **设置 → 数据 → 导入 DeepSeek 数据**。
2. 把完整地址粘贴到 **DeepSeek 导出下载链接**。
3. 点击键盘上的 **前往 / Go** 开始，等待下载、读取与导入进度。
4. 成功后打开新建的 **DeepSeek** 智能体，检查会话数量、标题、分支与可用附件。
5. 要继续聊天，确认该智能体已经选好可用模型；需要时按[模型教程](providers-and-models.md)配置。

现有智能体和会话保留不变。**每次成功导入都会新建一个 DeepSeek 智能体**，重复导入不会自动合并或去重。它可使用已有默认模型，但不保证该模型来自 DeepSeek。

## 哪些历史会保留？

可读取的消息、标题、时间和分支会尽量保留；导出包中实际存在、能导入的图片才会成为附件。缺失附件或不支持内容可能只保留名称/说明，并显示部分导入提示。

历史搜索和网页链接作为来源记录，不会重放历史工具操作；无法恢复的计费或运行状态也不会编造。导入成功不表示原服务中的全部数据均已提供到导出包。

## 导入失败或中途离开

* **链接过期或下载失败**：获取新的官方导出地址，检查网络后再试。
* **部分数据损坏**：可读会话或片段可能继续导入，查看跳过或缺失提示；不要把部分成功当作完整恢复。
* **ZIP 结构损坏、格式不支持或没有可读消息**：重新从 DeepSeek 导出。
* **容量过大、空间不足或其他数据操作正在进行**：按错误处理后再试，避免同时创建或恢复备份。

离开导入页会取消本次操作；不提供后台持续下载或被系统结束后的断点恢复。失败或取消不会替换现有会话，重新开始前先检查是否已经出现成功结果。

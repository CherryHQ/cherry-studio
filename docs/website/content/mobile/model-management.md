# 添加、编辑与管理模型

通常从服务商同步列表、选择常用模型即可。只有模型缺失、名称难辨认，或平台的实际能力与页面信息不一致时，才需要手动添加或编辑。

入口：**设置 → 模型服务 → 选择服务商 → 模型**。

## 手动添加一个模型

1. 在模型页点击添加按钮，进入手动添加页面。
2. 填写 **模型 ID（平台用来识别模型的准确名称）**，从平台文档或模型列表复制，不要自行翻译。
3. 填写显示名称，例如“日常问答”或“海报配图”。显示名称方便自己辨认，不会改变实际调用的模型。
4. 核对模型类型和接口；其他设置不确定时保留默认值。
5. 点击 **添加**。若是首次配置服务商，完成设置后回到模型服务列表，确认该服务商的开关已开启。

一次手动添加一个模型；需要批量添加时使用[模型同步](model-updates.md)。同一服务商下不能重复添加相同模型 ID。

## 查看与编辑

点击模型查看详情，可查看或复制模型 ID，并阅读能力、长度限制和价格等信息。点击详情页右上角的 **编辑** 进入设置；也可以长按列表中的模型，打开详情、编辑、选择或删除菜单。

模型编辑页采用**手动保存**：展开需要修改的设置，完成后点击 **保存**。如果保存失败，先处理提示中的字段，再重试；不要把退出页面当作保存。

现有模型的 **模型 ID 不能在编辑页修改**。填错时，按正确 ID 添加新模型，把智能体或默认模型切换到新条目后，再删除旧条目。

## 各项设置应该怎么理解？

| 设置 | 对使用有什么影响 | 不确定时怎么办 |
| --- | --- | --- |
| 显示名称、分组、备注 | 方便区分用途、整理列表 | 按自己的习惯填写 |
| 模型 ID | 决定平台实际调用哪个模型 | 使用平台提供的原值 |
| 模型类型 | 区分文字对话、图像生成等用途 | 按平台说明选择 |
| 接口 | 决定用哪种方式连接模型 | 保留自动或默认选择 |
| 推理 | 标记模型是否支持思考相关能力 | 使用模型默认信息 |
| 工具调用 | 标记模型能否调用搜索、日历或插件等工具 | 根据模型实际能力填写 |
| 支持的输入 | 标记图片、音频、视频等输入能力 | 不支持的能力不要勾选 |
| 流式输出 | 记录模型是否支持逐步返回回答 | 保留默认值；这个标记不会强制改变回答方式 |

**修改能力标记不会给模型增加新功能。** 例如，给纯文字模型勾选“图片”，并不能让它看懂照片；标记支持音频、视频，也不表示移动版已经可以发送所有这类附件。

“嵌入”“重排”是检索类模型的分类，可以保存和管理其信息，当前不能用它们进行普通聊天。只想问答时选择文本模型；想画图时选择图像生成模型。

## 上下文和输入、输出上限

**Token（模型计算内容长度的单位，不等于字数）**用于衡量文字、历史消息和其他材料占用的空间。

* **上下文窗口**：模型一次处理的内容总空间，历史对话、工具结果和新回答都可能占用它。
* **最大输入**：一次请求允许带入多少内容。
* **最大输出**：一次回答最多可以生成多少内容。

把数值调大不会突破服务商限制，反而可能让请求被拒绝。只有平台明确给出不同限制时再修改。填写正整数，并处理页面提示的限制冲突。

想恢复自动取值时，清空自己填写的长度上限并保存，即可重新采用模型目录或应用默认值。若长对话仍提示内容过多，可减少附件、缩短材料，或开启新对话。

## 模型价格与费用显示

价格设置用于用量和费用估算，**不会修改服务商账单**。

* 可选择美元或人民币，输入、输出价格的单位是 **每百万 Token**。
* 缓存读取、缓存写入是平台对重复内容采用的计价方式；按平台价格表填写，留空时按输入价格处理。
* 未知价格和免费不同。`0` 表示明确的零价格，不要为了消除空白把未知价格填成零。
* 某些平台对长输入使用阶梯价格。每档的起始输入量需要依次增大；达到某一档时，整次请求采用该档价格，并非只对超出部分加价。

没有可靠价格信息时保留默认值。用量页面的估算、缺失价格和服务商实际计费可能不同，详见[设置与用量](settings-and-usage.md)。

## 切换接口是否需要保存？

在模型管理列表中直接切换接口会立即保存；在模型**编辑页**选择接口只是修改草稿，需要点击保存。

“跟随默认”表示使用服务商当前的默认接口。如果服务商更改了默认接口，该模型也可能随之改变连接方式。遇到不可用提示时，检查服务商是否配置了对应接口，而不是反复修改模型名称。

## 删除与批量整理

长按模型进入选择模式，可选择当前筛选范围内的多个模型并删除。删除失败时选择会保留，可修正问题后再试。

* 被设为全局默认模型的条目不能直接删除，先到 **设置 → 默认模型** 更换或清除对应选择。
* 删除智能体正在使用的模型后，需要为相关智能体重新选择模型。
* 删除的是应用中的模型配置，不会关闭服务商账户，也不会取消已经发生的调用费用。

如果只是暂时不用某个平台，可以停用服务商，避免删除后重新配置。

模型信息如何跟随远端更新，见[模型信息与列表更新](model-updates.md)。

# 让 AI 使用工具

想让 AI 查一篇网页、读取日历，或把回答保存成文件，需要用到工具。工具负责取得资料或执行操作，模型再根据结果继续回答。你不需要记住工具名称，说明要处理什么、希望得到什么结果即可。

## 我想做的事，需要哪种工具？

| 你想做什么 | 需要准备什么 | 具体教程 |
| --- | --- | --- |
| 查资料、阅读网页 | 开启智能体的网络搜索，配置搜索与阅读服务 | [联网搜索与网页阅读](web-search.md) |
| 查日程、创建会议或整理待办 | 开启日历或提醒事项，并授予系统权限 | [日历与提醒事项](calendar-and-reminders.md) |
| 获取当前位置、汇总已记录的运动 | 开启对应设备能力并授权；健康记录仅限 iOS | [位置与健康记录](location-and-health.md) |
| 把内容保存为清单、表格或网页文件 | 选择支持工具调用的文字模型 | [生成与修改文件](file-generation.md) |
| 把 HTML 文件变成长图或 PPT | 打开已保存的 HTML 文件，使用分享菜单 | [HTML 转图片与 PPT](html-export.md) |
| 阅读或修改飞书、Notion 等服务中的资料 | 连接相应插件，账号能够访问目标资料 | [插件与外部工具](plugins.md) |
| 在文字对话中让 AI 画图 | 开启图片生成，并设置绘图模型 | [图片生成](image-generation.md) |
| 使用别人提供的远程工具服务 | 从插件页添加 MCP 服务器，在智能体工具区域开启 | [自定义工具配置](plugins.md) |
| 整理项目资料、移动或恢复文件 | 标准模式，明确文件和目标文件夹 | [文件库与工作区](file-library.md) |
| 复用一套任务方法 | 安装技能并为当前智能体启用 | [技能](skills.md) |

应用工具、插件和技能需要标准模式及支持工具调用的模型；模型自带联网的支持条件另见联网教程。只在模型编辑页勾选能力标记，不能让不支持的模型获得这项能力。

## 第一次使用，可以这样开始

1. 使用标准模式，在对话中选择支持工具调用的文字模型。
2. 打开当前智能体的编辑页，在 **系统** 区域开启这次需要的能力；文件读写没有单独的系统能力开关。
3. 使用插件时先连接账号；使用设备能力时按提示授权。开启智能体开关与授予系统权限是两件事。
4. 先提出一个明确的小任务，查看工具结果，再继续下一步。

例如，先发：

> 先列出手机中可写的日历，再读取明天的日程，按开始时间排序并标明所属日历。不要创建或修改任何内容。

等结果回来后，再发下面的请求，将“个人”替换为结果中实际可写的日历名称。没有可写日历时，先在系统日历中配置：

> 在刚才列出的“个人”日历里，明天北京时间下午三点到三点半创建“整理资料”。请告诉我是否保存成功。

这种分步提问有助于核对对象。希望执行前由 App 弹出审批时，还应把智能体的工具审批方式改为 **需要时确认**；文字里的“先确认”不能代替审批设置。

## 怎样把需求说清楚？

可以使用这个顺序：**资料在哪里 → 时间或内容范围 → 要做的事 → 输出形式 → 是否现在修改**。

* “阅读这篇飞书文档：[链接]。只整理第二部分，列出负责人、事项、截止日期；没有写的标为待确认。先不要创建任务。”
* “根据我上传的清单生成一个 CSV 表格文件，列为物品、数量、备注，保存为出行清单.csv。”
* “查上海人民广场到虹桥站的公共交通路线，列出换乘和预计时间。不需要获取手机位置。”

文件、网页、日历与插件可以在同一任务中配合，但各自都需要可用。能读到文档不代表可以创建任务，拿到当前位置也不代表已经接入路线查询服务。

## 为什么有些操作会询问，有些不会？

| 操作 | 使用“需要时确认”时 |
| --- | --- |
| 内置搜索、读取文件、读取已授权日历或位置资料 | 通常直接执行 |
| iOS 健康查询 | 每次确认，自动批准也不跳过，并显示数据接收方 |
| 移动、改名、移入回收站和恢复文件或文件夹 | 需要确认；自动批准模式可直接执行 |
| 内置创建或修改文本文件 | 直接执行，也不会因为选择该模式就逐次询问 |
| 创建、修改、删除系统日历或提醒事项 | 需要工具审批 |
| 插件与自定义工具 | 受工具规则控制，可能需要审批 |
| 通过文字模型调用图片生成工具 | 每次需要审批，“自动批准”模式下也一样 |

**自动批准**会自动通过符合条件的审批，仍不能越过账号权限或系统权限。当前新建智能体默认使用这个模式。详见[智能体与工具](agents-and-tools.md)。

## 计算和组合多个工具

可以让智能体进行日期、算术、统计和数据整理，并查看执行代码与结果。例如：“计算这个表格各分类的总额，再保存一份 CSV。”

Code Mode（用代码组合已授权工具的执行方式）可以把多个步骤串起来，但不会增加账号或系统权限。移动版的代码执行受限，不等于电脑终端，也不能运行技能包自带的脚本。需要修改智能体名称、说明等配置时，也可以在对话里提出具体要求并核对结果。

## 怎样知道任务真的完成了？

回答中的处理过程会显示工具操作。工具还在准备内容、等待批准，或者要求你到系统页面继续时，都不能当作已经完成。

* **读取成功**：核对资料来源和查询范围，再看总结；没有记录不一定代表不存在记录。
* **文件创建成功**：应能打开生成的文件卡片或在侧边栏的文件中找到它。只有代码块或“已生成”的文字，还不能证明文件已保存。
* **写入外部服务成功**：核对工具返回的结果，需要时到对应日历、文档或任务中查看。
* **部分失败**：先分清哪些已完成，哪些没有完成，只补做剩余部分。

## 卡住、拒绝或失败后怎么办？

| 现象 | 下一步 |
| --- | --- |
| 只用文字回答，没有调用工具 | 明确要求读取或保存；检查模型、能力开关和工具连接 |
| 等待你的确认 | 阅读操作对象与内容，再允许或拒绝；系统授权可能还需另行完成 |
| 权限不足 | 在系统设置或服务商中处理权限；反复改写提问不会增加权限 |
| 搜索、读取失败 | 根据提示检查网络、目标链接和账号，缩小范围后再试 |
| 写入超时，结果不确定 | 先到目标服务核对，避免重复创建日程、任务或内容 |
| Android 打开了系统日历 | 在日历页面核对并完成操作；打开页面不等于保存成功 |

停止回答、删除聊天或重新回答，都不会撤销已经完成的外部操作。工具取得的资料也可能交给模型处理，详见[数据、隐私与权限](data-privacy.md)。

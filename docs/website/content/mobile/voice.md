# 语音与音频转写

语音输入把你当下说的话变成消息草稿，音频转写处理已经保存的录音，朗读则把回答读出来。三者在 **设置 → 语音** 分别配置，不是把同一项“音频能力”开关打开就全部启用。

## 开启语音输入

语音输入默认关闭。在 **设置 → 语音 → 语音输入** 选择：

| 方式 | 需要准备 |
| --- | --- |
| 系统 | 设备可用的语音识别服务、识别语言及系统要求的权限；具体服务可能使用网络 |
| 离线 | 下载并校验 **SenseVoiceSmall** 模型，约 240 MB；实际大小以页面显示为准 |
| 关闭 | 输入框使用普通发送方式 |

下载时可看进度、取消或失败后重试。需要包含语音原生能力的新版安装包；仅收到代码更新不一定能启用新引擎。

## 在聊天里说一句话

1. 确认语音输入已启用。输入框没有待发送内容、没有正在生成的回复时，主操作位置会显示麦克风。
2. 点击开始，按提示授予麦克风和系统识别权限。
3. 说完点击停止，等待识别结束。
4. 检查识别文字，修改人名、数字和标点，再主动发送。

识别结果是草稿，不会因为开始或停止录音就自动提交给聊天模型。有文字或附件待发送、任务正在生成时，按钮会承担发送或停止任务的操作；不要把它当作固定的长按录音按钮。

## 转写已有音频

先在 **设置 → 语音 → 音频文件转写** 选择引擎与录音语言。离线方式需要已下载的 SenseVoice 模型；系统方式要求该设备和语言支持**离线文件识别**，不可用时不会悄悄回退到联网识别。

* 从 **文件** 导入录音，在音频条目的菜单选择转写，等待完成后打开保存的文字结果。
* 也可把音频通过 **＋ → 文件** 加入本机标准模式对话，明确要求转写或根据转写内容整理。
* 当前单个音频不超过 **100 MiB**，时长不超过 **2 小时**。具体编码仍需当前引擎能解码；修改扩展名不能转换格式。

音频附件保留在本机，模型获得用于转写的文件引用与转写后的文字，不代表模型直接具备听觉理解能力。把转写用于总结时，文字仍会发送给所选模型服务。

页面或任务取消会停止当前处理；没有完成时不要把部分识别内容当作完整录音。重要名称与数字应对照原音频核对。

## 朗读回答

在 **设置 → 语音 → 朗读** 选择可用的系统音色，再从已完成回答的操作区启动朗读，可停止当前播放。语音与语言取决于设备安装的服务和音色。

朗读可以在系统允许时继续到后台，但仍受音频、系统和进程限制；它与[后台生成](settings-and-usage.md)是不同的任务。

## 找不到麦克风或转写失败

检查语音输入是否仍为关闭、输入框是否已有待发送内容、是否正在生成，以及系统识别服务、权限、离线模型下载与语言支持。下载或校验失败时按设置页重试；错误并不表示应重新发送原来的聊天任务。

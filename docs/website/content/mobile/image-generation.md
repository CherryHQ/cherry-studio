# 图片生成

绘画功能用画板组织生成与编辑关系，绘画列表按画板展示拼贴封面。你可以从文字、参考图或模板开始，再选择某张结果继续修改。先配置图像生成模型；能理解图片的文字模型不一定能生成图片。

## 三种使用方式

| 方式 | 怎么开始 | 结果在哪里 |
| --- | --- | --- |
| 独立绘画 | 侧边栏打开 **绘画**，新建创作、选择照片或使用模板 | 画板中的生成结果，可从绘画列表再次打开 |
| 在对话中直接使用图片模型 | 为标准模式的智能体选择图像生成模型 | 当前对话的图片附件 |
| 让文字智能体调用绘图工具 | 在 **设置 → 默认模型** 选择绘图模型；不再需要智能体能力开关 | 当前对话的工具过程和图片 |

第三种方式在每次调用图片工具前要求确认，即使使用自动批准也一样。独立绘画和直接使用图片模型由你点击发送提交。下面的画板操作适用于独立绘画。

## 从一段描述开始

1. 从绘画入口打开新创作。
2. 在输入框的 **＋** 菜单中选择模型并调整生成参数。
3. 描述主体、用途、风格与构图，检查参考图后发送。
4. 等待结果，在大图中查看细节；失败时打开错误详情，再决定重试。

例如：

> 为读书笔记生成横向封面：木桌上有一本打开的书和一杯茶，清晨自然光，暖白和浅木色，左侧留白，不要文字。

首次生成会创建画板。画幅、尺寸、数量等参数由模型决定；更大的图片或更多结果可能增加费用和等待时间。输入框可以展开为大编辑器，适合修改较长描述。

## 用模板快速开始

模板支持按分类浏览。打开后检查示例、提示词变量和所需照片，按模板替换照片或修改变量，选择模型与参数，再点击生成。

现在模板面板可直接发起首次生成并打开新画板，不是只把提示词复制到聊天草稿。预览仍是效果示例，不是本次实际生成结果；发送前确认真正会使用的参考照片与描述。

## 在聚焦视图和画板总览间切换

* **聚焦视图**显示当前图片。双指或双击缩放；同次生成有多张图片时可横向切换。
* 从绘画列表打开画板会进入**总览**，从单张结果、文件库或通知进入则可聚焦该图；也可用顶部画板入口切换。
* 总览中点击节点先选中，再点击已选节点进入大图；点击空白取消选择。拖动与缩放查看关系。
* 图片下方的关系条展示来源、当前图片和后续结果；点击切换，长按可临时对比。
* 点击总览中的提示词说明，或从菜单打开生成信息，查看完整描述。画板名称可在总览中修改。

## 用参考图继续修改

聚焦的图片会成为下一次生成的参考。提交前检查输入框中的参考图；移除它表示这次不以该图继续。总览选中节点时以该图继续；点击空白取消选择后才从新的根分支开始。不要把“在总览输入”一概当作没有参考图。

> 保留这张图的构图和主体，把背景改成傍晚，其他部分尽量不变。

参考图和编辑是否可用取决于模型。只支持文字生图的模型不能因此获得图片编辑能力；需要参考图的模型必须先提供图片。不要把画板里的所有图片都当作下一次请求的输入。

### 用位置批注说明要改哪里

在大图上长按添加位置批注，选择批注后输入对应要求；切回整图可编辑整体要求。发送时，这些说明随参考图交给模型。

批注是位置和文字提示，**不是精确蒙版**，不能保证模型只改变标记区域。先描述要保留的内容，再检查结果。

支持的模型会提供比例快捷项。选择比例只准备参数或修改要求，不会立即发送；确认输入后仍需主动提交。

## 失败、取消和重复提交

生成期间可以继续浏览画板。查看任务状态再决定下一步；失败结果提供重试、错误详情及适用的[问题诊断](diagnostics.md)，之前成功的结果仍可继续使用。停止正在生成的任务会移除该次生成占位。

取消不保证服务商没有处理请求，也不保证退费。模型不支持、参考图不符、余额不足、限流与网络错误应分别处理。

## 保存与分享

从当前图片的菜单保存、分享或查看信息。生成多图时可分享整组，总览可分享画板中已完成的输出，绘画列表也支持批量选择。引用输入与画板连接关系不作为成果一起导出；选择分享图片不会改变当前画板焦点。

支持的 GIF 结果可在预览、保存和原文件分享中保留动画；GPT Image 2.6 新图默认请求 GIF，仍可按支持的参数指定格式。聊天卡片不代替动画原文件。

保存相册时按系统提示处理权限。删除一个绘画版本与删除文件库中的文件是不同操作，文件和回收站规则见[文件库与共享工作区](file-library.md)。

在 **设置 → 通用设置 → 分享水印** 调整后续对外分享；本机保存使用无水印成果。聊天中的图片可随所选问答一起导出，详见[分享与导出](sharing-and-export.md)。

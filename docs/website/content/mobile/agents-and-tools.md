# 智能体与工具

智能体保存名称、头像、指令、默认模型和工具审批方式。把常用的工作要求写进智能体，再为不同话题分别新建对话；具体文件和本次需求放在消息里。

标准模式下，应用根据模型、设备、系统权限和服务配置提供可用的内置工具。技能与自定义 MCP 需分别添加到智能体。

## 创建一个常用智能体

1. 从侧边栏打开 **智能体**，点击添加；也可以从对话顶部的智能体选择器新建。
2. 填写名称、选择头像，点击指令区域的 **编辑**，写清工作要求，完成后返回表单。
3. 选择模式和默认模型。文件、技能、插件与设备工具需要 **标准** 模式及支持工具调用的文字模型。
4. 选择工具审批方式，按需 **添加 MCP**。新建后可继续在编辑器中 **添加技能**。
5. 点击 **保存**。从对话选择器创建会进入新对话，从管理列表创建会返回列表。

例如：

> 你帮我整理工作材料。先用三句话概括，再列待办。没有明确的负责人与截止时间时写“待确认”，不要自行编造。回答使用中文。

不要把 API Key（调用模型服务的密钥）或账号密码放进指令。

## 修改后需要点保存吗？

在聊天顶部点击**当前智能体名称**，即可直接打开编辑面板，不必离开对话；管理列表也可进入同一套编辑器。

**新建需要保存，编辑已有智能体会自动保存。** 名称和指令在停止输入后保存，头像、模型、审批方式和绑定按各自操作保存。指令面板中的“完成”返回编辑器；新建表单仍需最后保存。出现保存失败提示时，保留草稿并重试。

未选择模型也能保存智能体，但需要选择可用模型后才能聊天。指令区域只显示摘要，修改完整内容请点 **编辑**。

## 标准模式与极简模式

| 模式 | 适合什么 | 能力范围 |
| --- | --- | --- |
| 标准 | 处理文件、使用技能、插件与设备工具 | 可用的应用工具与模型联网能力 |
| 极简 | 文字问答、图片理解 | 不使用应用工具、技能或插件；支持时可用模型自带联网 |

切换模式会保留技能、MCP 和审批配置，回到标准模式后继续使用。极简模式缺少这些工具时，重新授权账号并不能扩展它的范围。

## “需要时确认”和“自动批准”有什么区别？

| 方式 | 实际行为 |
| --- | --- |
| 需要时确认 | 按工具规则询问；部分读取及文件创建、编辑可直接进行 |
| 自动批准 | 自动通过符合条件的审批，仍受系统权限、工具配置和资料范围限制 |

新建智能体默认 **自动批准**，已有智能体保留原设置。希望日历写入或外部服务改动先审批时，选择 **需要时确认**。

通过文字模型调用的**图片生成工具**和**健康记录读取**仍保留单独确认，不会被自动批准跳过。SSH 也有独立审批与有限的诊断授权，见 [SSH](ssh.md)。

阅读待审批的对象、操作和数据接收方，再选择允许或拒绝。系统授权可能随后出现，它与工具审批是两件事。停止回复、删除记录或切换模式不会撤销已经完成的外部操作。

## 手机能提供哪些系统工具？

现在不需要为每个智能体逐项开启内置能力。应用会在开始新请求时检查模型、平台、可请求或已有的系统权限，以及绘图、联网等服务配置；无法满足条件的工具可能不会提供给模型。

| 能力 | 可以怎样提问 | 可用范围 |
| --- | --- | --- |
| 日历 | “列出我明天的日程” | iOS、Android，受读写权限与系统支持限制 |
| 提醒事项 | “明天上午九点提醒我寄快递” | iOS；Android 当前不提供 |
| 健康记录 | “汇总本周已记录的步数和运动” | iOS，按实际支持和授权的数据类型读取 |
| 当前位置 | “获取我的位置，再查附近的地铁站” | iOS、Android，需要定位权限 |
| 应用内文件 | “将总结保存为文件” | 当前对话可访问的附件、生成文件和工作区资料 |

在 **设置 → 系统权限** 管理系统授权。撤销权限应到对应的系统设置；旧版的智能体开关已不能用于停用某项设备能力。Android 某些日历操作需要在系统表单里完成，打开表单不代表已保存。

本机工具不能随意扫描所有手机文件或接管其他 App。[电脑智能体](remote-chat.md)、[远程桌面](remote-desktop.md)和 [SSH](ssh.md) 是各自独立的连接方式。

## 联网、插件和自定义工具从哪里配置？

* **联网**：在 **插件 → 内置工具 → 网络搜索 / 网页读取** 配置来源与服务，见[联网教程](web-search.md)。
* **插件**：在插件页连接飞书、Notion 等账号；可通过 **＋ → 插件** 指定本次使用，见[插件教程](plugins.md)。
* **MCP（连接远程工具服务的协议）**：在插件页配置、启用服务器，再在编辑器中 **添加 MCP**；移除绑定不等于删除服务器。
* **技能**：先安装，再在编辑器中 **添加技能**；移除绑定不会卸载技能，见[技能教程](skills.md)。
* **绘图工具**：在 **设置 → 默认模型** 选择绘图模型；支持工具调用的标准模式文字模型可按需调用。也可直接选择图片模型，见[图片生成](image-generation.md)。

组织管理的智能体可能有锁定或隐藏字段、指定模型及固定技能/MCP。由组织提供的配置应到组织端修改；可用的本机编辑项以页面为准，见[账号与组织空间](accounts-and-organizations.md)。

## 为什么已经授权，智能体仍然不会使用工具？

依次检查标准模式、模型工具调用能力、服务连接、MCP 的全局启用与智能体绑定、系统权限，以及组织策略。账号能登录，不代表能访问某个具体文档或执行所有操作。

给出明确目标，例如文档链接、日期范围或文件名。可以先让它读取并列出对象，核对后再要求修改。完整的执行、审批和失败处理见[让 AI 使用工具](using-tools.md)。

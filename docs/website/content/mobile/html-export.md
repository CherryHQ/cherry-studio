# HTML 转图片与 PPT

保存好的 HTML 网页可转换为图片或图片式 PPT。它适合保留信息卡、方案或演示页的外观；需要可逐项编辑的 Word、Excel、PowerPoint 时，使用[原生文档生成](file-generation.md)。

## 先准备一个 HTML 文件

可以上传文件，也可以在标准模式中要求支持工具调用的模型创建：

> 把项目介绍做成独立 HTML 演示稿，三页分别介绍目标、计划、下一步。每页 16:9、字号便于阅读，不依赖网络图片或字体。保存为“项目介绍.html”，每页使用 class="slide" 的独立容器。

只有聊天代码块时，先要求实际保存成文件。等待完成，打开返回的文件卡片，或从 **文件** 打开它。

## 分享成长图或 PPT

1. 打开 HTML 的**文件预览**，检查文字、图片和完整性。
2. 点击分享，进入共同预览面板。
3. 可转换的 HTML 提供 **原始文件 / 图片 / PPT**，在这里选择目标格式；不再寻找旧版更多菜单里的两个独立转换项。
4. 等待转换并检查预览；失败后在当前格式重试，或主动改选其他格式。
5. 明确选择 **保存** 或 **分享**，再核对相册、文件库或接收应用中的结果。

**文件库列表的分享只分享原文件，不提供转换选项。** 需要转换时先点开文件预览再分享。

转换结果先是临时成果：图片的保存进入相册，PPT 的保存进入文件库；仅点击分享不会自动永久保留到库里。关闭面板可以清理临时转换，原 HTML 保留。系统分享面板打开不等于已成功保存或发出。

## 两种格式有什么区别？

| 格式 | 用途 | 输出特点 |
| --- | --- | --- |
| 图片（PNG） | 展示信息卡或长页面 | 按 HTML 转换规则捕获页面，仍有尺寸限制 |
| PPT（PPTX） | 按页展示 | 页面画面放入 16:9 幻灯片，文字和图表不作为独立可编辑对象 |

明确页面标记可用于逐页转换；普通长页面可能按高度切页，截断段落或表格，并不会自动重新设计。比例不一致时保留比例并留白。转换的较宽布局也可能与手机窄屏预览不同。

聊天问答的图片卡片使用另一套高度限制，不要把[聊天分享](sharing-and-export.md)的规则套到 HTML 文件转换上。

## 水印和文件里的交互会保留吗？

对外分享的转换成果遵循 **设置 → 通用设置 → 分享水印**；明确点 **保存** 时使用无水印版本。已经保存的文件不会因之后修改水印开关而重做。

转换读取已保存的 HTML，不复制你在预览中临时展开、点击或填写后的状态。动画、视频也不会成为可播放的 PPT 内容。要保留某种状态，先把它保存成页面静态内容再转换。

## 为什么看不到转换入口，或转换失败？

* 从文件库直接分享：先打开 HTML 预览，再进入分享面板。
* 不是 HTML、内容为空或仅加载部分：提供完整文件，精简或拆分后再试。
* 外部图片或字体不可达：改用可访问的资源，或制作独立文件。
* 页面太多或图片过大：PPT 最多 64 页，图片也有尺寸限制；拆分材料。
* 动态布局或后台中断：保持前台，改用稳定的静态页面。

失败不会自动把图片改成其他格式。处理原因后重试，并在接收软件中核对页数、文字和图片；原 HTML 可继续修改。

# 下载与安装

请始终从[官方下载页的移动端选项](https://cherryai.com.cn/download?platform=mobile)获取安装入口，不要安装来源不明的安装包。

## Android

国内站默认提供 **APK** 下载，安装包来自 GitCode。当前 APK 适用于 ARM64 设备。

1. 在下载页 Android 一栏，扫描 **APK** 二维码或选择下载按钮。
2. 下载完成后，从浏览器下载记录或文件管理器打开 APK。
3. 如果系统阻止安装，按提示临时允许当前浏览器或文件管理器“安装未知应用”。
4. 返回安装界面并完成安装。

安装完成后，可以关闭刚才授予的“安装未知应用”权限。新版本发布时，重新从官方下载页获取 APK 并覆盖安装；升级前请先查看版本说明。

### 其他方式：Google Play

可使用 [Google Play](https://play.google.com/store/apps/details?id=com.cherryai.cherrystudio_app) 的用户，也可以在 Android 一栏切换到 **Google Play** 安装，后续更新由商店管理。

[国际站](https://cherryai.com/download?platform=mobile)默认推荐 Google Play，其备用 APK 下载来自 GitHub。

## iPhone 与 iPad

推荐从[国区 App Store](https://apps.apple.com/cn/app/cherry-studio-%E5%85%A8%E8%83%BD-ai-%E5%B7%A5%E4%BD%9C%E7%AB%99/id6809783714) 安装 Cherry Studio，支持 iOS / iPadOS 17.0 及以上版本。国内站链接指向中国大陆商店，国际站保留美区商店链接。

1. 在移动版下载页的 iPhone / iPad 一栏，扫描二维码或选择 **App Store** 按钮。
2. 在 App Store 中选择 **获取** 并完成安装。

### 其他方式：TestFlight 测试版

希望体验测试版时，可在下载页 iPhone / iPad 一栏切换到 **TestFlight**。

1. 从 App Store 安装 Apple 的 **TestFlight**。
2. 在移动版下载页 iPhone / iPad 一栏切换到 **TestFlight**，扫描二维码或选择按钮打开邀请。
3. 在 TestFlight 中接受邀请并选择 **安装**。

TestFlight 名额和测试版本有效期由 Apple 的测试机制管理。如果邀请暂时不可用，请稍后重试或关注官方发布渠道。

## 更新与版本差异

本组教程按 0.3.0 整理。先在 **设置 → 关于** 查看已安装版本；Google Play、App Store、APK 与 TestFlight 的可用版本取决于各自发布进度，不一定同时更新。

APK 渠道可按应用的更新提示或官方下载入口获取新包；商店安装按对应商店更新。兼容的代码与资源更新可以在后台下载，并在之后一次启动时生效，但涉及原生能力变化时仍需安装新版 App。0.3.0 的健康等原生能力不能只靠旧安装包接收代码更新启用。

更新或换机前建议先创建[完整备份](backup-and-restore.md)。恢复备份与覆盖安装是不同操作，不要为更新而先卸载当前 App。

## 安装后

首次打开应用后，继续阅读[快速开始](quick-start.md)，添加模型服务并发送第一条消息。

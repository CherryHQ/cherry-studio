# 在手机使用电脑智能体

配对兼容的 Cherry Studio 桌面端后，可以在手机查看电脑上的智能体会话、发送任务、回答追问并处理工具审批。**任务在电脑执行，手机是操作入口。** 本文按移动版 **0.3.0** 整理；实际能力还取决于桌面端版本。

这与[导入模型配置](desktop-sync.md)不同：配置导入后由手机调用模型；远程对话使用电脑上的智能体、模型、工具和工作区。远程聊天不会把电脑历史合并进本机聊天。

## 连接并选择电脑

1. 保持桌面端运行，让手机与电脑处于可互相访问的网络。首次连接优先使用同一局域网。
2. 在电脑的 **设备互联** 中显示配对二维码。
3. 手机打开 **设置 → 设备互联**，扫描二维码或使用页面提供的手动输入方式。
4. 按两端提示完成配对，并确认已允许访问电脑智能体。只有配置同步权限时，不能据此访问远程会话。
5. 打开手机侧边栏，从顶部的设备选择入口切换到这台电脑。

出现升级提示时先更新桌面端。电脑休眠、退出应用、网络隔离或权限被撤销，都可能导致无法访问。

## 开始或继续一个任务

1. 选择电脑上的智能体，打开已有会话，或新建会话。
2. 新建时选择电脑提供的工作区；只有桌面端支持时，才会出现 **PC 默认工作区**。
3. 输入明确任务，例如“阅读这个工作区的项目说明，整理待办事项，先不要修改文件”。
4. 查看回复、工具结果和状态。需要批准操作或补充信息时，在手机上处理对应请求。

智能体及其模型、工具、工作区由电脑配置。手机切回 **本机** 后使用本机自己的智能体和资料。移动版的文件夹工作区见[文件库与共享工作区](file-library.md)，两者不是同一个文件目录。

## 发送图片和文件

在支持附件的远程会话中，使用输入框旁的 **＋** 添加图片或文件，再填写需求。也可以只发送文件。

* 当前远程传输每条消息最多 8 个文件，单文件最高 1 GB，合计最高 2 GB。
* 查看附件的准备、上传和完成状态；可以取消、在失败后重试，或在重连后继续上传。应用重开后可恢复符合条件的上传。
* 文件上传完成不代表模型已经读懂它。电脑端的模型能力、文档解析和工作区权限仍会影响处理结果。
* 没有附件入口时，先检查桌面端版本和它提供的能力。

上述是远程传输限制，本机聊天的图片、文本与文档限制见[对话与文件](chat-and-files.md)。

## 断线、切到后台或发送失败

**手机断开连接不会自动停止电脑上已经开始的任务。** 返回前台后，应用会尝试重新连接并读取最新状态。需要停止时，应使用会话中的停止操作并确认结果。

遇到未发送消息，先阅读状态和原因，再选择重新发送或放弃。结果尚不确定时，先恢复连接并查看电脑端，避免重复执行可能已开始的任务。

| 现象 | 处理方式 |
| --- | --- |
| 找不到电脑或连接失败 | 检查电脑是否运行、地址是否可达、局域网权限、防火墙与代理；按设备详情中的检查或地址指引处理 |
| 配对信息需要更新 | 扫描电脑当前的二维码重新配对 |
| 能同步配置，却看不到智能体 | 检查电脑是否支持远程智能体，以及是否已授予对应访问权限 |
| 电脑没有智能体或模型不可用 | 到桌面端创建或配置智能体并选择可用模型 |
| 审批已处理，手机仍显示旧状态 | 等待重新同步；不要对同一操作重复提交 |

远程连接不是云端备份。手机的[完整备份](backup-and-restore.md)不替代电脑数据备份；撤销访问时，在电脑的设备互联中移除手机授权。

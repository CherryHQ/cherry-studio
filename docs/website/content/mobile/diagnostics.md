# 错误检查与 AI 诊断

聊天或绘画失败时，可以先检查本次配置与连接，再决定是否用另一个模型分析。**本机检查、AI 分析和提交反馈是三个独立动作**，打开错误详情不会直接同意让 AI 分析或上传反馈。

## 先看错误与检查结果

1. 从失败的聊天回复或绘画结果打开错误详情，选择 **排查问题**。
2. 等待模型配置、服务连接、任务运行与应用数据等检查。
3. 展开 **检查依据**，查看哪些通过、哪些异常、哪些未能完成。
4. 有设置入口时，按具体原因处理；配置改变后重新检查。

“地址可达”只说明地址能够响应，不能证明密钥有效、模型调用成功或图片已生成。运行与数据检查也只覆盖本次相关状态，不是完整数据库验收。

电脑端执行的任务，手机只能检查自己可见的连接与信息；应结合[远程聊天](remote-chat.md)的电脑状态处理。

## 主动开始 AI 分析

1. 在检查页选择 **使用 AI 分析**。
2. 选择一个可用、支持工具调用的文字模型。当前故障影响的模型可能不可选，应选另一个可用模型。
3. 阅读发送范围与费用说明，再点击 **开始分析**。
4. 查看分析结论、建议和对应依据；检查状态与后续 AI 读取的事实可能来自不同时刻，应分别核对。

发送范围包括脱敏错误、相关配置、检查结果和技术日志摘要；不包含模型密钥、聊天正文或附件内容。调用会发送给所选模型服务，可能产生费用。模型给出的原因是分析建议，不能替代实际修复后重新执行所需的操作。

取消、关闭页面或离开来源会停止当前诊断。超时、配置变化或分析模型不可用时，按提示重新检查或更换模型；不要把未完成结果当成已诊断成功。

## 提交反馈与查看进度

需要继续处理时，可在诊断页 **反馈问题**，或到 **设置 → 关于我们 → 意见反馈**。核对关联诊断、描述和自选截图后再提交。

反馈附带的检查摘要与 AI 分析不是同一份完整对话；不要手动附上密钥、私有下载链接或完整备份。提交成功后保留报告 ID，并在反馈记录查看处理进度。删除本机记录不会撤回已经提交的报告。

常见状态码、权限与附件问题见[常见问题](troubleshooting.md)。

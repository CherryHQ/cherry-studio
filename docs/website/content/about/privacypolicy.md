# 隐私政策

## Cherry Studio 隐私政策

**更新日期：** 2026 年 11 月 26 日

**生效日期：** 2026 年 11 月 26 日

欢迎使用 Cherry Studio（以下简称"本软件"或"我们"）。我们高度重视您的隐私保护，本隐私政策将说明我们如何处理与保护您的个人信息和数据。请在使用本软件前仔细阅读并理解本政策。

### 一、我们收集的信息范围

为了保障软件正常运行、优化用户体验和提升产品质量，我们会分类收集以下运行与使用信息。这些信息不包含您的对话内容、API Key、知识库内容以及您输入的文字。您可以随时关闭这些信息的收集，具体方式见下文说明。

#### （一）基础运行信息

此类信息用于保障软件基础功能正常运行、安全性及版本兼容性。您接受当前版本的隐私政策后，数据收集默认开启。您可随时关闭。收集范围如下：

1. 软件与设备信息：软件版本、操作系统类型与版本、本设备随机生成的标识、IP 地址，用于版本兼容性判断、安全更新推送、运行环境适配及服务安全保障；
2. 运行状态信息：记录应用启动和更新事件，用于统计软件使用活跃度。

#### （二）产品改进信息

为持续改进产品体验，我们会在上述条件下收集以下信息：

1. 功能使用情况：各项功能的使用次数、结果（成功或失败及失败类型）和耗时，包括页面浏览及停留时长、点击、快捷键使用、设置项变更等界面交互（文字类设置仅记录是否修改，不记录具体内容）；
2. 模型使用情况：所用模型服务的类型、模型名称和 Token 用量；
3. 错误日志与崩溃信息：软件运行过程中发生的错误日志、崩溃堆栈信息等，用于问题排查与稳定性提升。发生原生崩溃时，诊断报告还可能附带崩溃转储文件。

上述信息不涉及您的对话内容、API Key、知识库内容或您输入的文字。

**关闭方式：** 您可随时通过【设置】-【数据】-【隐私设置】中的开关关闭上述信息的收集，不影响软件核心功能的正常使用。

#### （三）登录账号后的信息关联

本软件的基础功能无需登录即可使用。当您选择登录 Cherry Studio 账号后，上述信息会与您的账号标识关联；登录前在本设备上产生的相关记录也可能与该账号关联，以便更好地为您提供服务。退出登录后，新产生的信息不再与账号关联。账号体系下的个人信息处理见《Cherry Studio 隐私政策》（账号体系版）。

#### （四）信息的存储地点和期限

我们在中华人民共和国境内收集和产生的个人信息，原则上存储于中华人民共和国境内。如涉及向境外提供个人信息，我们将按照法律法规的要求履行相应程序。

我们仅在为实现本政策所述处理目的所必需的最短时间内保存您的个人信息，法律法规另有规定的除外。其中，设备标识、IP 地址等基础运行信息，以及运行状态日志、错误与崩溃信息及产品改进信息的保存期限为自收集之日起 6 个月，期限届满后删除或匿名化处理；经匿名化处理、无法识别特定自然人且不能复原的统计数据，可长期用于统计分析。法律、行政法规规定必须留存的记录，按照法定期间保存。

保存期限届满或您撤回同意的，我们将删除或匿名化您的个人信息；法律、行政法规规定的保存期限未届满的，我们仅予存储并采取必要的安全保护措施，不再用于其他目的，法定期间届满后及时删除或匿名化处理。

#### （五）我们的承诺

无论是基础运行信息还是产品改进信息，我们均承诺：

- 未登录时，上述信息仅与本设备随机生成的标识、IP 地址等设备信息关联，不与您的姓名、手机号、邮箱等个人身份信息关联；登录后，仅按本条（三）所述与您的账号关联；
- 不会用于用户画像、广告推送，也不会出售或以其他方式向第三方提供（法律法规强制要求或为本政策所述目的委托服务商处理的情形除外）；
- 不会包含您的对话内容、API Key、知识库内容等任何敏感数据（详见第二条）。

### 二、我们明确不会收集的信息

为了最大限度保护您的隐私和信息安全，在您使用本软件本地功能（无论是否注册账号），或使用自行配置的第三方模型服务时，我们明确承诺，不会收集、保存、传输或处理以下数据：

- **您的 API Key：** 您输入到本软件中的模型服务 API Key 信息；
- **您的对话数据：** 您在使用本软件过程中产生的任何对话数据，包括但不限于聊天内容、指令信息、知识库信息、向量数据及其他自定义内容（您使用自行配置的第三方模型服务时，相关数据由您的设备直接发送至该第三方，我们不收集、不存储；您注册并登录账号后使用我们提供的模型服务时，相关数据处理规则以账号体系隐私政策为准）；
- **个人身份信息与敏感个人信息：** 您的姓名、手机号、邮箱、身份证件号码等可直接识别您个人身份的信息，以及法律法规规定的敏感个人信息（本政策第一条所述设备标识、IP 地址、使用信息及账号标识除外）。

当您主动提交问题报告时，如报告提供「附带对话记录」选项，仅在您勾选该选项并提交后，报告才会附带本次反馈所选对话的记录。

### 三、本地存储与数据交互说明

**数据本地化：** 您的本地配置、API Key 及本地历史记录等数据均默认存储在您的本地设备中，不会上传至我们的服务器；但您主动提交问题报告并选择附带对话记录时，相关对话记录将随报告一并上传。Cherry Studio 提供的模型服务如何处理对话数据，见第四条。

**直接调用：** 当您使用自行配置的第三方模型服务时，本软件作为本地工具提供与第三方模型服务的接口调用功能。您的终端设备将直接与您配置的第三方模型提供商（如 OpenAI、Anthropic 等）的服务器建立网络连接，相关数据不经由我们的服务器中转。

**内容合规义务：** 无论您使用第四条所述内置模型服务，还是使用自行配置的第三方模型服务，您均不得利用本软件制作、复制、发布、传播任何违反中华人民共和国或您所在国家/地区适用法律法规、危害国家安全、损害国家荣誉和利益、破坏民族团结、散布谣言、扰乱社会秩序、宣扬淫秽色情、暴力、侵害他人合法权益等违法或不良信息。

### 四、内置模型服务

您登录 Cherry Studio 账号后，可使用内置模型（Cherry Cloud 模型）等服务，当您使用 Cherry Cloud 模型时，我们会保存相关对话正文，留存用途、期限及用户权利见《Cherry Studio 隐私政策》（账号体系版）。

### 五、第三方模型服务提供商隐私政策声明

当您使用自行申请并配置的第三方模型服务提供商的 API Key 进行 AI 对话时，实际上是直接接受该第三方模型服务提供商的服务：

您需自行承担使用第三方模型服务提供商所涉及的隐私与合规风险。

各模型提供商（如大模型厂商）会依据其自身的隐私政策、数据安全措施等，处理您主动输入的数据（如对话内容），并可能在其服务范围内独立采集其他相关数据。上述处理与采集行为均不受本软件控制，本软件【隐私设置】中的开关亦无法关闭此类行为。

如您希望了解或关闭相关数据处理与采集行为，请查阅所选模型服务提供商官方网站的隐私政策，并向其寻求关闭方法。我们对此不承担任何责任。

### 六、关于第三方服务的特别说明

为方便您管理、处理数据，在本软件的【设置】-【数据】中，我们支持包括但不限于以下第三方服务功能，由您通过输入 API 地址、用户名、密码等方式自行选择配置并使用这些服务：

# 输入工具栏与效率工具



<details>

<summary>为什么工具固定后在另一个输入区没有出现？</summary>

Chat、智能体、快捷助手和绘画页面支持的工具不同，Chat 与智能体的固定布局也分别保存。请在目标输入区重新打开【自定义工具栏】。

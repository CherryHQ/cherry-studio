# 功能介绍

Cherry Studio 是一款桌面级 AI 客户端，集成了 **对话助手、智能体、绘画、翻译、知识库、笔记、文件管理、编码搭档** 等核心能力，并通过 [API 网关](../../advanced-basic/developer-tools/api-gateway.md)、[频道](../../advanced-basic/automation/channels.md)、[定时任务](../../advanced-basic/automation/scheduled-heartbeat.md) 把 AI 能力延伸到自动化与跨平台场景。

下表是本节涉及的主要功能与对应入口：

| 功能 | 简述 | 入口 |
| --------------------------------------- | ------------------------------------- | ------------ |
| [对话](chat.md) | 创建 [对话助手](chat.md#助手库)，与不同模型对话，并调用知识库 | 【启动台】→【对话】 |
| [工作](../../advanced-basic/agent.md) | 工作即智能体，可自主执行任务 —— 读文件、跑命令、多步推理 | 【启动台】→【工作】 |
| [绘画](drawing.md) | 接入文生图模型 | 【启动台】→【绘画】 |
| [翻译](translation.md) | 双栏快速翻译 | 【启动台】→【翻译】 |
| [小程序](../../cherry-studio/preview/app/) | 运行常用网站，或安装可调用 Cherry AI 的本地小程序 | 【启动台】→【小程序】 |
| [知识库](knowledge-base.md) | 文档/网址/笔记向量化检索 | 【启动台】→【知识库】 |
| [文件](files.md) | 集中查看对话、绘画、知识库等附件 | 【启动台】→【文件】 |
| [编码搭档](code-cli.md) | 安装、配置并启动 AI 编程 CLI 工具 | 【启动台】→【编码搭档】 |
| [笔记](notes.md) | 内置 Markdown 笔记本，随手记录、整理，可导出到知识库 | 【启动台】→【笔记】 |
| [快捷助手](quick-assistant.md) | 全局快捷键唤起的迷你提问窗口 | 全局快捷键 |
| [划词助手](selection-assistant.md) | 在任意应用划词后通过浮动工具栏调用 AI | 划词后浮动工具栏 |

更高阶能力请参考 [进阶教程](../../advanced-basic/capability-map.md) 一节。

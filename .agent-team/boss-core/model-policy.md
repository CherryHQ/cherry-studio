# Model selection

Tiers describe intended task complexity, not benchmarks. Hard: lead, product, UX, runtime, data, security and verifier. Medium: renderer, desktop and providers. Mechanical follow-ups may use a lower tier through explicit task policy, without changing the assigned ownership or acceptance criteria.

| Harness | Binding | Limits |
| --- | --- | --- |
| Codex | hard gpt-6-astra/high; medium gpt-5.6-terra/high | IDs/efforts observed in installed host catalog during UAR research; inference not tested by installation |
| Claude Code | hard opus/high; medium sonnet/high | native aliases, account entitlement remains runtime-dependent |
| Kimi Code | launcher selects configured kimi-code/k3 unless overridden | role model frontmatter unsupported; secondary model pool follows native settings |
| OpenCode | inherit active configured provider/model | catalog visibility does not establish credentials; choose explicit provider/model only after discovery |
| MiniMax CLI | inherit isolated native provider/model | mcode 0.5.4 installed; launcher CLI verified, custom-role execution and provider readiness unverified; MiniMax-M3 gateway alias is not a native provider/model identifier |

Use agent-team-models before actual task invocation. Recheck configured IDs; do not silently substitute an unavailable model or guess vision/tool capabilities. A UX visual task requires actual image capability plus a browser/image tool; otherwise hand off or mark visual acceptance incomplete. Do not infer quality from naming. No prices or budgets are invented: local gateway discovery attempted during this setup returned transport_unavailable_or_redirect_refused. Same-day UAR discovery is historical evidence, not present availability. Optional services are not required to read/use local definitions.

For independent review choose a fresh-context different-family judge when configured (for example a verified MiniMax-M3 gateway alias). Record actual producer/judge. Native same-family fallback is weaker. When no independent review completes, record pending review, never a pass. Do not persist credentials. Native permissions and model invocation controls are separate from this manifest.

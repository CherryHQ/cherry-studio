Cherry Studio 隐私政策

欢迎使用上海千彗科技有限公司（以下简称“我们”）提供的 Cherry Studio（以下简称“本软件”）。本隐私政策说明我们如何处理与保护您的个人信息。您可通过第九条所列联系方式提出查阅、复制、更正、补充、删除、限制处理个人信息等请求。账号注销见《Cherry Studio 隐私政策》（账号体系版）。

一、我们收集的信息范围

为了解软件运行情况和改进产品体验，我们会收集以下运行与使用信息。自动上报的范围和关闭方式见下文。

（一）基础运行信息

您同意当前版本的隐私政策后，运行与使用信息的收集默认开启。您可随时关闭。基础运行信息包括：

  • 软件与设备信息：软件版本、操作系统类型与版本、设备架构、本设备随机生成的客户端标识。接收统计请求的服务端可从网络连接获取 IP 地址，用于统计和服务安全保障。
  • 运行状态信息：记录应用启动和更新事件，用于统计软件使用活跃度。

（二）产品改进信息

为持续改进产品体验，我们会在上述条件下收集以下信息：

  • 功能使用情况：订阅等功能入口的展示、点击、来源及相关操作结果，用于了解功能使用情况和改善体验。
  • 模型使用情况：所用模型服务的类型、模型名称和 Token 用量；
  • 错误日志与崩溃信息：软件运行过程中的错误类型、错误日志及堆栈信息，用于问题排查与稳定性改进。发生原生崩溃时，错误报告还可能附带崩溃转储文件，其中可能包含进程内存中的数据。

常规使用统计不收集对话正文、API Key、知识库内容或您输入的文字。

关闭方式：您可随时通过【设置】-【数据】-【隐私设置】中的开关关闭上述信息的收集，不影响软件核心功能的正常使用。

（三）登录账号后的信息关联

本软件的基础功能无需登录即可使用。应用启动、更新、模型用量统计及错误报告使用随机生成的客户端标识。当您登录 Cherry Studio 账号后，部分订阅相关事件可能与账号标识关联，用于分析订阅流程和改进体验。账号体系下的个人信息处理见《Cherry Studio 隐私政策》（账号体系版）。

（四）我们的承诺

我们不会将基础运行信息和产品改进信息用于用户画像或广告推送，也不会出售或向第三方提供此类信息，法律法规强制要求或为本政策所述目的委托服务商处理的情形除外。

二、本地功能、自行配置的模型与问题报告

您使用本地功能或自行配置的第三方模型服务时，以下说明适用于相应数据。

  • 您的 API Key：您自行配置的第三方模型服务 API Key 保存在本地设备。调用该服务时，客户端按服务商的认证方式使用该凭证。
  • 您的对话数据：本地对话数据（如聊天内容、指令、知识库信息、向量数据及其他自定义内容）默认存储在本地设备。调用自行配置的第三方模型时，推理所需的数据由您的设备发送至该服务商。Cherry Studio 提供的模型服务和您主动提交的问题报告，分别按第四条和下文处理。

当您主动提交问题报告时，我们会为排查您反馈的问题接收诊断包。诊断包可能包含软件及设备环境信息、所选时段内的日志和追踪记录，其中可能含有未经脱敏的信息。如界面提供「附带对话记录」选项，该选项默认关闭，您勾选并确认提交后，报告才会另外附带所选对话记录。

三、本地存储与数据交互说明

数据本地化：您的本地配置、API Key 及本地历史记录等数据默认存储在您的本地设备中。主动提交问题报告、使用模型服务或配置第三方备份与连接时，相关数据按第二条、第四条、第六条及本条下述说明处理。

直接调用：当您使用自行配置的第三方模型服务时，本软件作为本地工具提供与第三方模型服务的接口调用功能。您的终端设备将直接与您配置的第三方模型提供商（如 OpenAI、Anthropic 等）的服务器建立网络连接，相关数据不经由我们的服务器中转。

内容合规义务：无论您使用第四条所述 Cherry Studio 提供的模型服务，还是使用自行配置的第三方模型服务，您均不得利用本软件制作、复制、发布、传播任何违反中华人民共和国或您所在国家/地区适用法律法规、危害国家安全、损害国家荣誉和利益、破坏民族团结、散布谣言、扰乱社会秩序、宣扬淫秽色情、暴力、侵害他人合法权益等违法或不良信息。

四、Cherry Studio 提供的模型服务

使用客户端内置的 CherryAI 模型时，完成推理所需的提示词、对话上下文和模型回复会经由 Cherry Studio 官方服务即时中转。推理完成后，我们不会保存相关对话正文。为完成推理，上游模型服务商会处理所需内容，具体处理规则见相应服务商的隐私政策。

您登录 Cherry Studio 账号并使用 Cherry Cloud 模型时，我们会处理并保存相关对话正文（包括请求与模型回复）。处理用途、保存期限及行使个人信息权利的方式，请参阅《Cherry Studio 隐私政策》（账号体系版）。

Cherry Studio 隐私政策

更新日期：2026 年 8 月 20 日
生效日期：2026 年 8 月 20 日

欢迎使用 Cherry Studio（以下简称"本软件"或"我们"）。我们高度重视您的隐私保护，本隐私政策将说明我们如何处理与保护您的个人信息和数据。请在使用本软件前仔细阅读并理解本政策。

一、我们收集的信息范围

为了保障软件正常运行、优化用户体验和提升产品质量，我们将分类收集以下完全匿名的非个人化运行信息。所有信息均经过匿名化处理，不包含任何可识别您个人身份的数据，也无法与您的个人信息相关联。您始终保有对全部信息收集行为的完整控制权，具体方式见下文说明。

（一）基础运行信息

此类信息用于保障软件基础功能正常运行、安全性及版本兼容性，默认收集范围如下：

  • 软件版本信息：用于版本兼容性判断、安全更新推送等；
  • 功能使用汇总信息：各项功能的整体使用情况汇总（不涉及具体使用行为细节）。

（二）产品改进信息

为持续改进产品体验，我们会默认收集以下信息：

  • 功能使用活跃度与频次：各项功能被使用的活跃程度、调用频次等；
  • 错误日志与崩溃信息：软件运行过程中发生的匿名错误日志、崩溃堆栈信息等，用于问题排查与稳定性提升。

上述信息均为高度聚合的匿名数据，不涉及您的对话内容、API Key 或任何个人身份信息。

关闭方式：您可随时通过【设置】-【数据设置】-【隐私设置】中的相应开关关闭以上两类信息的收集，关闭后不影响软件核心功能的正常使用。若您关闭基础运行信息的收集，可能无法及时收到版本兼容性提示与安全更新通知。

（三）我们的承诺

无论是基础运行信息还是产品改进信息，我们均承诺：

  • 全部数据经过匿名化处理，无法关联到您的个人身份；
  • 不会用于用户画像、广告推送，也不会出售或以其他方式向第三方提供（法律法规强制要求的除外）；
  • 不会包含您的对话内容、API Key、知识库内容等任何敏感数据（详见第二条）。

二、我们明确不会收集的信息

为了最大限度保护您的隐私和信息安全，我们明确承诺，不会收集、保存、传输或处理以下数据：

  • 您的 API Key：您输入到本软件中的模型服务 API Key 信息；
  • 您的对话数据：您在使用本软件过程中产生的任何对话数据，包括但不限于聊天内容、指令信息、知识库信息、向量数据及其他自定义内容（使用第四条所述内置模型服务时，为完成推理所必需的即时中转除外；我们不会记录或存储相关内容）；
  • 个人身份信息与敏感个人信息：任何可直接或间接识别您个人身份的信息，以及法律法规规定的敏感个人信息。

三、本地存储与数据交互说明

数据本地化：您的 API Key、历史对话记录以及个人偏好设置等数据均默认存储在您的本地设备中。Cherry Studio 不提供云端同步服务，也不会将这些数据上传至我们的服务器（使用第四条所述内置模型服务时，为完成推理所必需的即时中转除外）。

直接调用：当您使用自行配置的第三方模型服务时，本软件作为本地工具提供与第三方模型服务的接口调用功能。您的终端设备将直接与您配置的第三方模型提供商（如 OpenAI、Anthropic 等）的服务器建立网络连接，相关数据不经由我们的服务器中转。

内容合规义务：无论您使用第四条所述内置模型服务，还是使用自行配置的第三方模型服务，您均不得利用本软件制作、复制、发布、传播任何违反中华人民共和国或您所在国家/地区适用法律法规、危害国家安全、损害国家荣誉和利益、破坏民族团结、散布谣言、扰乱社会秩序、宣扬淫秽色情、暴力、侵害他人合法权益等违法或不良信息。

四、内置模型服务

Cherry Studio 提供无需自行配置 API Key 的内置模型服务。使用该服务时，完成推理所需的提示词、对话上下文及模型回复会通过 Cherry Studio 官方服务进行中转。

中转服务仅处理当前请求，不记录或存储相关内容，并在请求完成后立即丢弃，不会用于本次请求以外的用途。

内置模型服务所对应的上游模型服务商将在其服务范围内处理该等请求内容，具体以其隐私政策为准。

内置模型及其服务商可能根据服务情况调整。您也可以选择使用自行配置的其他模型服务。

内置模型服务依赖上游模型服务商的能力提供，可能因服务调整、网络状况或上游变更而出现中断、延迟或不可用。模型输出内容由模型自动生成，我们不对其准确性、完整性或适用性作出保证，您应自行判断并承担使用该内容的风险。在法律允许的范围内，我们不对因使用内置模型服务产生的损失承担责任。

您需自行承担使用第三方模型服务提供商所涉及的隐私与合规风险。

各模型提供商（如大模型厂商）会依据其自身的隐私政策、数据安全措施等，处理您主动输入的数据（如对话内容），并可能在其服务范围内独立采集其他相关数据。上述处理与采集行为均不受本软件控制，本软件【隐私设置】中的开关亦无法关闭此类行为。

如您希望了解或关闭相关数据处理与采集行为，请查阅所选模型服务提供商官方网站的隐私政策，并向其寻求关闭方法。我们对此不承担任何责任。

六、关于第三方服务的特别说明

为方便您管理、处理数据，在本软件的【设置】-【数据设置】中，我们支持包括但不限于以下第三方服务功能，由您通过输入 API 地址、用户名、密码等方式自行选择配置并使用这些服务：

具体支持的第三方服务以客户端内实际展示为准。

您输入的 API Key、密码等凭证仅在您的设备本地使用，本软件不会收集或存储此类信息或数据。请您自行妥善保管您的凭证。

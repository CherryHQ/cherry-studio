# UI/UX Pro Max TypeScript port

Upstream: nextlevelbuilder/ui-ux-pro-max-skill at `dcc40ff5133ef78276117db0cc34e7b83cc8aeba`, MIT. See LICENSE and provenance.json. The complete selected data directory and reference documents are retained byte-for-byte. No catalog refresh or runtime download is performed.

Retained behavior: BM25 k1=1.5/b=0.75, Unicode tokenization, aliases and synonyms, stopwords, calibrated abstention, semantic domain rewrites, exact style/landing/API identities, deprecated redirects, legacy stack applicability, typo suggestions, closed decision-rule grammar, source identity audit fields, color-mode derivation, dial selection, page guidance and master/page preservation. All upstream search CLI flags are accepted; diagnostics is an additional flag.

Adaptations: the TypeScript implementation reads immutable shipped assets without a cross-call mutable index cache. Text presentation uses portable Markdown or plain text rather than ANSI/decorative boxes. Persisted master output includes the complete structured recommendation as readable sections; it does not reproduce upstream's additional hard-coded generic component/CSS appendix or timestamp. Page outputs retain generated override data in readable JSON sections. Those presentation differences are intentional, not a claim of byte-identical Markdown. Windows reserved slugs receive a `project-` prefix. Forced replacement retains a recovery file. No dependency or platform upgrade is implied by upstream stack freshness data.

Trust boundary: CSV decision rules are interpreted using a closed validated grammar, never executed. Persistence names are sanitized into single path segments; linked directories/files beneath the explicitly chosen output root are rejected. Default creation uses exclusive file creation so concurrent agents cannot overwrite one another. Filesystem power-loss atomicity for exclusive first creation differs from upstream's hard-link publication; no hard links or symlinks are required. A completed forced write is published by rename after preserving the previous file.

Completed-phase integration evidence is recorded in `reference-cases.json`: 50 real-CLI cases matched the pinned original upstream JSON (or rejected unsupported stack input) through both full and mini entrypoints, covering all 22 stacks, identities, typo suggestions, calibrated abstention, reasoning and all dial tiers. Nineteen persistence and packaged-offline checks passed, including CRLF preservation, existing master/new page, existing page, force recovery, path/Unicode/reserved slugs, linked output rejection, and standalone execution without developer-global dependencies. The packaged-offline check initially found a direct-entry path-alias mismatch; canonicalizing argv[1] fixed it, and only the three failed gate cases were rerun. Two of those failures were canonical-path assertions in the gate, not escaped writes. Native Windows and native Linux execution remain unrun; Windows-like strings on macOS are not native Windows evidence. Presentation parity is intentionally scoped as described above.

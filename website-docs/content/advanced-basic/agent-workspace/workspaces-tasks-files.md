# 工作目录、任务与文件



<details>

<summary>哪些文件不能直接编辑？</summary>

二进制文件、非 UTF-8 文本和体积较大的文件只提供预览或外部打开。它们仍可由智能体工具处理，但不一定能在内置编辑器中修改。

</details>

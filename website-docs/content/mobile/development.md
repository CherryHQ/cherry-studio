# 参与移动版文档

这里汇集移动版文档维护和问题反馈入口。使用教程见[移动版首页](README.md)；遇到连接、模型或工具问题，先按[故障排查](troubleshooting.md)检查。

## 改进教程与翻译

发现步骤、截图或翻译与当前版本不一致时，按[贡献文档](../contribution/docs.md)修改网站仓库中的移动版页面。提交时说明系统、App 版本、界面语言和要修正的页面地址，便于核对适用范围。

中英文教程使用对应语言的截图。提交截图或日志前，遮挡密钥、账号和私人对话；不要放入真实健康记录或位置记录。

本轮功能基线为 **0.3.0**。新增图片和动画统一使用 **WebP**；连续操作可使用动态 WebP，中英文需呈现同一功能。功能讲解优先使用 App 实际录屏生成的动态 WebP，展示真实入口和点击顺序；录制前统一状态栏，并对密钥、账号和私人内容打码。记录素材所用版本，并保持图片与原图链接指向同一语言目录。

## 提交可复现的问题

先参考[如何高效提问](../question-contact/ask.md)，整理操作步骤、预期结果、实际结果和已尝试的排查方法。文档问题可提交到[网站仓库 Issues](https://github.com/CherryHQ/cherry-studio-website/issues)；App 使用问题请按[移动版故障排查](troubleshooting.md)中的说明反馈。

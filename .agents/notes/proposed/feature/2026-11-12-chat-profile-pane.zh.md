# Agent Note: 对话页中助手与智能体的资料面板

Status: proposed

[English](2026-11-12-chat-profile-pane.md) | 中文

## 问题

在对话中，用户正在对话的助手或智能体没有资料页。点击顶栏里的名称会打开完整的编辑弹框或选择器；点击消息头里的头像没有任何反应。想知道助手知道些什么、用了哪些知识库，或者智能体产出了什么、安排了哪些任务，用户只能打开编辑弹框或其他页面。对话里也没有任何提示告诉用户可以问什么、下一步可以设置什么。

设计原型（`bot-profile-cherry`）在现有的右侧面板槽位中加入一个资料面板。完整设置复用[分页式编辑弹框](2026-11-12-resource-edit-pages.md)。

## 提案

### 位置与过渡

- 资料面板是现有右侧面板框架（`src/renderer/components/chat/panes/Shell`）中的一个新面板，在助手和智能体对话中都排在第一个。它与现有面板共用一个槽位；打开别的面板会替换它，点击当前已打开面板的入口会收起面板。
- 智能体会话详情卡片和资料面板互斥：打开其中一个会关闭另一个。卡片保持已上线的紧凑样式（[紧凑的智能体会话详情卡片](../../implemented/feature/2026-11-08-agent-session-details-card.md)）；本 Spec 只增加互斥规则，部分取代该 note。
- 新增 `profile` 宽度档：最小 300、默认 360、最大 440 像素，与其他宽度档一样会被记住。
- 在已打开的面板之间切换时，宽度从一个宽度档平滑过渡到另一个，新内容用 150 ms 淡入。被切走的面板保留状态。
- 资料面板不能最大化。在其他面板最大化时打开资料面板，会恢复正常布局。
- 面板没有标题栏：顶部是一条固定的空白条，只放关闭按钮，内容在它下方滚动。

### 入口

- **顶栏。** 头像单独成为一个按钮，点击切换资料面板。名称保持现有行为（打开编辑弹框，空对话时打开选择器）。
- **消息头。** 点击消息头里助手或智能体的头像，切换当前对话所属助手或智能体的资料面板。消息头仍显示每条消息记录时的快照。

### 内容

顶部显示可直接更换的大头像、名称和简介。下面是两个页签：**动态**，以及 **产物**（仅智能体）。

**动态，助手：**

- 用量：话题数、消息数，以及最近 7 天的 token 数。
- 最近话题：这个助手最近活跃的 5 个话题。点一行打开该话题；「全部」打开筛选为这个助手的话题列表。
- 已关联知识库，带「管理」，打开编辑弹框的知识库页。
- 试试这样问：由默认模型根据助手的名称、简介和提示词生成 4 个开场问题，在其中任何一项变化之前一直使用缓存。点击填入输入框。「隐藏」会对这个助手隐藏这一块。
- 设置：模型、浏览器和回复语言，带「全部 ›」，打开编辑弹框。

**动态，智能体：**

- 用量：会话数、最近 7 天的任务运行次数，以及最近 7 天的 token 数。
- 定时任务：这个智能体的任务，带暂停开关；点一行打开任务表单。「新建」在输入框填入创建任务的请求。
- 推荐：只显示还没做的项——智能体没有频道时推荐连接飞书或微信，没有任务时推荐每天发日报，没有关联 GitHub MCP 服务时推荐连接 GitHub，找合适的技能，记住我的习惯，以及没有关联知识库时推荐关联知识库。点击填入输入框，关联知识库除外，它打开编辑弹框。
- 工作区：当前会话的工作区，以及智能体是否正在运行。点击打开文件面板。
- 设置：模型（对话已有消息时沿用现有的确认）、权限模式和回复语言，带「全部 ›」。

**产物，智能体：** 智能体在所有会话中上报过的交付物，可按全部、页面、媒体、文件筛选并显示数量，按今天、本周、更早分组。每行显示类型缩略图、标题、类型及来源或大小，以及时间。点击在文件面板中打开；已删除的文件显示为不可用。

助手没有产物页签，因为助手没有交付物这个概念。

### 数据

- **用量。** 用量统计接口支持按来源（助手或智能体 ID）筛选。话题、消息、会话和任务运行的数量来自小型 DataApi 计数查询。「最近 7 天」是滚动窗口。
- **最近话题。** 话题接口支持按助手筛选，并按最后活跃时间排序。
- **产物。** 新增一张表，在 `report_artifacts` 工具上报交付物时建立索引，记录智能体、会话、路径、标题、类型、大小和时间，通过 DataApi 列表接口提供。类型由文件类型推断：HTML 和 Markdown 是页面；图片、音频和视频是媒体；其余是文件。本功能上线之前上报的交付物不会回填。
- **助手回复语言。** 助手新增回复语言设置，选项与智能体相同，以同样方式注入系统提示词。它出现在资料面板的设置和助手编辑弹框的回答卡片中。
- **输入框预填。** 一个按对话限定的渲染进程事件，把输入框草稿替换为给定文字并聚焦，助手和智能体的输入框都支持。草稿非空时，需要用户确认后才替换。

### 编辑弹框链接

「全部」「管理」和设置行使用编辑弹框 Spec 中的 ID，打开编辑弹框的对应页面。弹框关闭后资料面板仍然打开，修改会立即反映在资料面板、顶栏和输入框中。

## 备选方案

- **把智能体会话详情改回共用槽位中的整列面板。** 这会推翻一个已上线的决定；互斥规则无需推翻也能做到「同一时间一个面板」。
- **使用现有的 `inspector` 宽度。** 它的最小宽度 255 像素对资料内容来说太窄。
- **像原型一样按关键词匹配开场问题。** 成本低但千篇一律；生成方式贴合实际提示词，且有缓存，每次变化只花一次调用。
- **只显示当前会话的产物。** 这些数据已经在会话详情里；资料面板关注的是跨会话的智能体。
- **去掉助手的回复语言行。** 原型把它放在助手设置里，这个设置本身也有用。
- **资料变化时更新历史消息头。** 这需要修改 `MessageSnapshot`，不在本次范围内。

## 验收标准

- AC1 — 点击顶栏头像或消息头头像，打开当前对话所属助手或智能体的资料面板，再次点击则收起 (verification: renderer; owner: implementer)
- AC2 — 打开其他面板会替换资料面板，打开资料面板会关闭智能体会话详情卡片，反之亦然，资料面板不能最大化 (verification: renderer; owner: implementer)
- AC3 — 资料面板以 360 像素打开，可在 300 到 440 之间调整并记住宽度，切换面板时宽度平滑过渡、内容淡入 (verification: renderer; owner: implementer)
- AC4 — 助手的动态页签显示用量、最近话题、已关联知识库、试试这样问和设置，数据只属于这个助手 (verification: renderer and main service test; owner: implementer)
- AC5 — 智能体的动态页签显示用量、定时任务、尚未完成的推荐、工作区和设置，数据只属于这个智能体 (verification: renderer and main service test; owner: implementer)
- AC6 — 用量计数、最近话题和 7 天 token 总数与这个助手或智能体的记录一致 (verification: main service test; owner: implementer)
- AC7 — 试试这样问显示 4 个生成的问题，在名称、简介或提示词变化前复用它们，点隐藏后对这个助手保持隐藏 (verification: renderer; owner: implementer)
- AC8 — 点击问题、推荐或新建任务，会把对应文字放进当前对话的输入框，草稿非空时先询问再替换 (verification: renderer; owner: implementer)
- AC9 — 智能体上报的交付物出现在它的产物页签中，类型和时间分组正确，并能在文件面板中打开 (verification: main service test and renderer; owner: implementer)
- AC10 — 在资料面板或编辑弹框中为助手设置的回复语言会作用于它的回复 (verification: main service test; owner: implementer)
- AC11 — 「全部」「管理」和设置行打开编辑弹框的对应页面，在那里做的修改无需重新打开就会显示在资料面板中 (verification: renderer; owner: implementer)
- AC12 — 所有新增界面文案在全部渲染进程语言包中都有翻译，没有占位符 (verification: docs gate; owner: implementer)
- AC13 — 在运行中的应用里，一个助手和一个智能体的资料面板显示真实的用量、话题或任务以及产物，其中的链接都能用 (verification: Electron; owner: implementer)

## 风险

- 生成开场问题在助手每次变化时要调用一次默认模型；没有默认模型时生成失败，这一块保持隐藏。
- 对已有的智能体，产物索引一开始是空的，因为旧的交付物不会回填。
- 每次打开资料面板都会运行用量和计数查询；历史数据多时，需要在筛选列上建索引才能保持速度。
- 助手回复语言是新的持久化设置。已有助手必须默认为不限制；如果这个设置需要新增列而不是设置字段，就随一个追加的迁移一起发布。
- 让会话详情卡片和资料面板互斥，会改变一个已上线的行为：卡片原本可以和任何面板同时打开。

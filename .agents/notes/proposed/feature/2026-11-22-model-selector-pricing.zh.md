# Agent Note: 模型选择器参考价格

Status: proposed

[English](2026-11-22-model-selector-pricing.md) | 中文

## Problem

Issue #19347 要求在模型选择器现有详情卡片中展示 API 价格。Cherry 已保存模型价格，支持自定义价格和输入 token 阶梯，并可解析服务商计费时段。目前详情卡片展示身份、上下文限制和能力，但不显示价格。用户不应为了比较已知参考费率而必须打开模型设置。

展示不能把未知价格变成零、隐藏币种差异、抹平阶梯，或将本地估算当作服务商报价。本需求无需新增实时价格来源。

## Proposal

在 `ModelSelectorDetailCardContent` 现有 token 限制下方添加只读、本地化的参考价格区域。普通选择器传入模型和服务商；缺少服务商上下文的其他消费者可仅展示模型保存的费率，但必须明确标注为未应用服务商计费调整的配置价格。保留模型选择、悬停/焦点行为、身份、标签、描述和能力行。

使用模型现有价格和自定义价格来源。对于具有服务商上下文的卡片，复用现有服务商计费/默认策略解析器及 API 模型身份，不另写价格计算器。卡片打开时捕获参考时间；应用依赖时段的计费时显示本地截至时间。打开期间价格固定对应该时间，重新打开时刷新。它不是对未来请求的承诺。缺少服务商上下文时不能暗示已应用服务商调整。不发起网络请求、不修改保存的价格，也不创建用量记录。

输入、输出、缓存读取和缓存写入费率需明确币种和每百万 token 单位。缺失、非有限数或负费率显示不可用；有效零保持数字零，不把整个模型标为免费。保留足够小数精度，使正的小额价格不会变成零。token 币种缺省时遵循现有 schema 的默认契约，不做汇率转换，也不静默替换显式币种。没有已知价格时显示独立的不可用状态。

输入 token 阶梯展示基础费率及每个阈值对应的输入/输出/缓存费率，而非一个误导性的固定价格。阈值语义和顺序沿用现有解析器。缺失缓存费率保持未知，不复制普通输入价格。显示已知的每图/像素和每分钟费率及正确单位，但只在现有数据契约明确时归属币种。非 token 币种存在歧义时标明未指定，不从无关字段猜测。长表格在现有避碰卡片中滚动，不能截断价格或单位。

明确所有金额都是来自配置/目录元数据的参考估算，不是实时报价或最终账单。存在自定义价格时展示其来源，简短说明服务商计费可能依赖请求时间、token 阶梯、缓存使用和未表示的其他费用。除非当前解析器实际表示相关条件，否则不宣称包含税费、账户折扣、地区换算或条件服务等级价格。现有服务商/模型计费设置仍负责编辑；本功能不新增偏好、schema 或目录变更。

## Alternatives considered

- 悬停时抓取服务商网页：增加延迟、凭据/限流问题，以及没有时效契约的第二价格来源。
- 仅显示输入/输出标量：隐藏缓存优惠、阶梯、计费时段和币种差异，可能改变比较结论。
- 将缺失价格或免费能力标签当作价格免费：虚构计费事实，可能误导预算敏感用户。
- 在渲染器卡片重写时段乘数：偏离现有计费所有权。
- 展示请求总价：选择器不知道未来 token 数、缓存结果或最终费用。

## Acceptance criteria

- AC1 — 打开具有服务商上下文的模型详情卡片时，通过现有价格/计费所有权展示可用的已解析参考费率、明确币种/单位和自定义来源；重新打开刷新参考时间，缺少上下文的消费者不宣称价格已调整；选择和原有详情内容不变。(verification: renderer and shared tests)
- AC2 — 未知/无效值保持不可用，显式零保持零，小额正价仍为正数；保留币种，不转换或虚构非 token 币种；缓存、阶梯输入/输出和支持的非 token 单位不会被合并成单一费率。(verification: renderer and shared tests)
- AC3 — 用户通过现有悬停/焦点入口查看价格，窄屏/明暗布局及长阶梯表格可读；英文/中文文本及所有已发布语言键完整；展示路径不调用模型、不修改价格、不创建用量。(verification: renderer, visual inspection and Electron)
- AC4 — 双语模型选择指南说明参考估算及其限制；变更文件检查、受影响消费者测试和文档门禁通过，明确声明原生验收边界，所有条件具备证据前保持 proposed。(verification: docs gate, renderer and Electron)

## Risks

模型 schema 能表达的价格比紧凑卡片易于概括的更多。应保留单位和阶梯并允许滚动，不能静默省略条件。说明应简短，但不能丢失配置价格与实时价格的区别。

有服务商上下文和没有上下文的消费者不能显示相同数字却隐含不同权威。标签必须清晰。依赖时段的费率需要截至时间，避免打开的卡片静默将旧费率宣称为当前费率。本功能不修复目录时效，也不新增计费策略。

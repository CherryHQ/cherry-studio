# Agent Note：Doc2X v3-2026 文档处理支持

Status: proposed

[English](2026-11-08-doc2x-v3-2026-support.md) | 中文

## 问题

当前 Doc2X 文件处理器没有为提供商的 v2 和 v3-2026 PDF API 提供可由用户选择的模型契约。导出请求对所有模型都发送 v2 的公式字段，v3-2026 响应中的结构化布局数据也无法进入 Markdown 工件路径。因此用户无法选择提供商模型，表格和重复页眉等布局信息也会在文档输出中丢失。

这项改动跨越共享处理器偏好设置 schema、渲染器设置界面、主进程远程轮询、任务上下文持久化和提供商响应 schema。同时需要保持现有用户的 v3-2026 预设行为，除非用户明确选择其他模型。

## 提案

为文档转 Markdown 能力增加 Doc2X 模型和 v3 导出控制：

- 保留 `v3-2026` 作为预设默认值，同时允许用户在设置中选择 `v2` 或 `v3-2026`。
- 将 `formulaLevel`（0、1 或 2）和 `mergeCrossPageForms` 作为可选能力覆盖项持久化。只有 v3-2026 导出请求使用这些字段；v2 保持文档规定的请求格式。
- 在 preupload 请求中发送选定模型，并在远程轮询和重新载入任务时传递选项。
- 校验 `version`、`inplace_pages`、页面 Markdown 和可扩展的 `layout.blocks` 响应数据。将 `page.md` 作为页面正文主体；将布局块作为增强层，移除标记的样板内容、遵循 `reading_order`、优先使用 `table_data.html`，并在没有 Markdown 回退内容时使用图片 URL 生成图形。
- v2 和旧响应继续使用现有 ZIP 工件路径。包含结构化布局数据的 v3-2026 响应使用现有 Markdown 工件持久化逻辑。
- 保留独立的实时 E2E 脚本，覆盖提供商的上传、解析轮询、导出轮询和 ZIP 下载契约。脚本需要 `DOC2X_API_KEY`，手动运行，不作为 CI 测试。

## 备选方案

- **完全从布局块重建每个 v3 页面。** 不采用，因为会丢失提供商 Markdown 中的图片和代码；布局应作为增强层。
- **始终发送 v3 导出字段。** 不采用，因为 v2 API 有独立的文档化请求格式，且必须保持既有 v2 行为兼容。
- **把 v2 设为新的默认值。** 不采用，因为已发布的预设默认使用 v3-2026；改变默认值会静默改变现有用户的输出。
- **把实时提供商调用放入常规 Vitest 套件。** 不采用，因为检查需要真实凭据、外部服务可用、长时间轮询和远程工件下载。确定性的单元测试覆盖转换和请求契约，独立脚本覆盖真实提供商契约。

## 验收标准

- AC1 — Doc2X 设置面板提供 v2/v3-2026 选择、公式级别 0/1/2 和跨页公式合并；现有 v3-2026 预设仍为默认值。（验证：渲染器和共享偏好设置测试）
- AC2 — preupload 请求携带所选模型；只有 v3-2026 的导出请求发送 v3 专用字段，v2 请求格式保持不变。（验证：主进程处理器测试和实时 E2E）
- AC3 — v3-2026 结构化响应生成 Markdown 工件，保留 `page.md`、移除标记的样板内容、遵循阅读顺序、有表格时使用表格 HTML，并在需要重建时保留图片 URL。（验证：主进程处理器测试）
- AC4 — v2 和没有结构化布局的旧响应继续生成现有 ZIP 工件并使用远程 URL 处理。（验证：主进程处理器测试）
- AC5 — 实时 E2E 脚本对 v2 和 v3-2026 都完成上传、解析轮询、导出轮询并下载非空 ZIP，且不会将凭据写入仓库。（验证：手动实时 E2E）
- AC6 — 现有持久化处理器覆盖项仍然有效，因为新增能力字段均为可选；现有用户不会改变模型，除非主动选择。（验证：共享 schema/config 测试和升级审查）

## 风险

- Doc2X 可能增加布局块字段或块类型。响应 schema 保持块类型可扩展并保留可选的提供商元数据，但新增语义可能需要后续渲染器决策。
- 实时 E2E 依赖提供商可用、有效凭据和公共 PDF fixture；它是提供商契约证据，不是确定性的 CI 门禁。
- v3 结构化输出以 Markdown 内容保存，而 v2 继续使用 ZIP 路径。共享工件持久化契约必须继续作为唯一边界，使调用方仍然获得基于路径的工件。
- 公式和跨页选项会影响输出质量以及提供商成本/延迟。默认值保持现有预设的 v3-2026 行为。

# Agent Note: 智能体下一问建议

Status: proposed

[English](2026-11-14-agent-prompt-suggestions.md) | 中文

## Problem

智能体回复后，用户经常输入一句从对话中已经能推断出意图的简短追问。他们需要的是可选的草稿建议，而不是自动发送消息或再次执行智能体。

## Proposal

`agent.input.suggestions.enabled` 默认开启，在输入设置中提供关闭选项。只有智能体会话输入框提供建议；普通聊天和消息编辑不提供。用户已在开发期间确认默认开启。

观察到正在运行的一轮成功结束后，等待 300 毫秒，通过可取消的 `ai.text.generate` 向当前模型请求至多一条下一问。只使用最近四条消息的文本，每条最多 2,000 个字符；排除推理、附件、工具结果和系统指令。禁用工具；模型支持时关闭推理，否则通过共享的模型选择解析器请求最低支持档位。不重试，传输超时设为 10 秒。不静默切换到备用模型。模型不可用、请求失败、响应为空、多行或超过 120 个字符时不提供建议。仅打开历史记录不会生成预测。

建议显示为柔和的叠加文字，独立于编辑器文档及已保存草稿。不带修饰键的 Tab 插入可编辑的纯文本，不发送。Escape 取消该条回复的建议。用户输入、附件、令牌、排队的追问、编辑状态、隐藏的输入层及新一轮运行都会抑制建议。取消过时请求；迟到结果不能跨越会话或模型边界。保留快捷面板处理、提示词变量导航、Shift+Tab 计划模式控制和输入法组词。接受前不将建议持久化为消息或草稿。

## Alternatives considered

- 将预测附加到智能体回答：不采用，会污染对话记录，并与各运行时的提示词耦合。
- 自动发送预测：不采用，预测不等于用户授权。
- 默认关闭：用户不采用；请求使用少量、有界的文本上下文，也可关闭。
- 独立模型选择器或专用服务：暂缓；复用现有单次请求 IPC 和选定模型，不新增运行时所有者。

## Acceptance criteria

- AC1 — 只有智能体会话输入框在观察到一轮成功结束后预测，设置默认开启且可关闭；重新打开历史和普通聊天不请求预测。(verification: renderer)
- AC2 — Tab 填入可编辑纯文本但绝不发送；Escape 取消后，同一条回复的建议不再出现。(verification: renderer)
- AC3 — 现有草稿和附件绝不被覆盖；取消请求、切换会话或模型、开始新一轮后忽略迟到结果。(verification: renderer)
- AC4 — 轻量与富文本输入界面均保留快捷面板和提示词变量的 Tab 行为、Shift+Tab 以及输入法组词。(verification: renderer)
- AC5 — 请求只使用有界的近期文本，禁用工具，关闭推理或选择最低支持档位，不重试或切换备用模型；失败不阻塞输入框、不改变会话历史。(verification: renderer)
- AC6 — 柔和的建议文字和 Tab 提示在明暗主题的 Electron 窗口中均清晰可读，接受后文字仍可编辑。(verification: Electron)

## Risks

每条符合条件的回复都会增加一次模型请求，可能产生提供商费用。预测质量和延迟取决于选定模型。上下文发送到同一配置的提供商；预测不能视为授权。传输取消是尽力而为，因此仍需校验结果身份。在所有验收证据（包括真实提供商验证）完成前，本记录保持 proposed 状态。

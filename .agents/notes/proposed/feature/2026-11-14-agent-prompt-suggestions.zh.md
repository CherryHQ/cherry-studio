# Agent Note: 智能体下一问建议

Status: proposed

[English](2026-11-14-agent-prompt-suggestions.md) | 中文

## Problem

智能体回复后，用户经常输入一句从对话中已经能推断出意图的简短追问。他们需要的是可选的草稿建议，而不是自动发送消息或再次执行智能体。

## Proposal

`agent.input.suggestions.enabled` 默认开启，在输入设置中提供关闭选项。只有智能体会话输入框提供建议；普通聊天和消息编辑不提供。用户已在开发期间确认默认开启。

预测生成由活跃的原生运行时负责；renderer 只展示并接受临时建议。[预测研究](https://mcnnox2fhjfq.feishu.cn/docx/NfzKdatIlojMa1xJ4KDcqdoInry) 对应的需求称为 `prompt_predict`；固定版本 Claude Agent SDK 0.3.311 暴露的是 `Options.promptSuggestions` 和 `SDKPromptSuggestionMessage`，并没有名为 `prompt_predict` 的方法。

Claude Code 通过现有 Query 选项启用原生建议，包括预热 Query 的初始化。在 `result` 后保持唯一的原生读取器运行，通过带类型的原生观察消费 `prompt_suggestion`。绝不提交合成的预测轮次，也不回退到 `ai.text.generate`。保留原生抑制条件，包括首轮、Plan 模式、错误和用量限制。原生生成参数、上下文与缓存策略仍由 Claude 负责。

pi 和 pi-durable 在交互式根轮次成功后至多请求一条建议。在完成时捕获运行时的有效模型上下文，包含压缩后的视图，不从四条产品消息重建。通过现有原生模型绑定和 Cherry gateway 发起可取消、只生成一次响应的模型请求。按用户要求，在独立的上下文副本后原样追加所链接研究中的 Claude Code 建议指令。指令保存在 `src/main/ai/runtime/promptSuggestion.ts`，不为 Pi 改写措辞。保留父请求的工具声明以维持缓存前缀，不进入智能体工具循环，并在工具调用开始流出时立即中止。不将请求或响应追加到原生或产品历史，不创建持久任务或子智能体，不改变分支头或目标。通过依赖补丁增加原生 Pi `createQueryFork` API 和 pi-ai 提供商选项：保留父请求的推理设置和显式缓存断点，不给预测后缀新增断点，并禁止写入 continuation 状态。不能用 `cacheRetention: none` 替代 `skipCacheWrite`。提供商自动缓存的服务端写入仍由提供商控制。不额外覆盖预测超时或重试策略。Gateway 仍是唯一计费所有者，不把建议输出归入助手回复。

Main 在符合条件的轮次结束时启动生成；renderer 仅消费已有状态。Main 拥有临时结果及其会话、原生上下文代次、来源回复和模型身份。只有结果仍对应同一条成功完成的根回复，且中间未发生输入、重置、压缩、模型或分支切换、中断、连接替换时才可发布。在这些状态变化及关闭时失效结果并取消自己拥有的请求。Claude 建议的 UUID 是事件身份，不是来源轮次 ID；原生事件不能明确关联到已完成回复时丢弃。驻留的原生快照可播种最新建议，直到真实用户消息到达；观察缺口清空状态，归档历史不触发生成。Pi 检查文档中的至少两条 assistant 消息及 10,000 token 缓存门槛。第一段文本经过包装/标签清理和候选过滤（少于 100 个 UTF-16 单元、至多 12 个近似多语言词）；展示校验拒绝控制字符、命令前缀和已识别的秘密格式，保留通过校验的原始文本。不臆造未知的私有功能开关、退避和未使用次数阈值。失败或抑制不影响输入框使用，也不改变轮次成功状态。

保留默认开启的偏好。关闭建议后不得发起 Pi 预测请求，并在新建和预热的 Claude 连接上关闭原生选项。如果固定 SDK 没有公开的实时暂停接口，通过现有安全连接重建机制在空闲边界应用选项变化；不中断运行中的轮次，不发送未公开的控制消息。立即隐藏建议，并丢弃已在运行的结果。打开历史、无头运行和子智能体结果引发的自主轮次不发起宿主预测。其他运行时保留现有预测行为；本次变更仅覆盖 Claude Code、pi 和 pi-durable。

建议显示为柔和的叠加文字，独立于编辑器文档及已保存草稿。不带修饰键的 Tab 或文字方向前进键（LTR 为右键、RTL 为左键）插入可编辑的纯文本，不发送。Escape 取消该条回复的建议。用户输入、附件、令牌、排队的追问、编辑状态、隐藏的输入层及新一轮运行都会抑制建议。取消过时请求；迟到结果不能跨越会话或模型边界。保留快捷面板处理、提示词变量导航、Shift+Tab 计划模式控制和输入法组词。接受前不将建议持久化为消息或草稿。

## Alternatives considered

- 将预测附加到智能体回答：不采用，会污染对话记录，并与各运行时的提示词耦合。
- 自动发送预测：不采用，预测不等于用户授权。
- 默认关闭：用户不采用；预测仍为可选功能，也可关闭。
- 保留 renderer 四条消息的 `ai.text.generate` 实现：这些运行时不采用，因为它丢失原生上下文，并绕过 Claude 的预测和缓存策略。
- 持久化预测分支、任务或子智能体：不采用，建议不得改变恢复、对话历史或执行所有权。
- 独立模型选择器或独立服务：暂缓；使用活跃运行时模型和现有会话生命周期。

## Acceptance criteria

- AC1 — 只有智能体会话输入框在观察到一轮成功结束后预测，设置默认开启且可关闭；重新打开历史和普通聊天不请求预测。(verification: renderer)
- AC2 — Tab 填入可编辑纯文本但绝不发送；Escape 取消后，同一条回复的建议不再出现。(verification: renderer)
- AC3 — 现有草稿和附件绝不被覆盖；取消请求、切换会话或模型、开始新一轮后忽略迟到结果。(verification: renderer)
- AC4 — 轻量与富文本输入界面均保留快捷面板和提示词变量的 Tab 行为、Shift+Tab 以及输入法组词。(verification: renderer)
- AC5 — Pi 预测使用独立的有效上下文快照和活跃 gateway 模型，不执行工具，保留推理设置和父缓存断点、不缓存新增后缀；成功或失败均不改变历史、分支头和轮次结果。(verification: unit)
- AC6 — 柔和的建议文字和 Tab 提示在明暗主题的 Electron 窗口中均清晰可读，接受后文字仍可编辑。(verification: Electron)
- AC7 — Claude 为冷启动和预热 Query 启用固定版本的原生选项，在 `result` 后消费建议，保留原生抑制条件，且绝不发起第二个宿主预测请求。(verification: unit)
- AC8 — 重置、压缩、输入、模型或分支切换、连接替换及关闭使旧预测失效；Claude 来源身份不明确和观察缺口均不产生建议；驻留状态可播种输入框，无需新增查询。(verification: unit)
- AC9 — 关闭偏好立即隐藏建议，并通过受支持的运行时控制阻止后续生成；这三个运行时的无头和自主路径不发起宿主预测。(verification: unit)
- AC10 — 真实提供商运行证明 Claude 原生交付以及 Pi/pi-durable 建议均不写入历史、不执行工具、不重复计费；原生抑制与成功交付分别记录。(verification: Electron)

## Risks

符合条件的回复可能增加模型请求和提供商费用。原生上下文预测可能将运行时上下文中已有的系统指令、工具结果和附件发往其配置的提供商；这有意替代之前仅四条消息文本的限制。即使已启用，Claude 也可能抑制建议，且事件没有显式来源轮次 ID，因此保守丢弃可能降低可用性。提供商取消是尽力而为，仍必须校验身份。繁忙的 Claude 连接可能需要安全到达空闲重建边界后，偏好变化才对原生生成生效。用户已明确豁免实现前的 Spec 批准门槛。在每条验收标准都有证据（包括真实提供商验证）之前，本记录保持 proposed 状态。

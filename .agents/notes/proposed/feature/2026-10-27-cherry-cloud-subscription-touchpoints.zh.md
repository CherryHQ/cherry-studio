# Agent Note: Cherry Cloud 订阅付费触点

Status: proposed

[English](2026-10-27-cherry-cloud-subscription-touchpoints.md) | 中文

## Problem

Cherry Cloud 订阅（全球版为 Flash）只能从账户面板的一行和个人资料页进入，而且这两处在国内版都被隐藏，国内的 Plus 套餐因此无法售卖。想订阅的用户在需要的时候也看不到入口：模型选择器只列出用户已拥有的模型，额度用完只体现在选择器的一行描述里，网页支付完成后客户端要等之后某次刷新才会体现。

## Proposal

- **两个版本同一套流程。** 订阅相关界面、付费触点和交互在国内版和全球版完全一致。套餐、模型、套餐名和额度都由 Cherry Cloud 后端下发（`display_name` 显示为 Plus 或 Flash），客户端不写死任何套餐名或价格。账户门户在所有环境下都是 Cherry Cloud API 同源下的 `/account/plans`：生产环境由版本对应的 origin 决定国内或全球门户，配置的开发 origin 则打开它自己的门户。
- **登录和支付都在网页。** 登录、注册、选择账号、套餐详情和支付都是本仓库之外开发的网页。客户端负责打开这些网页，并处理用户回到客户端之后的逻辑。客户端不展示付费弹窗、成功弹窗、价格、续费日期或首月优惠。
- **设置页和账户面板。** 去掉个人资料设置页及其路由、订阅区块、账户面板订阅行上的「仅全球版」限制，两个版本都显示。未订阅账号看到蓝色「去订阅」。已订阅账号看到套餐名和剩余最少的额度百分比，悬停这一行会弹出卡片，显示每个额度窗口的用量、恢复时间，以及跳到用量页的「查看用量详情」。
- **国内版 Onboarding。** 打开现有的 Cherry 账号登录。只改按钮文案：主按钮为「登录」，次按钮为「使用自定义服务商」。布局、提示小字、语言切换、稍后设置、隐私协议、授权中的状态，以及现有的登录后流程（选第一个可用的 Agent 模型，没有则弹出无可用模型对话框）都保持不变。全球版 Onboarding 不动。
- **模型选择器。** Cherry AI 分组里订阅模型排在免费模型之前。免费模型带绿色「免费」文字标签；共享的免费模型标签在所有出现的地方都显示这个文字，不再显示礼盒图标。付费套餐可以在 `available_plans[]` 的可选字段 `models` 里列出它包含的模型；账号还没有有效付费套餐时，它还不能用的模型会以上锁行出现在分组里，带能力标签和带锁的「订阅」标签，点击会发起订阅动作而不是选中。订阅之后不再有上锁的行，因为没有更高档的套餐可卖。上锁行和已拥有模型遵循同一条 `available_features` 规则，并且不看 `purchase_available`，能否购买由门户决定。分组标题旁未订阅时显示蓝色「去订阅」链接，订阅后显示胶囊样式的套餐名。额度用完的模型保留现有的不可用状态。
- **订阅动作。** 所有触点都调用同一个动作：消除红点并打开对应版本的门户。未登录用户先走现有的 Cherry 账号登录，登录完成后再打开门户。登录失败时保留「需要升级」「服务不可用」等具体提示，门户打开失败单独提示。
- **回到客户端和订阅成功提醒。** 主窗口重新获得焦点时，客户端刷新账户套餐和模型可用性。同一账号新获得一个此前没有的有效付费权益时，客户端弹出一条轻提醒「{套餐名} 已生效」。网页支付后的 `cherrystudio://` 回跳链接、切换到选定的目标模型，等网页回跳格式和套餐模型清单就绪后再做。
- **额度用完提示条。** 一个通用提示条，位于对话和 Agent 输入框的正上方。当前模型是额度已用完的 Cherry Cloud 模型时出现，并说明额度何时恢复。免费模型提供「去订阅」（已订阅时不显示），付费模型提供「查看用量」，「切换模型」打开模型选择器。此时发送会被拦住、不发出请求，草稿保留。切换模型后，或刷新后的额度显示已恢复时，提示条消失。文案不提「升级」，因为目前没有更高档的套餐。
- **红点。** 用户没有有效付费权益时，侧边栏账户头像显示红点，直到第一次使用任意「去订阅」触点。消除状态重启后保留。
- **用量页。** 30 天滚动窗口和 `subscription_month` 计费周期窗口都标为「月度用量」。恢复时间取 `next_recovery_at`，计费周期窗口取 `period_end`。区块标题旁的蓝色「FAQ 与帮助」链接在拿到网址后打开对应版本的订阅 FAQ。
- **开发后端。** 通过 `MAIN_VITE_CHERRY_CLOUD_API_ORIGIN` 配置的后端，可以在恰好这个 origin 上返回纯 HTTP 的授权链接，这样没有 HTTPS 的局域网后端也能用于联调。生产构建从不设置这个覆盖项。

## Alternatives considered

- 客户端内展示套餐详情的付费弹窗：不采用；套餐和其中的模型会调整，套餐介绍由网页负责。
- 订阅成功弹窗（有营销效果或无营销效果）：不采用，改为不打断用户的轻提醒。
- 像全球版现在这样只在分组标题旁放链接、不列上锁的行：作为后端没提供套餐模型清单时的表现保留，不是目标形态。
- 从模型目录或主进程模型同步推出上锁行：不采用；国内后端的 `/v1/models` 只列出已拥有的模型，而每次同步多请求一次套餐会改变所有客户端的网络行为。
- 按 `purchase_available` 过滤上锁行：不采用；国内后端对门户里仍在售卖的套餐也返回 `false`，用量页本来也不看这个字段。
- 按版本写死 Plus 和 Flash：不采用；后端已经下发 `display_name`。
- 支付期间轮询：不采用；获得焦点时刷新就能覆盖回到客户端的场景，且没有后台请求。
- 客户端展示首月优惠价：按 2026-10-27 的产品决定不展示。
- 全球版 Onboarding 也用 Cherry 账号登录：暂缓；本次全球版 Onboarding 仍保持 CherryIN。
- 接受任意纯 HTTP 的授权链接：不采用；只有明确配置的开发 origin 才豁免。

## Acceptance criteria

- AC1 — 国内版设置中显示带订阅区块的个人资料页，账户面板显示订阅行；每个环境都打开其 Cherry Cloud API origin 下的 `/account/plans`。 (verification: renderer)
- AC2 — 国内版 Onboarding 显示「登录」和「使用自定义服务商」，用 Cherry 账号登录，登录后流程保持现状；全球版 Onboarding 不变。 (verification: renderer)
- AC3 — Cherry AI 分组中订阅模型排在免费模型之前；免费模型显示绿色「免费」文字标签，免费标签在任何地方都不再出现礼盒图标；未订阅时，账号不能使用的套餐模型以上锁行出现，带能力标签，点击发起订阅而不是选中，订阅后不再有上锁的行；标题旁未订阅时显示「去订阅」链接，订阅后显示后端下发的套餐名。 (verification: renderer + Electron)
- AC4 — 任意「去订阅」触点都会打开门户，并永久消除账户头像红点；未登录用户会先发起 Cherry 账号登录，再打开门户；登录失败和门户打开失败都显示各自的具体提示。 (verification: renderer)
- AC5 — 支付完成后，窗口重新获得焦点会刷新套餐和模型，同一账号新生效的付费权益只弹出一次写明套餐名的提醒。 (verification: renderer + Electron)
- AC6 — 当前对话或 Agent 模型额度用完时，输入框上方的提示条显示恢复时间，以及免费模型或付费模型对应的按钮，且不提示升级；发送不发出请求并保留草稿；切换到可用模型后提示条消失。 (verification: renderer + Electron)
- AC7 — 用量区块把 30 天滚动窗口和 `subscription_month` 窗口标为「月度用量」，并按 `next_recovery_at` 或 `period_end` 显示恢复时间；带 `subscription_month` 窗口的套餐响应能通过校验。 (verification: unit + renderer)
- AC8 — 客户端任何界面都不出现写死的套餐名、价格、续费日期或首月优惠。 (verification: renderer)
- AC9 — 账户面板未订阅时显示蓝色「去订阅」；订阅后显示套餐名、剩余最少的额度百分比，悬停弹出按窗口展示用量的卡片，并可跳到用量页。 (verification: renderer + Electron)
- AC10 — 只有 `MAIN_VITE_CHERRY_CLOUD_API_ORIGIN` 配置的 origin 上，纯 HTTP 授权链接才会被接受；其他 HTTP origin 仍被拒绝。 (verification: unit)

## Risks

- 上锁的行需要后端在 `available_plans[]` 上新增 `models`；上线前，分组只显示标题旁的链接。
- 订阅模型的 `available_features` 必须包含 `agent`、`chat` 和 `translate`；只给 `chat` 不给 `translate` 的模型不会出现在任何选择器里，国内联调后端目前就是这样。
- 国内版全新账号如果没有任何 Cloud 模型、后端也没给套餐模型清单，选择器里就没有 Cherry AI 分组，也就没有「去订阅」入口；账户面板和红点仍然有。
- FAQ 网址和 `cherrystudio://` 回跳格式仍需与网页同学对齐；即使没有回跳链接，获得焦点时的刷新也能生效。
- 国内版 Onboarding 打开 Cherry 账号登录，会改变 #20155 选定的默认行为；CherryIN 仍作为服务商保留在设置中。
- 红点会出现在所有没有付费权益的用户面前，包括只用自己服务商的用户。
- 开发用的 HTTP 豁免信任的是掌控构建时覆盖项的人，发布构建绝不能设置它。

# Agent Note: 分批将智能体会话导出为 Markdown 文件

Status: proposed

[English](2026-11-21-agent-session-markdown-export.md) | 中文

## Problem

一位用户排查会话加载缓慢的问题时，测得一个包含 398 条消息的智能体会话占用 303 MB 存储空间。导出这类会话时，Cherry Studio 目前会在渲染进程中收集所有分页数据，并发转换消息，再将整个会话拼成一个 Markdown 字符串。如果没有配置导出目录，保存对话框要到这时才会打开。即使用户取消保存，也已经付出了读取和转换全部消息的代价。报告中的 303 MB 是已存储的输入数据量，导出文件时的内存峰值仍需测量。[会话大小报告](https://github.com/CherryHQ/cherry-studio/issues/24555) · [导出跟踪议题](https://github.com/CherryHQ/cherry-studio/issues/25052)

## Proposal

智能体会话菜单中有两项操作可将会话保存为本地 Markdown 文件，其中一项包含推理过程。两项操作都采用以下流程。

1. 读取第一页消息之前确定保存位置。如果已配置 Markdown 导出目录，沿用带时间戳的文件名。否则，由主进程在发起导出的窗口中显示系统保存对话框。选定文件后，已有文件的内容保留至导出成功。
2. 开始读取时记下当前会话分支的末条消息。按时间顺序分批读取该分支，读到记下的消息为止。每批写入后即释放该批消息数据。保留跨批次引用所需的信息，以便后续回答仍能引用早先的搜索结果。沿用现有的 Markdown 格式、推理过程和引用的导出设置，以及消息所属的模型信息。
3. 处理消息时显示进度，并允许用户在导出期间取消。在目标目录中写入临时文件，最后一次写入成功后才将完整文件保存到目标路径。取消或失败时清理临时文件，允许再次导出。

## Alternatives considered

- 以空字符串调用现有的保存对话框，会在读取会话之前创建或清空所选文件。将选择路径与写入分开，即使读取后续页面失败，原有的导出文件也能保留。
- 单靠数据库分页查询，渲染进程拼接结果时仍要在内存中保留所有页面。分批写入还可以省去额外构建完整 Markdown 字符串的开销。
- 只导出最近的消息，会遗漏完整归档所需的早期对话和引用来源。

## Acceptance criteria

- AC1 — 未配置导出目录时取消保存对话框，导出流程不会请求任何一页会话消息，也不会创建文件。已配置目录时，执行一次导出就会生成一个带时间戳的 Markdown 文件，期间不弹出对话框。 (verification: renderer export tests and desktop save-dialog check)
- AC2 — 导出一份跨多页的会话测试数据，后面某页的回答引用较早页面中的来源。对每种推理过程选项和引用设置，导出文件均与现有 Markdown 输出逐字节一致，首条、末条消息都在正确的位置。未选中的同级分支消息，以及开始读取后追加的对话轮次，都不会写入文件。 (verification: renderer export integration tests)
- AC3 — 比较两个合成会话的导出过程。两者的页数相差十倍，单条消息的最大尺寸和引用数量相同。分别记录现有流程与拟议流程的渲染进程内存峰值。对分页读取和写入进行检测，验证每批写完后都会释放该批消息数据，且在读取最后一页之前就已经开始写入。 (verification: export integration tests and desktop memory profile)
- AC4 — 观察导出进度是否持续推进，至少写完一批后，使用界面上可见的取消操作终止导出。另行模拟后续的读取或写入失败。每种情况下均停止安排后续页面的处理，保留目标文件的原始字节，并删除本次导出的临时文件。随后再次导出可以成功。 (verification: main-process file tests and desktop cancellation check)

## Risks

当前的会话游标从新到旧遍历消息，每读一页都会重新确定当前分支的末条消息。改为从旧到新读取时，必须沿选定分支遍历，并在到达开始读取时记下的末条消息后停止。长会话中的单次工具调用就可能返回大量数据，后面的回答也可能引用第一轮对话。记录内存峰值时，同时报告单条消息的最大尺寸和引用数量，以便判断分批处理的实际效果。写入临时文件和保存最终文件时，都应沿用现有的文件写入保护。各桌面平台处理已打开文件的方式不同，需要在所有受支持的桌面平台上验证替换已有文件的行为。

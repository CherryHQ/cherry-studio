# Agent Note: 智能体与助手的分页式编辑弹框

Status: proposed

[English](2026-11-12-resource-edit-pages.md) | 中文

## 问题

智能体和助手的编辑弹框（`src/renderer/components/resourceCatalog/dialogs/edit/AgentEditDialog.tsx`、`AssistantEditDialog.tsx`）共用 `EditDialogShell`：一个较宽的弹框，左侧是一列页签。所有设置都在同一层级：基础信息、系统提示词、工具、技能、知识库、MCP、提示词绑定、记忆和高级参数。用户分不清哪些设置重要，运行时、Plan 模型、Small 模型这类很少改的字段就摆在名称旁边，而有些智能体设置根本不在弹框里：IM 频道只在全局设置里，智能体的定时任务只在定时任务页里。

设计原型（`bot-profile-cherry`）用一个窄的分页式弹框代替左侧页签。[创建流程](2026-11-12-resource-auto-create.md)复用同一套能力列表和完整系统提示词预览，[对话页资料面板](2026-11-12-chat-profile-pane.md)会直接跳到这些页面。

## 提案

### 分页外壳

编辑弹框改为带页面栈和返回按钮的窄弹框。主页面是入口；「更多设置」列出分组卡片；每项能力打开一个二级页。从二级页返回回到更多设置，从更多设置返回回到主页面。弹框保留现有的自动保存（500 ms 防抖）、关闭时 flush 和名称校验。头像、频道、任务、心跳任务和记忆仍通过各自现有的 IPC 和 DataApi 调用即时保存。

### 主页面

- 居中的大头像。点击打开现有的头像选择器，仍支持上传图片。
- 名称以大号无边框文字显示，下面一行简介。两者悬停和聚焦时显示浅底，名称为空时仍显示必填提示。
- 一行显示模型（chip 样式）和「更多设置 ›」链接。

去掉运行时这一行。去掉 Plan 模型和 Small 模型字段；修改模型时清空这两个字段，让它们跟随主模型。

### 更多设置：智能体

分组卡片，每行左边是名称，右边是控件或摘要：

- **能力。** 内置工具 ›、技能 ›、知识库 ›、MCP 服务 ›、频道 ›、定时任务 ›。每行显示 `已启用 X / Y`；知识库显示 `已关联 X / Y`。
- **运行。** 权限模式和回复语言。
- **心跳。** 心跳开关；打开后显示间隔和最长执行时间；以及「编辑心跳任务」，显示心跳文档中有几条任务。
- **高级。** 系统提示词 ›（已填写或未填写）、记忆 ›、环境变量。

计数规则：内置工具按运行时的工具计数（已应用知识库工具的显示规则），不含浏览器控制和电脑操作；技能把内置技能算作已启用；MCP 不含浏览器服务；定时任务只算正在运行的任务。

### 更多设置：助手

- **能力。** 知识库 ›；MCP 模式（自动、手动、禁用），手动时多一行「MCP 服务 ›」；浏览器。
- **回答。** 温度、Top-P、最大 Token，各是一个开关，打开后出现滑块或输入框；流式输出；最大工具调用次数；自定义上下文 ›（消息条数以及现有的压缩和截断设置）；自定义参数 ›。
- **高级。** 系统提示词 › 和分组。

### 二级页

- **系统提示词。** Pi Durable 上的智能体使用创建流程 Spec 中定义的完整系统提示词预览，只有智能体自己的指令可编辑。其他运行时的智能体和助手使用现有的提示词编辑器，带生成、润色、预览和变量。
- **内置工具、技能、知识库、MCP 服务。** 使用创建流程 Spec 中的共享能力列表。内置技能锁定为开启。
- **频道（智能体）。** 列出绑定到这个智能体的频道，每项显示平台图标、名称、连接状态、一行摘要、编辑、删除和启用开关。「添加频道」列出所有支持的平台。配置对话框复用现有的频道表单，把频道绑定到这个智能体，并隐藏智能体选择。扫码登录在对话框里完成。设置 › 频道保留为全局视图。
- **定时任务（智能体）。** 列出这个智能体的任务，带暂停开关、执行频率摘要和上次运行。「新建任务」和每一行都打开现有的任务表单，智能体固定为当前这个；编辑时还显示运行历史、立即运行和删除。
- **记忆（智能体）。** 现有的记忆面板。有未保存的修改时离开会要求确认，和现在切换页签时一样。

### 回复语言

用一个下拉框代替分段控件和组合框：跟随全局设置（显示其当前值，全局为空时显示「跟随会话语言」）、不限制、预设语言，以及「其他语言…」，选它时出现一个 1–50 个字符的单行输入框。写入现有的 `languageMode` / `languageCustom` 映射。创建流程使用同一个组件。

### 移除

- 运行时这一行，以及 Plan 模型和 Small 模型字段。
- 提示词绑定页签。绑定在输入框里照常可用；输入框的「管理当前」入口去掉，它现有的「管理全部」入口打开设置 › 提示词。

### 深链

现有的 `initialTab` ID 继续可用，打开对应页面：`basic` 打开主页面；`prompt` 打开系统提示词；`tools.builtin` 打开内置工具（助手：更多设置）；`tools.skills` 打开技能；`tools.knowledge` 打开知识库；`tools.mcp` 打开 MCP 服务（助手：更多设置）；`advanced` 打开更多设置；`memory` 打开记忆。新增的 `channels` 和 `tasks` 打开对应二级页，因此频道绑定提案中智能体列表的「连接到 IM…」会落到频道页。

### 与频道绑定提案的关系

[智能体范围的 IM 频道绑定入口](2026-11-08-agent-channel-binding-entry-points.md)提议在频道页签里按平台放开关。本 Spec 部分取代它：智能体的频道页是已绑定频道的列表，带完整配置，而不是每个平台一个开关，因此一个智能体可以有同一平台的两个频道，也能不离开弹框就启用频道。它提出的智能体列表菜单入口、保持不变的全局设置 › 频道、以及唯一的创建代码路径都保留。

## 备选方案

- **只给现有的左侧页签换样式。** 所有设置仍在同一层级，问题依旧。
- **把运行时、Plan 模型和 Small 模型保留为高级字段。** 它们很少被修改；产品正走向每个智能体一个模型、不提供运行时选择。数据保留，日后若有新决定可以恢复。
- **删掉原型没画的助手字段**（最大工具调用次数、自定义参数、压缩和截断）。这些字段仍在使用；收进二级页既能让主界面简短，又不减少功能。
- **按平台的频道开关。** 见上面的关系说明。
- **智能体范围的任务表单保留工作区字段。** 任务 schema 要求工作区，所以表单保留这个字段，默认为系统工作区。

## 验收标准

- AC1 — 打开智能体或助手的编辑弹框，显示主页面：头像、名称、简介、模型 chip 和更多设置，没有运行时、Plan 模型或 Small 模型字段 (verification: renderer; owner: implementer)
- AC2 — 更多设置显示各类型的分组卡片，从行进入二级页，返回回到上一页且不关闭弹框 (verification: renderer; owner: implementer)
- AC3 — 能力行按本 Spec 的计数规则显示 `已启用 X / Y`（知识库为 `已关联 X / Y`） (verification: renderer; owner: implementer)
- AC4 — 任何页面上的修改都会自动保存，关闭弹框会 flush 未保存的修改，空名称永远不会被保存 (verification: renderer; owner: implementer)
- AC5 — 修改智能体的模型会清空它的 Plan 模型和 Small 模型 (verification: unit; owner: implementer)
- AC6 — 频道页只列出这个智能体的频道，在这里添加的频道绑定到这个智能体，开关或删除后全局设置 › 频道同步更新 (verification: renderer and Electron; owner: implementer)
- AC7 — 定时任务页只列出这个智能体的任务，暂停和恢复会更新任务，在这里打开的任务表单固定为这个智能体，编辑时提供运行历史、立即运行和删除 (verification: renderer; owner: implementer)
- AC8 — 回复语言下拉框能写入继承、不限制、预设语言或自定义语言，自定义输入框只在选「其他语言…」时出现 (verification: renderer; owner: implementer)
- AC9 — 提示词绑定页签已移除，输入框不再提供「管理当前」，其「管理全部」入口打开设置 › 提示词 (verification: renderer; owner: implementer)
- AC10 — 每个现有的 `initialTab` ID 以及新增的 `channels`、`tasks` 都打开本 Spec 映射的页面 (verification: renderer; owner: implementer)
- AC11 — 记忆页有未保存的修改时离开会要求确认 (verification: renderer; owner: implementer)
- AC12 — 所有新增界面文案在全部渲染进程语言包中都有翻译，没有占位符 (verification: docs gate; owner: implementer)
- AC13 — 在运行中的应用里，通过每个二级页编辑过的智能体，重启应用后修改仍然保留 (verification: Electron; owner: implementer)

## 风险

- 编辑弹框的测试大量依赖页签 ID，需要大幅重写。
- Plan 或 Small 模型与主模型不同的智能体会一直保留这些值，直到模型被修改；界面上看不到它们。
- 把频道管理放进智能体，会和设置 › 频道部分重复。两处使用同一个频道表单组件，避免逐渐不一致。
- 移除提示词绑定页签后，已有的绑定没有按对象管理的入口。实现层必须确认之后如何移除绑定，或在输入框里保留一个最小的移除入口。

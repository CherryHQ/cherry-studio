# Agent Note: 地区小程序会话归属

Status: proposed

[English](2026-11-14-regional-mini-app-sessions.md) | 中文

## 问题

网页小程序共用默认会话，没有独立的国家配置。地区会话需要明确宿主授权、登录数据保留和全局代理切换的约定。代理切换后，现有连接可能仍使用旧线路。

## 提案

为网页小程序增加可选的国家配置。本提案等待上游审查。功能默认关闭，并要求启用开发者模式。

每个网页小程序可以选择一个国家。持久 partition 按小程序 ID 和国家区分。兼容早期实验版本时，保留其 partition 名称和已保存的登录数据。

准备租约绑定受管理的宿主窗口、已存在的网页小程序及所选国家。附加网页必须持有有效租约。释放最后一个租约时，移除运行期登记并关闭地区网页。撤销授权时保留持久登录数据。本地安装型小程序继续使用独立沙箱和网络策略。

明确执行重置时，先关闭网页，并在存储、Worker、HTTP 缓存和代码缓存清理完成前阻止准备操作。删除自定义网页小程序时，先清理地区数据再删除记录。重置不清理共享的默认网页会话。

地区会话继承全局代理。协调配置期间，请求在有时限的门控处等待。配置和旧连接关闭成功后，门控恢复放行。配置错误会拒绝等待中的请求。明确选择的直连和用户绕过规则继续有效。该功能不选择 IP 国家，也不承诺匿名。已经接收的数据无法撤回。

## 考虑过的替代方案

- 停用时自动删除数据：未采用，因为切换配置时需要保留登录状态。
- 每个代理共用一个 partition：未采用，因为同一线路上的不同小程序可能需要独立账号。
- 每次切换代理都查询外部 IP 服务：未采用，因为该服务的可用性不应控制所有网页访问。

## 验收标准

- AC1 — 两个网页小程序可以分别保留不同国家，现有实验版本的地区选择保留 Cookie（验证：unit, renderer, Electron）。
- AC2 — 非受管理宿主、其他宿主窗口、已撤销租约和本地安装型小程序不能附加地区会话（验证：unit, Electron）。
- AC3 — 关闭或停用地区小程序时释放运行期登记，同时保留登录数据（验证：unit, Electron）。
- AC4 — 重置和删除期间阻止并发附加，并清理全部地区 Cookie、存储和缓存，不影响默认会话（验证：unit, renderer, Electron）。
- AC5 — 代理切换期间的请求等待最终配置和旧连接关闭，配置失败时请求被阻止（验证：unit, Electron）。
- AC6 — 代理变更保留本地小程序的拒绝全部网络策略，并遵循明确选择的直连和绕过设置（验证：unit, Electron）。
- AC7 — 改动相关测试、类型检查、格式、lint、翻译和文档检查通过（验证：docs gate, unit, renderer）。

## 风险

关闭连接会中断流式请求和 WebSocket，网站需要按自身逻辑重连。切换前已经发出的请求可能已经到达旧线路。系统 PAC 和明确配置的绕过规则可以选择直连。会话清理使用受支持的 Chromium API，不直接删除运行中的 partition 目录。

系统代理配置沿用现有的一分钟刷新。PAC 脚本内部或远端代理节点的变化可能不会体现在配置比较中，本功能不承诺立即检测这些变化。

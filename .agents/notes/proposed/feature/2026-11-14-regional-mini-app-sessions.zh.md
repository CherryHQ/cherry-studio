# Agent Note: 地区小程序会话归属

Status: proposed

[English](2026-11-14-regional-mini-app-sessions.md) | 中文

## 问题

网页小程序共用默认会话，没有独立的国家配置。地区会话需要明确宿主授权、登录数据保留和全局代理切换的约定。代理切换后，现有连接可能仍使用旧线路。

## 提案

为网页小程序增加可选的国家配置。本提案等待上游审查。功能默认关闭，并要求启用开发者模式。

每个网页小程序可以选择一个国家。持久分区以国家和小程序原始 ID 的固定长度 SHA-256 摘要命名，计算摘要时保留 ID 的大小写。同一个小程序在不同窗口选择同一国家时，共用该分区。仅大小写不同的 ID 使用不同分区。

早期实验版本保存的国家选择会迁移。新分区从空白存储开始，用户可能需要重新登录。只有其他已保存的网页小程序未共用旧分区名时，手动重置或删除小程序才可以清理按小写 ID 命名的旧分区。

准备租约绑定受管理的宿主窗口、已存在的网页小程序及所选国家。附加网页必须持有有效租约。释放最后一个租约时，移除运行期登记并关闭地区网页。撤销授权时保留持久登录数据。本地安装型小程序继续使用独立沙箱和网络策略。

手动重置时，关闭地区网页并阻止新会话准备。重置会清理网页存储、Worker 注册、HTTP 缓存、代码缓存和缓存的 HTTP 认证凭据。恢复准备前会检查是否残留 IndexedDB 文件。清理失败或中断时，阻断状态会在重启后保留，直至重试成功。删除自定义网页小程序时，先清理地区数据再删除记录。共享的默认会话和其他小程序的数据会保留。

地区会话继承全局代理。切换期间，Electron 拦截到的会话请求会等待，等待时间和队列长度都有上限。配置应用成功且连接池中的连接关闭后，等待的请求才会放行。配置错误会拒绝等待中的请求。明确选择的直连和用户配置的绕过规则继续有效。公网 IP 由全局代理及其路由规则决定。

## 考虑过的替代方案

- 停用时自动删除数据：未采用，因为切换配置时需要保留登录状态。
- 每个代理共用一个 partition：未采用，因为同一线路上的不同小程序可能需要独立账号。
- 每次切换代理都查询外部 IP 服务：未采用，因为该服务的可用性不应控制所有网页访问。

## 验收标准

- AC1 — 两个网页小程序可以分别选择不同国家。早期实验版本的选择会迁移。仅大小写不同的 ID 使用不同分区（验证：unit, renderer, Electron）。
- AC2 — 非受管理宿主、其他宿主窗口、已撤销租约和本地安装型小程序不能附加地区会话（验证：unit, Electron）。
- AC3 — 关闭或停用地区小程序时释放运行期登记，同时保留登录数据（验证：unit, Electron）。
- AC4 — 重置和删除会阻止附加，并通过会话 API 清理地区数据。默认会话和其他小程序的数据会保留。清理失败后，阻断状态会在重启后保留（验证：unit, renderer, Electron）。
- AC5 — 代理切换时，Electron 拦截到的请求等待配置应用和连接池中的连接关闭。配置失败时阻止这些请求（验证：unit, Electron）。
- AC6 — 代理变更保留本地小程序的拒绝全部网络策略，并遵循明确选择的直连和绕过设置（验证：unit, Electron）。
- AC7 — 改动相关测试、类型检查、格式、lint、翻译和文档检查通过（验证：docs gate, unit, renderer）。

## 风险

关闭连接池中的连接可能中断流式请求。无关联网页帧的 Worker 发起的 WebSocket 握手会绕过请求门控。已经升级的 WebSocket 连接可能仍走旧线路。切换前已经发出的请求可能已经到达旧线路。系统 PAC 和明确配置的绕过规则可以选择直连。重置通过 Electron 会话 API 清理数据，并保留运行中的分区目录。

SharedWorker 启动时的 `navigator.language` 使用所选地区的语言。如果最初的客户端关闭后，其他客户端继续使用该 Worker，它的 `Intl` locale 和时区可能发生变化。

系统代理配置沿用现有的一分钟刷新。PAC 脚本内部或远端代理节点的变化可能不会体现在配置比较中，本功能不承诺立即检测这些变化。

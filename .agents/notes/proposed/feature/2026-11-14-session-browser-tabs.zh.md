# Agent Note: 会话归属的浏览器多标签页

Status: proposed

[English](2026-11-14-session-browser-tabs.md) | 中文

## Problem

右侧浏览器对每个 Agent Session 或普通对话 Topic 仅保留一个页面。打开文档、开发预览或 HTML 产物会替换之前的页面。单一 guest 绑定也使 Agent 无法在用户阅读另一页时继续定位原页面。

## Proposal

文件和浏览器继续作为独立的侧栏能力。文件负责工作区导航和编辑；浏览器负责网页导航、浏览历史与受控网页实例。展示层可以复用组件，合并资源模型不在本次范围内。

每个会话拥有一个有序、仅存于内存的页面集合和一个可见页面。每页分别具有稳定的 renderer 页面 ID 和可独立撤销的主进程 guest 绑定 ID。应用路由标签仍拥有会话页面集合。收起侧栏或切换可见页保留 guest 和页面状态。Agent 集合延续已有的活跃轮次生命周期。

手动首次打开及新建标签遵循空白页、自定义首页或上次页面设置。上次页面按会话分别记忆，仅由选中的普通网页更新；显式网址及自动化创建的页面保留请求的目的地。地址栏导航作用于可见页。消息链接复用网址和安全配置相同的页面，否则创建页面。显式新建标签允许重复。HTTP(S) 弹出请求在来源会话内创建页面，并遵循后台标签意图。POST 以及预览、产物的弹出请求沿用已有约束。开发预览按预览身份更新，不抢走用户选择。HTML 产物保留逐文件授权和独立分区。

Agent 句柄绑定精确的 guest，独立于用户选择。每个已取得的页面分别保留观察租约，直到页面或控制会话关闭，因此观察其他页面不会使其元素引用失效。REPL 支持枚举页面、取得指定标签以及新建标签。每次操作检查会话归属和权限。关闭或替换 guest 使旧句柄失效并中断其工作；旧句柄绝不转向相邻页面。鼠标和键盘操作通过已有侧栏自动打开偏好请求展示目标页面。后台执行语义和权限检查仍由浏览器引擎负责。

文件和浏览器使用同一套侧栏标签组件，共用中性的选中背景与尺寸。标签条保持单行，新建入口固定可见，仅在页面放不下时显示溢出菜单，并保持选中页可见。加载停止后显示站点图标；地址建议使用本地缓存的 favicon，无可用图片时回退为地球图标。浏览器标签的上下文菜单提供将已提交网址在顶部独立浏览器标签页或新窗口打开、复制链接、在外部浏览器打开 HTTP(S) 页面，以及关闭被右键页面、其他页面、右侧页面或当前会话全部页面的操作，不包含刷新。在其他位置打开会保留来源页面；右键后台页面保持当前选择。溢出列表提供相同菜单。批量关闭包含隐藏页面，并保留仍然存在的选中页；选中页被关闭时优先选择右侧最近的保留页，再选左侧。

最大化和收起按钮放在标签栏内，不再单独显示浏览器标题行。关闭当前页优先选择右邻，再选左邻；关闭最后一页或全部页面时直接关闭右侧边栏。键盘导航、关闭动作、加载状态与无障碍名称在两种主题下均可用。运行中页面标识允许用户返回 Agent 目标。

## Alternatives considered

- 立即合并文件和浏览器：混合可编辑文件生命周期、工作区导航和网页控制，扩大范围却未解决页面定位。
- 只增加视觉标签条：保留单 guest 限制，每次切换仍丢失页面状态。
- 每次 Agent 操作都跟随用户当前页：一次无关的界面切换即可重定向已绑定操作。
- 重启后持久化并恢复页面集合：需要独立的持久化与恢复策略；本次保持已有进程生命周期。

## Acceptance criteria

- AC1 — 同一会话的多个页面在切换网页、侧栏能力或会话时保留各自 guest 和状态，其他会话不会继承页面。（verification: runtime/host tests and Electron; owner: renderer browser）
- AC2 — 窄侧栏内可以新建、切换、关闭、访问溢出标签并使用键盘；关闭最后一页或全部页面时关闭右侧边栏，仍有页面时保持侧栏打开。（verification: real UI component tests and Electron; owner: renderer browser）
- AC3 — 地址栏导航保留在当前页，消息链接新建或复用页面，预览更新保留用户选择，允许的弹出请求留在来源会话。（verification: affected consumer/registry tests and Electron; owner: browser integration）
- AC4 — 用户切换网页后 Agent 句柄仍定位原页；指定页面与新建页面可用；已关闭、替换或跨会话句柄明确失败且不操作其他页面。（verification: main-process protocol and REPL tests; owner: browser control）
- AC5 — 浏览器权限、分区隔离、逐文件授权、活跃轮次保留及取消机制继续按 guest 生效。（verification: affected main/renderer tests and Electron; owner: browser lifecycle）
- AC6 — 运行中页面状态、翻译标签、可见焦点以及加载和空态在明暗主题下均可用。（verification: component tests, locale checks and Electron; owner: renderer browser）

## Risks

保留更多 guest 会增加内存占用。闲置回收不得静默丢弃用户页面状态或活跃操作。主进程替换绑定不得改变其他页的身份。弹出请求沿用现有限制，不承诺依赖 opener 的认证流程或 POST 流程。正式 Spec PR 审批以及 implemented 生命周期转换与本地实现验证分别记录。

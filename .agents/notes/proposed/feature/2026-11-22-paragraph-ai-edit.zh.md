# Agent Note: 助手回复中的段落级 AI 编辑

Status: proposed

[English](2026-11-22-paragraph-ai-edit.md) | 中文

## Problem

Issue #13304 请求仅对选定段落进行 AI 辅助编辑，例如缩短文字或修正语法，而不是重新生成整条回复。将文字复制到新提示中会丢失原始位置，用户还需要手动整合结果。

现有选区工具栏和右键菜单会提取文本用于复制、引用及保存到 Notes，但没有稳定的写入目标。`ChatMarkdown` 渲染消息文本部分，而普通 Chat 与 Agent 会话适配器分别负责持久化和编辑权限。现有主题消息编辑操作替换整个 parts 数组，不是比较并交换式的段落操作。

## Proposal

### Eligible target and source identity

在持久化 Chat 主题或 Agent 会话中，当选区位于一条已完成、可编辑的助手文本部分的单个合格段落内时，在选区工具栏和右键菜单提供 Edit with AI。选中段落的一部分即以整个段落为编辑单位；发送模型请求前，面板明确预览完整目标段落。同时支持键盘选区和键盘调用。

资格遵循现有领域编辑权限，包括 Agent 历史限制和运行中保护。用户消息、生成中回复、思考、工具输出、代码块、表格、独立 HTML 预览，以及跨段落或跨消息选区均不是目标。包含引用标记或无法可逆映射到源文本的公式／嵌入内容的段落，显示不可用原因，不进行扁平化或猜测。这不是通用 Canvas 工作区或文件编辑器。

目标携带所有者类型、主题／会话 ID、消息 ID、文本部分身份、源范围，以及从规范消息数据捕获的内容修订号／哈希。渲染必须暴露合格段落的源映射。DOM 文字、文本搜索及首次匹配位置不是写入坐标。重复段落、行内 Markdown、转义文字、Unicode 和多个文本部分也必须准确对应唯一规范范围。预处理破坏映射时不提供该操作。

### Request and review

打开一个共享行内审阅面板，包含原始段落、指令输入、可见的模型选择器、Generate 和 Cancel。若生成原回复的模型仍配置且支持文本，初始选中它；否则要求明确选择可用模型。打开面板不发送请求。Generate 仅发送目标段落的原始 Markdown、指令，以及同一文本部分中相邻段落各最多 500 个 Unicode 字符，后者标记为只读上下文。Generate 前展示上下文及范围。不发送整段对话、附件、工具、凭据或其他消息部分。

Main 通过现有模型／服务商解析和流基础设施负责独立、可取消、仅文本的生成操作，借鉴一次性翻译的职责划分，但不修改翻译协议。除选定服务商请求外，没有工具执行或文件／网络能力。目标与上下文作为引用数据，不得用来扩大操作范围。用量记入所选模型和本次操作，与原始回复的生成统计分开。

流式输出仅写入面板中的建议，不在生成时覆盖消息。显示错误并允许重试，原文保持不变。取消、离开页面、目标删除或面板卸载会终止所拥有的请求；迟到片段不能重新打开面板、修改其他选区或写入消息。每个编辑所有者仅有一个面板／请求，生成身份阻止旧结果被重新使用。

生成后对比原文与替换内容，允许用户在 Apply 前编辑建议 Markdown。空结果不能应用。重试仅丢弃上次建议。取消丢弃建议并恢复焦点／阅读位置。应用始终是独立的明确操作，不重新生成后续消息，也不触发另一模型调用。

### Safe persistence and undo

领域适配器向 Main 拥有的变更发送明确的段落替换。在一个数据库事务内，Main 检查所有者／消息访问、当前编辑权限、终态、源身份／修订号、精确旧范围及预期旧文本，然后只替换该范围。修订过期、消息移动／删除、文本部分改变或执行新启动时，拒绝写入，保留建议供复制或主动重新选择。不得静默重新匹配相似文本或覆盖并发编辑。

选定范围之外的文本字节和非派生的非目标部分保持不变。下述派生翻译／上下文失效是明确例外。保留消息身份、树／兄弟关系、其他模型回复、投递来源和原始用量记录。按照既有编辑语义使已变文本的服务商／引用／输入快照派生元数据失效；不保留过期生成项 ID 或虚构引用有效性。通过领域现有编辑失效路径处理派生翻译／上下文状态，并在面板中说明影响。不得把渲染器整个数组的补丁当作并发保护。

Apply 成功后提供针对该次编辑的一步 Undo。Undo 以应用后的修订号和精确替换范围为前提；仅在没有后续变更时恢复原始源和该编辑所失效的对应元数据，否则拒绝覆盖新内容。应用内容在重新加载后保留。建议和撤销句柄无需跨应用重启保存，面板不得承诺持久历史。

### Ownership and delivery

共享选区／消息模块负责捕获与审阅界面。Chat 与 Agent 适配器提供领域权限、目标读取、应用和撤销能力。Main 负责服务商调用、取消、输入校验、比较并交换式写入及既有历史失效。共享 schema 只包含跨进程契约；仅渲染器使用的映射辅助代码保留在渲染器层。

分层交付：先实现源定位和受保护持久化，再实现生成／审阅界面，最后完成两个领域适配器及原生验收。所有条件获得实际证据前保持 proposed。不包含整体编辑器替换、自动接受、外部文档变更、批量编辑、自主工具调用或整条回复重写。

## Alternatives considered

- 将选区引用到普通提示：简单，但会发送对话上下文并保留手动整合，未解决核心问题。
- 替换存储回复中首次匹配的文字：会改坏重复段落，且无法防御并发编辑。
- 修改渲染 DOM：不持久，重新渲染时丢失 Markdown／源语义。
- 用过期 parts 数组复用整条消息保存：可能覆盖新文字或无关部分。
- 先添加完整 Canvas 编辑器：范围远大于请求的段落操作。
- 自动应用流式输出：没有审阅，可能持久化不完整或失败内容。

## Acceptance criteria

- AC1 — 在持久化 Chat 与 Agent 回复中，鼠标和键盘选区为准确的合格段落打开一个可访问审阅面板；不支持或不可编辑的选区解释不可用原因。 (verification: renderer and Electron)
- AC2 — 重复段落、Unicode、行内 Markdown、多个部分和预处理边界均定位正确规范范围或安全拒绝，不接受 DOM／文本搜索猜测。 (verification: unit and renderer)
- AC3 — 打开面板不请求模型；Generate 使用可见的选定模型，仅发送目标、指令及展示的有界相邻上下文，禁用工具并独立记账。 (verification: main and renderer)
- AC4 — 流式结果始终为建议；重试、服务商失败、取消、所有者改变和迟到结果均不修改回复或其他面板。 (verification: main, renderer and Electron)
- AC5 — 明确 Apply 只更新一个源范围，保留其他文本／部分、兄弟／树身份和原始用量，并在两个领域中正确使已变文本派生状态失效。 (verification: database and renderer)
- AC6 — 并发编辑、目标删除／移动、资格改变和重复提交具备事务安全；拒绝时保留建议，不重新匹配或覆盖新内容。 (verification: database and renderer)
- AC7 — 应用编辑在重新加载后保留；Undo 仅在应用后修订号匹配时恢复旧范围，发生后续变更则拒绝。 (verification: database and Electron)
- AC8 — 双语、焦点／阅读连续性的无障碍体验、窄宽度／深浅色、服务商错误及既有复制／引用／Notes／手动编辑流程通过定向检查和原生验收，并明确报告未验证边界。 (verification: renderer, docs gate and Electron)

## Risks

源文本与渲染内容的映射是主要正确性边界。Markdown 转换和重复文字使视觉选区不足以定位。第一层必须证明可逆定位后，生成界面才能被视为安全。

并非所有历史 Agent 输出都允许编辑。复用 Main 的历史资格与缓存失效，不增加绕过路径，也不假设与主题消息相同。渲染器能力标志仅提示展示，不是最终写入授权。

段落编辑会改变未来对话上下文，并可能使派生翻译或上下文摘要失效。保留未受影响内容，解释这些影响，不得仅因引用标记仍存在就声称旧引用支持重写后的文字。

模型调用产生已配置服务商的用量。Generate 是明确操作，模型／上下文范围可见，不进行后台重试。本 Spec 不执行调用，也不保证价格或 token 节省。

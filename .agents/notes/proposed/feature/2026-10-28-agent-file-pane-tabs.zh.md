# Agent Note: Agent 文件面板标签页与面包屑

Status: proposed

[English](2026-10-28-agent-file-pane-tabs.md) | 中文

## Problem

Agent 文件面板打开文件时，会用铺满整个面板的浮层盖住目录树。面板 header 也变成带返回箭头的"二级页面"，在文件之间切换只能来回进出。点击文件内的链接（例如 Markdown 引用）会替换当前文件，返回路径存放在一条用户看不到的返回链里。

目录树还把工作区包在一个合成的根节点下，文件名也比同级文件夹名多缩进一级。

## Proposal

布局参照 ChatGPT 的文件面板。

### 布局

- **宽面板（不小于 672px）：** 目录树在左侧，默认宽 256px，打开的文件占右栏。拖动目录树右边缘可在 180px 到 480px 之间调整宽度；宽度保存在 renderer 持久化缓存中（`ui.agent.file_pane.tree_width`），对所有工作区生效。目录树保持可见，并高亮当前文件。没有打开文件时，右栏显示"打开文件"空状态。
- **固定目录树（宽面板）：** header 左侧的开关用于固定或取消固定目录树。取消固定时隐藏目录树：打开的文件铺满面板，没有打开文件时显示空状态。该选择按工作区记在 renderer 持久化缓存中（`ui.agent.file_pane.unpinned_tree_workspaces`，记录取消固定的工作区路径），工作区默认固定。
- **窄面板：** 打开的文件仍像现在这样覆盖目录树。header 左侧的目录树开关可以显示或隐藏目录树，不会关闭标签页，并取代原来的返回箭头。

### Header：文件标签页

- 面板 header 是一行标签页。每个标签页显示文件名、未保存圆点和关闭按钮，当前标签页高亮。右侧只保留面板操作（最大化、关闭），不再有刷新按钮或工作区打开按钮。
- **打开文件**（从目录树、面包屑，或文件内的链接，例如 Markdown 引用）：在当前标签页之后的新标签页中打开。文件已在某个标签页中打开时，切换到该标签页。当前标签页的标题为斜体。标签页变多时先缩小到可读的最小宽度（约十个字符）。仍放不下的标签页移入标签栏末尾的 ▾ 菜单，菜单只列出这些被隐藏的标签页；标签栏本身不滚动。当前标签页始终留在标签栏中，必要时占用最后一个可见位置。
- **关闭：** 切换到相邻标签页。关闭最后一个标签页后显示空状态。
- **切换标签页：** 等同于在目录树中选择该文件。现有编辑会话在文件被切走时会在后台保存草稿，所以切换标签页不会丢失编辑内容。
- **状态：** 标签页由 Agent 右侧面板持有，归属于单个 Agent 会话，切换工作区时清空，重启后不保留。

### 面包屑行

- 在文件上方，右栏以面包屑显示文件相对工作区的路径。工作区外的文件只显示文件名。
- 每一段都可以点开下拉框：目录段显示该目录下的条目，文件段显示文件所在目录的条目。下拉框是一棵小的目录树：目录像面板目录树一样就地展开，展开状态独立，不会改变面板的目录树。选择文件的效果与点击目录树相同（新开标签页，或切换到已有标签页），并关闭下拉框。
- 这一行右端依次是：预览插件的工具栏（只有附件预览才有，例如附件的 Markdown/HTML 预览/源码切换，通过 file-preview 工具栏 portal 显示在这里）、支持引用的文档的引用选区按钮、渲染类文本文件的编辑/预览切换，以及列出所有打开目标的**打开**分体按钮。不提供 ⋯ 按钮（2026-10-29 用户移除），因为打开按钮和右键菜单已覆盖其内容。不再单独提供复制按钮。
- 标签页、面包屑和目录树使用同一套右键菜单布局（参照 ChatGPT）：**作为上下文附加**、**复制 ▸**和打开目标。作为上下文附加会把文件或文件夹加入当前会话的输入框，效果与 `@` 提及该路径相同（同样的标记和附件）；已附加的文件不会重复添加。复制 ▸ 包含文件内容（仅限打开的文件且可按文本复制时）、绝对路径、相对工作区的路径（仅限工作区内的文件）和文件名。打开目标为**用‹默认应用›打开**和**在 Finder 中显示**（其他平台为文件资源管理器 / 文件管理器），其他应用收在**打开方式 ▸**下；打开的文件的打开目标与打开按钮共用同一份缓存查询。
- 面包屑的每一段有自己的菜单：文件段显示文件菜单，目录段显示该目录在目录树中的菜单，因此作为上下文附加的是该目录。目录树不提供“文件内容”，因为它不知道该行文件能否按文本复制。
- 标签页菜单另有**关闭文件**、**关闭其他文件**（多于一个标签页时）和**关闭所有文件**。关闭自动保存时，若要关掉有未保存修改的文件，会像切换标签页一样先询问。ChatGPT 菜单中的“在文件中查找”和“重新加载文件”未提供：查找由编辑器自身的 ⌘F 覆盖，重新加载随刷新一起移除（见下）。“在文件树中显示”于 2026-10-29 被用户移除。
- 面包屑菜单不含关闭项，因为标签页和 Escape 已能关闭文件；所有菜单都不含刷新项（2026-10-29 用户移除）。目录树随文件监听更新；打开的预览或编辑器在文件被外部修改时暂不会自动重新加载。

### 编辑

- 不再提供预览/编辑切换。纯文本文件（由文本预览插件渲染，或没有匹配插件的文件）直接以实时编辑器打开，并自动保存。
- 有渲染预览的文件（HTML、Markdown、图片（含 SVG）、视频、PDF、Word、PowerPoint、电子表格）以预览打开。若同时是文本（Markdown、HTML、SVG）且非只读，**打开**按钮左侧有一个编辑/预览切换，可在预览与同一个实时编辑器（编辑源码）之间来回切换。PNG、PDF、Office 等二进制格式没有该切换。
- 编辑器无法加载的纯文本文件（二进制内容或超过大小上限）回退为预览，不弹出错误提示。

### 面板设置

面板 header 中、面板操作旁边的 ⋯ 菜单承载对所有工作区生效的设置。它们是 Preference（`feature.agent.file_pane.*`）：

| 设置 | 键 | 默认值 | 作用 |
|---|---|---|---|
| 文件树位置 | `tree_position` | `left` | `left` 或 `right`；在宽面板中移动目录树所在列。窄面板不受影响。 |
| 自动保存 | `auto_save` | 开 | 关闭后，输入时不再保存。文件有未保存修改时，面包屑行右侧出现**取消**（放弃）和**保存**按钮，⌘S / Ctrl+S 保存。切换到其他文件或关闭其标签页时，会询问*放弃未保存的更改？*，提供**继续编辑**和**放弃**。其他离开方式（切换 Agent 会话、关闭面板）仍会保存，不会悄悄丢失修改。 |
| 按 Tab 键缩进 | `tab_indent` | 开 | 关闭后，Tab 移动焦点而不缩进。 |
| 自动换行 | `word_wrap` | 开 | 编辑器中长行自动换行。含超过 256 KB 单行的文件（压缩后的 bundle、source map）始终不换行，打开这类文件时该选项置灰并注明原因：实测换行这样一行会让窗口卡住 0.6–5 秒，不换行则不到 0.5 秒。 |
| 缩进参考线 | `indent_guides` | 开 | 在行首空白的每个缩进位置绘制参考线。 |
| 显示空白字符 | `show_whitespace` | 关 | 标记空白片段中的空格和制表符。 |
| 滚动超出末尾 | `scroll_past_end` | 关 | 允许最后一行滚动到编辑器顶部。 |
| 制表符宽度 | `tab_size` | 2 | 2、4 或 8 列。 |

缩进参考线和空白标记依赖本地 `@pierre/diffs` patch，修改其四处行构建逻辑（高亮视图用的 `utils/renderTokenLines.js` 和 `worker/worker.js`，编辑时重渲染行的 `renderers/FileRenderer.js`，以及输入时渲染当前行的 `editor/tokenizer.js`）。纯空白的 token span 带 `data-ws`，行首的还带 `data-indent`；在两条编辑路径中，以缩进开头的 token 会拆成一个空白 span 和一个文本 span，并保持对应的 `data-char` 偏移。面板用 CSS 背景绘制两种标记，因此文本和光标位置不变。空行不显示参考线，非空白 token 内部的空白（例如字符串中的空格）不会被标记。

### 目录树行

- 不显示合成的工作区根节点，顶层条目从第 0 层开始。
- 文件夹只显示箭头，文件图标占据箭头所在列，使同级名称对齐。这一点通过 `FileTree` 的选项只作用于本面板，Notes 和技能页面保留文件夹图标。
- `CLAUDE.md` 使用 Claude 文件图标。
- 选中的目录树行、当前标签页和按下的目录树开关共用 `--resource-list-row-selected`。该变量不再引用 5% 的 `--accent`，改为独立取值：浅色 8% 黑，深色 14% 白。`--resource-list-row-hover` 和非当前标签页的悬停底色也改用它，不再使用几乎看不见的 2% `--background-subtle`。所有使用这些变量的资源列表都会得到更明显的底色。

### 导航历史

文件之间的链接跳转不再使用隐藏的返回链，因为原文件仍在自己的标签页中打开。从输入框附件打开的预览保留现有的返回行为。

## Alternatives considered

- **在所有宽度下都保留全屏浮层：** 已否决。只要打开文件，目录树就会消失。
- **把面包屑放进面板 header 并去掉文件头：** 2026-10-28 试过，用户否决。它覆盖了文件头，还需要临时加一个关闭按钮。
- **点击目录树替换当前标签页，只有链接才新开标签页：** 最初采用，2026-10-29 被用户改回。现在每个文件都在自己的标签页中打开。
- **为所有可编辑文件提供预览/编辑切换：** 2026-10-29 用户否决。纯文本直接进入编辑器；只有值得保留预览的渲染类文本格式才提供切换。
- **只用 CSS 容器查询切换布局：** 已否决。header 的内容取决于模式，CSS 无法改变渲染哪些元素。

## Acceptance criteria

- AC1 — 面板宽度不小于 672px 时，打开文件后目录树仍在左侧可见并高亮当前文件；没有打开文件时右栏显示空状态。(verification: Electron; owner: pane implementer)
- AC2 — 面板更窄时，文件覆盖目录树；header 的目录树开关可以重新显示目录树，且不关闭任何标签页。(verification: renderer and Electron; owner: pane implementer)
- AC3 — 从目录树、面包屑或链接打开文件时，在当前标签页之后新增标签页，或切换到该文件已有的标签页。(verification: renderer; owner: pane implementer)
- AC4 — 关闭当前标签页后切换到相邻标签页；关闭最后一个标签页后显示空状态。(verification: renderer; owner: pane implementer)
- AC5 — 文件有未保存编辑时切换标签页，编辑内容保留在磁盘或草稿中；有待保存编辑时标签页显示未保存圆点。(verification: renderer and Electron; owner: edit-session owner)
- AC6 — 面包屑显示相对工作区的路径；包括文件在内的每一段都能打开条目下拉框，目录就地展开且不改变面板的目录树，所选文件新开标签页，或切换到已有标签页。(verification: renderer and Electron; owner: pane implementer)
- AC7 — 目录树不显示工作区根节点；仅在本面板中同级文件夹名与文件名对齐；`CLAUDE.md` 显示 Claude 图标。(verification: renderer and Electron; owner: pane implementer)
- AC8 — 从输入框附件打开的预览，仍像以前一样返回之前的目标。(verification: renderer; owner: pane implementer)
- AC9 — 宽面板中，header 开关固定或取消固定目录树；该选择只作用于当前工作区，刷新后仍保留。(verification: renderer and Electron; owner: pane implementer)
- AC10 — 纯文本文件以实时编辑器打开，没有切换；Markdown、HTML、SVG 文件以预览打开，**打开**按钮左侧有编辑/预览切换；PNG 文件以预览打开，没有切换。(verification: renderer and Electron; owner: pane implementer)
- AC11 — 每项面板设置都按描述改变编辑器或布局，对所有工作区生效，重启后保留；关闭自动保存时，只有存在未保存修改时才显示保存/取消，离开文件前会先询问是否放弃。(verification: renderer and Electron; owner: pane implementer)
- AC12 — 从标签页、面包屑或目录树作为上下文附加，会把该文件或文件夹加入会话输入框且只加一次；面包屑目录段附加的是该目录；关闭其他文件和关闭所有文件分别只留一个或不留标签页。(verification: renderer and Electron; owner: pane implementer)

## Risks

- 右侧面板已有工具流程标签页（`flowTabState`）；文件标签页需要独立的状态，不能与之共用。
- 标签页会让文件选择一直保留。文件被删除或重命名后，对应标签页必须显示现有的文件缺失状态，不能崩溃。
- 面板宽度在 672px 附近时，拖动调整可能让布局来回切换；切换不能重置标签页或草稿。

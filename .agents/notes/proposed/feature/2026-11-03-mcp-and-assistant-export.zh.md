# Agent Note: MCP JSON 与助手批量导出

Status: proposed

[English](2026-11-03-mcp-and-assistant-export.md) | 中文

## Problem

用户可以导入 MCP 配置和助手预设数组，却无法导出 MCP 配置或选择多个助手导出到同一个文件。以名称为键的 MCP 文件可能悄然丢失重复名称或不受支持的键。助手目录的第一页也不是完整的导出数据源。

## Proposal

仅在渲染进程中添加导出操作，复用现有读取接口和原生文件保存能力。MCP 导出使用完整列表，排除内置和内存服务器，显式选取可导入的配置字段，保留凭据及本地包路径，补全缺失的传输类型，并验证结构和服务器数量。可导出服务器名称重复或名称为 `__proto__` 时，在保存前拒绝整个导出。

助手批量导出每次打开都重新分页读取，直到获得完整的未删除列表。对话框默认按 ID 全选，独立搜索保留隐藏项的选择，并支持对完整列表全选或取消全选。分组必须成功解析，仅为选中的助手读取有序提示词；任何分组无法解析或读取失败都禁止保存。按读取顺序将选中记录保存为一个旧版预设数组，UTF-8 大小上限为 5,242,880 字节。取消或失败保留选择；仅在返回保存路径后关闭对话框并提示成功。打开周期标记防止旧读取或保存结果影响后续打开的对话框。

本说明保持 `proposed`；本 PR 不声称已获得针对 Spec 当前提交的 Approval。

## Alternatives considered

- 重命名重复 MCP 名称、只导出部分数据或改变导入语义会改变身份或掩盖数据丢失。
- 脱敏凭据或打包本地文件会引入不同的传输契约。
- 复用目录页会遗漏第 500 个之后的助手，并继承无关筛选条件。
- 修改单个导出或导入会将兼容性工作扩展到这两个操作之外。

## Acceptance criteria

- AC1 — 混合传输类型的可导出 MCP 配置通过现有导入结构校验，服务器数量不变，名称、URL 别名及本地包路径得到保留 (verification: unit)
- AC2 — 可导出名称重复或为 `__proto__` 时在保存前拒绝整个导出，大小写不同的名称及 `constructor` 则保留 (verification: unit)
- AC3 — 存储的 MCP 凭据以及已定义的 false、零、空字符串和空集合原样导出 (verification: unit)
- AC4 — 内置及内存服务器在冲突检测前排除，目录搜索不会缩小 MCP 备份范围 (verification: renderer)
- AC5 — 助手选择包含成功读取的所有分页及第 500 个之后的记录，不受目录筛选影响，旧打开周期的异步结果不会写入新周期 (verification: renderer)
- AC6 — 选中的助手按读取顺序生成一个扁平旧版数组，包含已解析分组及按 API 顺序排列的提示词；分组或提示词失败不保存文件 (verification: renderer)
- AC7 — 默认全选、按 ID 选择、完整列表全选与取消、搜索隐藏项保留选择以及取消和重试均可在对话框中观察 (verification: renderer)
- AC8 — 超过 5,242,880 个 UTF-8 字节时在保存前拒绝导出，等于上限则允许 (verification: renderer)
- AC9 — 现有单个导出以及助手和 MCP 导入路径保持当前契约 (verification: renderer)
- AC10 — 七个新增字符串在全部十五种渲染进程语言中均有真实翻译，双语指南描述操作及限制 (verification: docs gate)
- AC11 — 原生保存、取消、导入持久化和键盘操作在已准备好的 Electron 实例中正常工作 (verification: Electron)

## Risks

文件包含凭据，分享时需谨慎。包路径不会携带二进制程序或文件。现有助手导入拒绝空提示词；导出不会编造内容，也不承诺所有助手都能往返导入。并发读取不是原子快照。原生对话框、目标环境依赖和 Windows 行为仍需运行时测量。不提议修改主进程、IPC、DataApi、结构定义或迁移。

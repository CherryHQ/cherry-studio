# Agent Note: 聊天连续代码块的水平标签页

Status: proposed

[English](2026-10-31-consecutive-code-block-tabs.md) | 中文

## 问题

聊天中的连续代码块目前纵向排列，阅读相关片段需要来回滚动。现有代码块视图已经负责高亮、编辑、复制、保存、执行及特殊预览。标签页分组应组合这些视图，不引入第二套代码编辑器，也不改变消息内容。

`ChatMarkdownRuntime` 向 `AppMarkdown` 提供聊天渲染器。流式 Markdown 在执行 Markdown 插件前先拆分源码，因此只在单个解析片段内分组，无法可靠地合并连续的顶层围栏代码块。流式分片与 Markdown 分组必须保持一致。

这是与[代码块阅读和编辑](../architecture/2026-10-26-message-code-block-surfaces.md)并列的新组合决策，不替代该记录中的编辑器、高亮或状态所有权。

## 提案

### 范围与分组

- 在聊天消息 Markdown 中启用分组，涵盖共享聊天消息渲染器的使用方。翻译、文件预览等其他 Markdown 宿主保留现有展示方式。
- 将同一父节点下至少两个连续的围栏代码块组成一个最大连续组。围栏之间的空白不打断分组。正文、标题、图片、表格、原始 HTML、缩进代码块及其他节点会打断分组。不得跨消息、消息块或不同的列表/引用容器分组。
- 围栏 HTML 与图表语言在各自面板内保留现有特殊渲染。被聊天渲染器识别为文件/导航链接的围栏保持独立，并打断分组；行内代码始终不参与分组。
- 单个代码块保留当前外观。分组只影响展示：持久化 Markdown 和导出的 Markdown 按源码顺序保留所有原始代码块。

### 组件与交互

- 新增可复用的 Renderer `CodeBlockTabs` 组件，组合 `@cherrystudio/ui` 的 `Tabs`、`TabsList`、`TabsTrigger` 和 `TabsContent`。组件接收稳定的条目标识、标签和渲染内容，不感知消息动作或文件导航。
- 在当前代码块上方使用水平下划线标签栏。标签使用围栏语言；重复语言附加序号，无语言时使用本地化的代码块标签和序号。本次不引入文件名元数据语法。
- 默认选中首个标签。点击或使用现有 Tabs 键盘交互切换可见面板。窄容器下标签栏水平滚动，获得焦点的标签保持可达，并使用现有明暗主题语义令牌和可见焦点样式。
- 切走再切回时保留每个已访问代码块的未保存草稿、编辑历史、视图模式及局部控件状态。面板首次访问时挂载，分组存续期间保留已访问面板；隐藏面板不得仍可通过键盘聚焦。现有复制/保存/运行动作继续使用其所属代码块当前显示的源码。
- 流式内容更新对应面板。追加围栏不抢走当前选中的标签，也不重置已有面板；流结束时同样保留选择。消息内容标识改变时重置分组，选中条目被移除时回退到剩余的首个条目。

### 集成与验证

Markdown 结构识别保留在 unified 流水线中。保留源码位置和原始围栏正文，扩展现有流式分片接入点，使一个连续组一起进入分组处理。聊天层负责参与分组的判定和渲染覆盖；共享 Markdown 只接收供聊天组合分片解析器所需的最小接入点。不增加全局偏好、不持久化标签选择、不复制代码块状态，也不替换 Markdown 引擎。

批准后通过一个依赖此 Spec 的实现层完成。先使用明确的解析器测试文件验证分组与流式分片契约，再使用明确的 Renderer 测试文件验证标签交互和受影响的聊天调用方。最后在 Electron 真实聊天消息中验证编辑草稿、流式追加、特殊预览、键盘导航，以及明暗主题下的窄容器。集成验证从现有代码块 Electron 场景开始。

## 考虑过的替代方案

- 对 React 兄弟节点分组或检查渲染后的 DOM：流式片段在此之前已将兄弟节点分开，调整 DOM 还会绕过 React 所有权和源码位置。
- 用正则表达式切分 Markdown：嵌套容器、不同围栏分隔符及未闭合围栏需要解析器已有的 Markdown 语法识别能力。
- 所有选中标签复用一个代码块视图：切换源码会重置或混用各代码块的编辑状态和动作。
- 在全部 Markdown 宿主启用分组：扩大已确定的聊天范围，在缺少实际需求时改变文件预览和翻译。

## 验收标准

- AC1 — 至少两个连续且符合条件的围栏按源码顺序显示为一个标签组；单个围栏、行内代码、文件/导航链接、被打断的连续序列及独立容器保留各自边界。 (verification: 解析器和 Renderer 测试; owner: 实现者)
- AC2 — 语言标签、重复语言序号和本地化的无语言标签可以区分面板；明暗主题下均可用鼠标和键盘激活每个标签，包括溢出区域的标签。 (verification: Renderer 测试和 Electron; owner: 实现者)
- AC3 — 切走再切回时保留未保存草稿和编辑撤销历史，复制/保存/运行使用选中代码块自己的当前源码和权限；现有 HTML 和图表预览在激活后仍可使用。 (verification: 受影响的 Renderer 测试和 Electron; owner: 实现者)
- AC4 — 未闭合围栏、追加围栏和流结束更新正确面板，不改变用户选择或丢失已有面板状态；替换内容标识或移除选中条目时，按确定规则重置选择。 (verification: 流式解析器和 Renderer 测试，以及 Electron 流式场景; owner: 实现者)
- AC5 — 其他 Markdown 宿主及持久化/导出的 Markdown 保持不变；分组代码块保留原始源码、顺序和消息保存目标。 (verification: 受影响调用方测试和源码审计; owner: 实现者)

## 风险

分组会增大单个流式渲染片段。应保持无关 Markdown 片段可独立渲染，并验证追加内容时已有面板标识不变。保留已访问面板比卸载面板消耗更多资源；未访问的面板不应启动编辑器或特殊预览。隐藏的图表和编辑器在重新激活时，可能需要验证现有可见性/尺寸测量行为。实现时必须检查图片及富内容捕获对隐藏面板的处理；本提案不新增导出模式，也不丢弃源码代码块。

# Agent Note: 统一应用滚动区域并删除旧滚动条组件

Status: proposed

[English](2026-11-04-unified-scroll-area.md) | 中文

## 问题

renderer 本地 `Scrollbar`、UI 包 `Scrollbar` 和 `DynamicVirtualList` 分别管理原生滚动条样式与显隐计时器。三者都可能通过标准滚动条颜色属性使用依赖平台的占位。renderer 本地组件有 17 个直接引用它的生产文件，涉及编辑器、选择器、设置和横向容器，此外还有专用测试和 mock。UI Scrollbar 的消费者包括消息虚拟列表、思考面板、文件导航、设置、知识库和翻译。

对话间距修复新增了基于 Radix 的 UI `ScrollArea`，但目前只有资源列表接入。它固定使用竖向滚动条、仅滚动时显示、根节点默认 `flex-1`，且 div 属性面向视口，这些能力不足以原样迁移现有消费者。原修复说明仍负责该局部修复：[对话滚动条间距](../../implemented/bug-fix/2026-11-04-conversation-scrollbar-spacing.md)。

## 提案

在 `@cherrystudio/ui` 中只保留 `ScrollArea` 这一个应用滚动容器 API。明确区分根节点布局与视口行为：根节点属性负责布局、尺寸和 `hidden`；视口属性负责原生滚动 ref、滚动事件和键盘属性。内容属性负责子元素布局。通用基础组件不默认占满 flex 剩余空间。使用 Radix 的原生滚动和指针处理支持两个方向、显隐模式及退出动画，保留不改变布局的纯色悬停变宽效果。

直接迁移两类旧 Scrollbar 消费者，然后删除 renderer 本地组件和 UI 包 Scrollbar 实现、导出、过时 stories、mock 及锁定实现的测试。不保留兼容别名或包装组件。将现有调用方的常显、悬停或滚动显示需求映射为支持的行为，仅在已有消费者需要时保留自定义隐藏延迟。

让内部滚动模式的 `DynamicVirtualList` 使用同一 UI 滚动区域。外部滚动模式继续依附传入的祖先，不新增滚动所有者。移除其原生滚动条样式、重复显隐状态与计时器，以及仅为资源列表提供的视口注入入口。资源列表在自己的组合层保留面板边缘布局。

迁移重复实现这些样式的应用列表和弹出选择器，包括翻译语言选择器。对照新几何关系检查所有固定占位补偿和嵌套滚动继承重置。消息导航刻度目前为原生占位预留约 15px，其定位必须根据实际宿主确定，不能继续保留这一假设。编辑器、原生文本输入、代码查看器、HTML 预览文档和刻意不显示滚动条的界面有各自的所有者，不机械套用容器或修改全局样式。

## 考虑过的替代方案

- 将旧导出保留为转发适配：仍有两个公开名称，并会让未完成的迁移看起来已经完成。
- 只修改 UI Scrollbar：遗漏 renderer 本地、虚拟列表和手写样式消费者。
- 替换所有 overflow 元素：会改变第三方组件或编辑器布局，并产生嵌套滚动所有者。
- 保留单 div 实现：DOM 变化最小，但仍保留依赖平台的占位和原生样式冲突。

## 验收标准

- AC1 — 生产代码和测试中的 import、mock、导出及文档引用均不再依赖两个被删除的 Scrollbar 实现；应用滚动条行为只由 UI ScrollArea 管理（验证：源码搜索、定向类型检查）。
- AC2 — 竖向、横向和双向溢出均能正确滚动；隐藏或折叠面板不占据布局，最大高度、自动高度、flex 和 grid 消费者保留原有尺寸关系（验证：UI 浏览器测试、Electron）。
- AC3 — 消费者 ref、测量、滚轮处理、键盘导航和程序滚动均指向真实视口；内部和外部虚拟列表保留稳定阅读锚点与吸顶标题（验证：定向 renderer 测试、Electron）。
- AC4 — 常显及悬停或滚动显示的消费者保留其显隐契约；纯色滑块悬停时变宽并渐隐，列表行宽不变，且支持减少动态效果偏好（验证：UI 浏览器测试、Electron）。
- AC5 — 对话面板、消息导航刻度、嵌套思考或代码面板、选择器和翻译界面保持对齐，不依赖固定原生占位，也没有横向溢出（验证：macOS 和 Windows Electron）。
- AC6 — 改动文件 lint 和格式检查、受影响消费者测试、文档配对及源码关联文档检查通过，并明确记录未验证的平台或构建覆盖范围（验证：定向本地检查、CI）。

## 风险

最强的反对理由是 DOM 兼容性：Radix 增加视口和内容层，而现有消费者在同一个 div 上使用直接子节点 flex 或 grid 布局、`hidden`、ref 和虚拟列表测量。盲目转发属性可能产生空白、破坏折叠，或把滚动接到错误元素上。必须逐个明确根节点与内容布局；包装层和 CSS 选择器也需要验证。

保留视觉行为不代表保留原生滚动条尺寸。悬停卡片、阅读锚点、滚轮所有权、嵌套面板和横向消息组需要明确的回归证据。迁移应作为一项完整的简化，按可独立验证的消费者分组推进，而不是全仓文本替换。本说明是提案，不授权在验证前删除受支持的行为。

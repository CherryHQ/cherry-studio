# Agent Note: 删除低价值测试用例

Status: proposed

[English](2026-11-23-low-value-test-reduction.md) | 中文

## 问题

基线 `b37ce6fa174` 的 3,224 个 Git 跟踪测试文件中，可静态识别 34,596 条用例声明。首批改动净减少 40 条。重复准备代码、复述 mock 固定返回值的断言以及绑定实现细节的用例仍有维护成本。

## 提案

通过删除或合并，净减少基线的约 10%，即约 3,460 条用例声明。在 Git 跟踪的 test 和 spec 文件中，统计带内联回调的 Vitest 和 Playwright 用例调用。参数化声明计一次，前后使用同一 AST 查询。受影响套件实际执行的用例数单独记录。

先清理 Renderer 和 Main，基线共有 29,156 条声明。按功能和测试归属分批。每项删除提供证据，指出已有等价覆盖、断言无法发现相关回归，或对应生产路径不可达。保留持久化、权限、异常恢复、并发和用户工作流的独立覆盖。把现有候选索引作为排查线索，每个实现 PR 记录具体文件和用例证据。

## 已考虑的替代方案

- 仅按 matcher 或 fixture 写法批量删除更快，但可能删掉有价值的外部效果检查或独立输入。
- 按文件数或行数设目标会鼓励删除大 fixture，无法衡量保留的行为覆盖。

## 验收标准

- AC1 — 维护者可使用统一计数口径复现基线和约 3,460 条声明的净减少量（verification: docs gate）
- AC2 — 每批记录保留的行为覆盖或删除依据，且带显式文件范围的测试通过（verification: unit）
- AC3 — 涉及端到端覆盖的变更在定向 smoke 中保留对应用户工作流（verification: Electron）

## 风险

相同的测试体可能对应不同 setup 或平台条件。删除前检查 fixture 和行为归属。若证据支持的删除量低于目标，记录差额。

# Agent Note: 移除 v1 数据迁移

Status: implemented

[English](2026-11-09-retire-v1-data-migration.md) | 中文

## 问题

无限期携带完整的 v1 到 v2 转换系统，会保留过时的转换引擎、UI 和通信层。直接删除 preboot 检查可能将未迁移的数据误判为全新安装，让已有数据不可见。

## 决定

应用保留只读旧数据检测，引导未迁移用户先使用 Cherry Studio **2.1.0**。该固定版本包含转换器和所需平台的安装包。品牌化 preboot 窗口在生命周期 bootstrap 之前提供直接下载安装包或退出操作。下载操作在系统浏览器打开固定安装包 URL 后退出；关闭对话框也退出。用户保留原有数据，安装并启动中转版本、完成迁移，再重新安装当前版本。使用 1.9.11 或更早版本、或无法识别原版本的用户，必须先安装并启动 1.9.12，再通过 2.1.0 迁移。窗口提供两个版本的直接安装包下载。

安装包根据操作系统和架构选择：macOS 使用 DMG，Windows 按当前安装方式使用 setup 或 portable EXE，Linux 使用 AppImage。支持 x64 和 arm64。ARM 电脑通过 Rosetta 或 WOW 运行 x64 应用时，使用 Electron 的 ARM 转译检测选择 arm64 安装包。不经过 release 页面，也不使用会随发布变化的最新版本链接。

已完成的转换状态优先于残留 v1 文件。没有转换标记的数据库，只有包含运行时 seeding 日志才被视为已建立的 v2 数据：旧转换引擎可能在记录进度前创建 schema，但不会运行 seeder。其余情况下，旧版本日志、Chromium 存储或非空旧配置都要求先使用中转版本。检测精确自定义目录及兼容安装版的备用目录，不修改数据库内容。目录不可访问、状态格式错误或数据库不可读时停止启动。开发数据目录不会检查生产环境旧配置。已建立的 v2 自定义目录会恢复 BootConfig 映射，并在 bootstrap 前重启以重新建立完整路径快照。

转换器、迁移器、渲染器、导出流程、迁移 IPC、设置中的重新迁移操作、映射生成器和专用依赖已删除。旧版本留下的待执行重新迁移重置标记会被隔离，不删除 v2 数据。保留的迁移状态读取器继续支持已迁移用户的提供商访问权限和旧文件清理 seeder。OpenClaw 仍使用的提供商投影类型移至消费者旁边。Preference 和 BootConfig schema 生成、备份恢复、普通重置及所有已发布的 SQLite schema migration 保持有效。事务调用方在 DbService 就绪前向迁移状态读取器传入已有数据库上下文。

## 考虑过的替代方案

无限期保留转换会持续产生运行和维护成本。进入新的空白数据目录会隐藏已有数据。release 页面链接需要用户手动选择平台，最新版本链接最终会指向不含转换能力的版本。固定的平台安装包可以提供可重复的升级路径。

## 影响

较旧的用户需要先运行 1.9.12，再通过 2.1.0 中转。应用通过浏览器发起下载，不在后台下载、不自动安装，也不宣称下载完成。GitHub 安装包可用性和操作系统安装行为仍是外部依赖。历史转换状态作为兼容性记录保留，不重写或删除。

## 验证

- AC1 — `legacyUpgradeGate.test.ts` 验证固定安装包选择、路径恢复重启、持久化失败、错误处理，以及阻止 bootstrap 的 handled 结果；`legacyUpgradeWindow.test.ts` 覆盖直接下载、退出、发送方校验和 IPC 清理；`legacyUpgrade.test.ts` 验证平台、架构及便携版组合。
- AC2 — `legacyUpgrade.test.ts` 使用生产 SQLite migration 验证空白新数据、转换完成且有旧文件残留，以及没有转换标记的已建立 v2 数据。
- AC3 — `legacyUpgrade.test.ts` 验证只读检测、包含仅创建 schema 后崩溃的转换中断、自定义目录发现及已建立数据目录恢复、不可访问目录、错误状态及开发隔离；`dataReset.test.ts` 验证已退役的重新迁移请求不会删除数据。
- AC4 — 主进程及渲染器类型检查和 `electron-vite build` 通过。受影响的提供商及模型版本权限、OpenClaw、已有数据库清理、seeding、重置、IPC 和设置测试通过。源码及产物检查未发现转换器或迁移窗口，已发布 SQL 文件未改动。
- AC5 — `pnpm i18n:check` 和 `pnpm docs:check` 通过；全部主进程语言目录均已翻译固定下载及升级说明。

已在隔离的 macOS Electron 数据目录中验证品牌化 preboot 窗口的浅色和深色主题：退出操作关闭应用且没有创建 SQLite 数据库，任意下载 URL 被拒绝。尚未验证实际下载安装、打包后的跨平台升级验收。

# Agent Note: Pi 嵌套工具投影与证据保留

Status: implemented

[English](2026-11-12-pi-nested-tool-projection.md) | 中文

## Problem

Codemode 通过原生权限与执行管线调用嵌套工具，但 Cherry 没有将这些调用投影成普通工具消息。Pi 只转发已知模型调用的更新，Durable 只消费 `live.tools`，未消费 `live.nestedTools`。缺失信息影响 shell、文件工具以及 MCP artifact 声明。

原生 1.5.2 还存在持久化缺口。Pi 保存有界的嵌套名称、参数和状态，但不保存工具结果或显式父子边。Durable 提供完整实时参数及任务级结果，却会清理嵌套槽位与调用方文档；codemode details 只保留 200 字符参数预览。解析预览无法恢复权威参数或结果。

PR #24318 从成功的原生记录恢复普通 Pi artifact 声明。本方案将这一修复推广到通用工具，并保留服务来源检查和去重。PR #24317 已为两种运行时提供原生 shell 超时；超时策略不在本方案范围内。

## Decision

记录由原生执行层拥有。通过仓库依赖补丁扩展 Pi 现有嵌套记录器和 Durable 终态提交路径，将带版本的展示记录保存在外层工具结果中。保存原生调用 ID、直接父调用 ID、解析后的工具名称、实际执行参数、终态及现有渲染器需要的有界工具结果。Durable 必须在任务文档清理前捕获后代记录，并在发布终态证据的同一次原生提交中保存；不能从合并后的 UI 观察事件重建记录。不增加第二套执行日志、调度器或 Cherry 数据库表。

记录独立于模型文本和 codemode 程序返回值。原生权限检查、参数修复、工具执行和重放继续作为权威来源。记录参数修复与权限处理后真正执行的参数，不把预览当成执行输入。以所属会话和外层调用为作用域的稳定原生 ID 区分相同的并发调用，并在重开后保留。通过父子边保留递归调用关系，不解析 ID 推断关系。

采用显式上限：每个外层调用最多保存 256 个调用，单次参数最多 8 KiB、参数总量最多 32 KiB，与 Pi 现有参数预算一致；新增结果 JSON 单次最多 64 KiB、总量最多 1 MiB。按 UTF-8 序列化字节计量。超限字段整体省略，并保存类型化省略原因和原始字节数，不保存截断 JSON。终态独立于省略载荷保存。工具已有的溢出文件引用仍是引用，不重复文件内容或内联超出预算的二进制数据。明确标记被省略的调用。记录沿用原生会话的存储与删除生命周期。

两个运行时适配器将实时嵌套开始、更新、终态结果投影成所属 assistant 消息上的 `dynamic-tool` 部分，身份与元数据和归档投影一致。外层 codemode 输出保持独立可见。即使后续脚本语句失败，先前成功的嵌套调用仍保持成功。取消和中断不能显示成成功，也不能永久停留在运行中。归档重建消费保留的原生记录，不依赖此前是否观察过执行过程。

Main 对这些部分应用现有工具名称和 MCP 来源映射。现有渲染组件处理 shell、文件及受支持的 MCP 工具，未知工具使用通用渲染器。在 provider metadata 中保留父调用身份。不仅凭参数合成成功结果。Artifact 声明必须来自成功的内置 `cherry-tools` 调用，且参数完整并通过 schema 校验，只展示一次。通用部分可用时替代 #24318 的 artifact 专用合成，保留旧记录支持并避免重复。

旧记录仍可读取。只渲染确有证据的信息：明确标记被省略载荷或不完整的旧记录，不重放工具以补全历史。不承诺回填旧运行时从未保存的信息。

用户明确要求直接在现有 Spec PR 中实现，不等待单独批准。#24317 已合并；#24318 仍开放，其 artifact 专用合成由通用工具部分取代。

## Alternatives considered

- 解析 codemode 文本或 Durable 的 200 字符参数预览：丢失类型，不能区分截断参数与执行参数。
- 在 Main 观察器中捕获嵌套调用：遗漏快速调用、晚附加和崩溃恢复，使持久化依赖 UI 时序。
- 仅增加实时嵌套投影：完成或重开后卡片消失。
- 为每个工具添加渲染器特例：重复缺失的契约，无法恢复不存在的原生历史。
- 无限制保存原始嵌套输出：重复大载荷并破坏原生存储边界。

## Consequences

原生补丁在现有执行状态旁保存展示证据，不新增 Cherry 数据表、第二套日志或重放路径。发布的依赖仅包含分发文件，因此补丁修改分发文件及其声明。大载荷可能被省略；旧会话无法恢复从未保存的证据。macOS Electron 验收不代表 Windows PowerShell 验收。

## Verification

- AC1 — Pi `tests/runtime.test.ts` 和 Durable `tests/runtime.test.ts` 通过真实嵌套执行验证相同并发调用、超过 200 字符的修复后参数、独立 ID 和递归父子边。Electron 通过真实 QuickJS codemode 调用 write、read、bash 和内置 MCP artifact 工具。

- AC3 — Renderer artifact 测试拒绝待执行、失败、取消及外部服务声明。两种 Electron 运行时均在完成和会话重载后显示唯一的长参数 artifact 卡片，预览加载生成的 HTML。

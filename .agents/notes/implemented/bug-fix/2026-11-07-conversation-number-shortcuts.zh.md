# Agent Note: 将数字快捷键限定到会话列表

Status: implemented

[English](2026-11-07-conversation-number-shortcuts.md) | 中文

## 问题

数字导航命令原先由应用侧边栏注册，用于打开应用入口。预期交互是在当前页面选择 Chat 话题或 Agent 会话，并在长按配置的会话修饰键时显示快捷键。

## 决策

Chat 话题和 Agent 会话列表主体通过共享会话列表 hook 注册九个命令。编号遵循实际渲染的列表模型，包括置顶分组、排序、筛选和折叠区段。仅前九个显示项参与；分组标题和折叠项不占编号。当前标签页拥有注册，Activity 隐藏或页面卸载时由 effect 清理释放。

长按配置的会话修饰键 500 ms 后，在行尾 Kbd 中显示每个可用绑定。松开修饰键、窗口失焦或文档可见性变化都会清除提示。执行快捷键无需先长按。禁用的绑定不显示提示；自定义绑定显示实际组合键。

保留已发布的 `app.sidebar.open_1` 至 `app.sidebar.open_9` 命令 ID 和偏好键，以保留自定义绑定。设置将十八个数字命令合并为一张卡片。默认使用 macOS Cmd（其他平台 Ctrl）切换会话、macOS Ctrl（其他平台 Alt）切换标签页；下拉菜单的另一选项通过一次偏好更新互换两组绑定。已有自定义绑定保留到用户选择预设。新增的九个 `tab.open_N` 命令由 AppShell 注册，顺序为置顶标签页在前、普通标签页在后。水平标签栏与会话列表共用长按提示 hook，500 ms 后显示对应标签页绑定。置顶标签页暂时用提示替代图标，普通标签页在尾部显示提示。尚无已保存偏好时，hook 读取命令默认值。应用侧边栏不再注册这些命令。

## 考虑过的替代方案

- 窗口级处理函数会让导航在会话所属页面之外继续生效，并需要另一套当前列表注册机制。
- 重命名命令 ID 会丢弃现有自定义绑定，除非引入不必要的偏好迁移。
- 按源数据编号会与显示的分组、筛选和折叠状态不一致。

## 影响

设置、小程序和其他页面不会通过这些命令切换会话。折叠或重排分组会改变位置快捷键。从偏好定义生成九个标签页快捷键偏好，无需修改数据库结构。

## 验证

- Regression — `src/renderer/components/chat/resourceList/__tests__/useConversationListShortcuts.test.tsx`：通过真实命令分发选择显示项，跳过折叠分组和空位置，在 Activity 页面之间转移所有权，遵循自定义和禁用绑定，并在松键或失焦时清除长按提示。
- Consumers — 针对 Topics、Sessions、SessionItem、Sidebar 和 CommandProvider 的定向测试通过。
- Electron — 独立 macOS 开发配置验证了 Chat 和 Agent 的行尾提示、Cmd+2 选择以及松键清理，无需请求模型服务。也验证了设置选择器、重载后保留互换结果、Ctrl 选择会话和 Cmd 选择标签页。未验证 Windows 原生交互。

- Presets — 定向测试覆盖 macOS、Windows、Linux 的全部九个位置、自定义绑定保留和两组角色同时更新。

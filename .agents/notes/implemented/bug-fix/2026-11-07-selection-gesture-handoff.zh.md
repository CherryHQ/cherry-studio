# Agent Note：保留输入手势切换后的选区操作

Status: implemented

[English](2026-11-07-selection-gesture-handoff.md) | 中文

## 问题

鼠标选区结束的同一动画帧内可能开始键盘选区。键盘处理函数取消了待执行的鼠标松开回调，使工具栏一直处于鼠标拖选状态。随后到达的选区变化事件会隐藏复制和引用操作，即使消息中的非空选区已经完成。

## 决策

开始键盘选区时清除鼠标拖选状态，由已有的按键跟踪逻辑负责选区完成、位置测量和滚动处理。

## 考虑过的替代方案

- 在 E2E 中增加延迟会掩盖用户同样可能遇到的时序问题。
- 执行已取消的鼠标回调会在键盘选区尚未完成时显示操作。

## 影响

纯鼠标选区、可编辑区域排除、滚动关闭和键盘修饰键跟踪保持原有行为，不涉及持久化或 IPC 变化。

## 验证

- 回归 — 用例在鼠标松开后立即开始键盘选区，完成后发送最终选区变化事件。修复前失败，修复后通过。
- 回归 — 选中文本工具栏全部 11 项测试通过，覆盖复制、引用、排除范围、滚动、修饰键释放及关闭行为。

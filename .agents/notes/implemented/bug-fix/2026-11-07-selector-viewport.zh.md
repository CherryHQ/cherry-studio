# Agent Note: 将选择器选项限制在可用视口内

Status: implemented

[English](2026-11-07-selector-viewport.md) | 中文

## 问题

MP-117 已创建并清理真实自动备份，但随后无法选择关闭。选择器向上打开，第一个选项位于窗口上方；弹层自身超过可用高度，因此滚动也无法使该选项进入视口。

## 决策

使用 Radix Popover 的可用高度变量约束现有 ScrollArea，扣除内容内边距，并保留原来的 20rem 高度上限。

## 考虑过的替代方案

强制点击或增大测试窗口会掩盖产品选项不可访问的问题。自定义弹层定位会重复实现库已有的功能。

## 影响

长菜单在触发器上方或下方的可用空间内滚动。选项值与选择行为不变。

## 验证

- Regression — 现有 MP-117 真实 Electron 场景复现了关闭选项不可访问的问题。Selector 组件测试已通过，仍需修复后的 Electron 复跑。

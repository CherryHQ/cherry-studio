# Agent Note: 释放已完成的渲染进程一次性定时器

Status: implemented

[English](2026-11-27-renderer-timeout-expiry.md) | 中文

## 问题

已挂载的组件可以为许多名称调度一次性定时器。定时器触发后，平台会释放它，但 Hook 仍保留注册，直到显式清理或卸载。

## 决策

Hook 在调用回调前移除已完成的注册。若回调以同名调度替代任务，新任务拥有新的注册。

## 考虑过的替代方案

- 在回调结束后删除名称，可能删除替代任务，也可能因回调抛错而漏掉清理。

## 影响

按名称清理仍适用于运行中的定时器。长期挂载的组件只保留待执行的一次性定时器注册。

## 验证

- Regression — `src/renderer/hooks/__tests__/useTimer.expiry.test.ts`：验证已完成或抛错的定时器被释放，且回调可以创建同名替代任务。

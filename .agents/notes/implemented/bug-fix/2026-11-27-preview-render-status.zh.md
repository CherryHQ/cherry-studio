# Agent Note: 让预览状态对应当前渲染

Status: implemented

[English](2026-11-27-preview-render-status.md) | 中文

## 问题

新输入进入队列或预览被取消后，图表渲染仍可能完成。旧渲染结束时可能清除新预览的加载提示，或显示已丢弃输入的错误。

## 决策

共享预览 Hook 在请求渲染时分配版本，取消时使该版本失效。只有当前版本可以更新加载和错误状态。在防抖前分配版本，可以防止旧任务在防抖等待期间更新状态。

## 考虑过的替代方案

- 仅取消防抖定时器无法阻止已经启动的渲染结束。

## 影响

当前预览的错误仍然可见。版本判断覆盖共享的加载和错误状态。各渲染器继续负责自己的输出与取消能力。

## 验证

- Regression — `src/renderer/components/Preview/__tests__/useDebouncedRender.test.ts`：验证旧渲染失败不会结束新预览的加载状态，且取消后不会显示进行中渲染的失败。

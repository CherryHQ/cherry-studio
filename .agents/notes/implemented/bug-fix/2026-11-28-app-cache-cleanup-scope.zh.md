# Agent Note: 应用缓存清理保留已安装的依赖

Status: implemented

[English](2026-11-28-app-cache-cleanup-scope.md) | 中文

## 问题

应用缓存清理漏掉了 Agent 浏览器、旧浏览器和小程序分区。浏览器设置中的清理入口只清除 HTTP 缓存，留下了 CacheStorage 和生成的代码。应用还会积累可重新下载的工具链数据，但部分已安装 CLI 直接链接到缓存目录下的 aube 共享依赖存储。

## 决策

对已有的浏览器和小程序分区使用 Electron 专用的缓存清理操作。浏览器设置和应用缓存共用 Agent 浏览器的清理操作。浏览器可以重新生成 HTTP 响应缓存、CacheStorage 和编译后的代码，同时保留 Cookie、历史记录和持久化站点存储。

仅纳入 Cherry 管理的 mise 缓存、npm 内容缓存和 aube 包元数据。BinaryManager 的变更锁被占用时跳过这些目录，并报告部分完成。保留 aube 共享存储、uv 缓存和已安装工具目录供现有使用方访问。

## 考虑过的替代方案

- 清除全部 Chromium 站点数据会丢失 Cookie 和持久化网站状态。
- 删除整个工具链缓存根目录会破坏通过绝对路径链接到 aube 共享存储的依赖。

## 影响

应用缓存可以释放更多可重建数据占用的空间。后续浏览、安装或更新时可能会重新下载这些数据。工具正在安装或卸载时，可能需要稍后重试清理。

## 验证

- 回归验证涵盖分区发现、站点数据保留、工具链清理目标的所有权校验，以及工具变更期间的清理行为。
- 在 macOS 数据副本上清除 Agent 浏览器和三类工具链缓存后，总占用从 8.92 GiB 降到 6.79 GiB。验证范围内的已安装工具和共享依赖目录占用保持一致。
- 通过 Electron 设置界面清除了旧浏览器和小程序分区的 CacheStorage，保留了两者的 Cookie 和 Local Storage，以及无关分区的缓存。

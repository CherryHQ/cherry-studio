# Agent Note：保持窄预览面板中的标签按钮可点击

Status: implemented

[English](2026-11-07-preview-tab-overlap.md) | 中文

## 问题

MP-19 在默认窄 Agent 面板中打开两个文件预览。当前标签仍然显示，但其固定最小宽度与溢出菜单按钮之和超过了标题栏剩余空间。溢出菜单按钮覆盖当前标签的关闭按钮，导致普通鼠标点击失败。

## 决策

让标签列表占用可用的弹性空间，并允许单个标签缩小到首选宽度以下。关闭和溢出菜单按钮保持原有尺寸，标题截断，同时保留当前标签位置与溢出菜单行为。

## 考虑过的替代方案

- 强制 E2E 点击穿过重叠控件会掩盖用户可见的问题。
- 扩大所有预览面板会为了标题栏缺陷而改变用户的会话布局。

## 影响

窄标题栏中的文件标题会缩短，但两个按钮都应保持可点击。标签容量计算和上下文菜单保持不变。

## 验证

- 回归 — 修复前 MP-19 截图记录了控件重叠，普通点击选中第二个文件的关闭按钮失败。该用例的关闭及回退断言继续作为应用层检查。

- 回归 — 修复后 MP-19 在真实 Electron 应用中通过，覆盖普通鼠标关闭溢出的当前标签、回退选择、DOCX／视频预览以及选中文字的剪贴板往返。

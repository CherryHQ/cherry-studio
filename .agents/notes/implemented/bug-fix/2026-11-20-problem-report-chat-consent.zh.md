# Agent Note：将问题报告的聊天附件限定在出错会话

Status: implemented

[English](2026-11-20-problem-report-chat-consent.md) | 中文

## 问题

提交普通问题报告时，可能附带其他会话最近 24 小时内的聊天记录。

## 决策

普通问题报告不附带聊天记录。从消息错误入口进入时，提供默认不勾选的选项，允许附带出错会话最近 24 小时的记录。用户勾选后，上传请求才携带对应的话题 ID，主进程只采集该话题或智能体会话。

## 考虑过的其他方案

- 允许用户选择上传所有近期会话，仍会暴露无关消息。

## 影响

日志和详细运行记录仍是诊断数据来源。本地诊断包导出保留独立的数据源选项。

## 验证

- Regression — `DiagnosticBundleService.test.ts` 验证两类会话的归档内容，渲染进程测试验证勾选行为以及从错误详情进入问题报告时的参数传递。

# Agent Note: Agent 头像修改后同步隐藏的 Work 标签图标

Status: implemented

[English](2026-11-10-agent-tab-icon-sync.md) | 中文

## Problem

问题 #23045 报告修改 Agent 头像后 Work 标签图标仍然过期。React Activity 会暂停隐藏页面的 effect，包括数据变更订阅和标签视觉更新。休眠标签没有已挂载的页面来刷新图标。只更新标签图标还会让 Agent 查询缓存保持过期，使恢复后的页面写回旧图标。

## Decision

在标签页面外的窗口运行时订阅 Agent 变更。解析 Work 标签绑定的会话并读取当前 Agent，在每个批次内合并重复的 Agent 读取。先将完整 Agent 行写入现有查询缓存，再更新匹配的标签图标。标题和路由保持不变。

后续事件会取代整个待完成批次，因此每个批次刷新全部已绑定会话。在发布缓存和更新图标前检查生命周期修订号；写入前重新检查标签当前绑定的会话。隔离会话或 Agent 缺失导致的失败，让其他标签仍能刷新。

## Alternatives considered

- 仅由页面订阅无法刷新隐藏或休眠标签。
- 更新图标却不更新现有 Agent 缓存，会让恢复后的页面用过期数据覆盖图标。
- 轮询或修改全局查询恢复策略会增加无关行为。

## Consequences

隐藏和休眠的 Work 标签无需激活即可接收表情、图片和清空头像的变更。每次 Agent 事件会增加对不同绑定会话及其 Agent 的读取。不引入新的持久化映射或缓存。

## Verification

- 回归验证 — 使用真实标签状态、数据变更订阅、查询 hook 和 React Activity，覆盖隐藏页面恢复、休眠和固定标签、图片及清空头像、无关标签、缺失记录、绑定变化、卸载和读取乱序。
- 回归验证 — 页面恢复后，较早的待完成查询不能替换已发布的 Agent 行。测试保持查询 provider 稳定，同时在 StrictMode 下运行应用 hook。
- 回归验证 — 新同步测试与已有标题、页面视觉和全屏测试共 26 项通过；限定范围的 lint 和格式检查通过。
- 限制 — 本机 Swift 6.0.3 不满足语音包要求的 Swift 6.2.0，Electron 在启动前受阻。未验证完整应用及真实跨窗口交互。

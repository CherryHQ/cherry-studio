# Agent Note: 将截图导出绑定到所属捕获会话

Status: implemented

[English](2026-11-08-screenshot-result-session-ownership.md) | 中文

## Problem

截图遮罩会复用池化窗口。PNG 编码可能在取消截图并复用窗口后才完成，因此只检查发送窗口，可能把旧图片当成新捕获的结果。重复导出操作也可能启动重叠的保存操作。在 macOS 上，旧保存框结束时会恢复当前遮罩，却没有检查会话归属，可能遮住新一轮保存面板。

## Decision

结果 IPC 携带捕获已有的 `mediaId`；主进程只接受当前活动遮罩且媒体身份匹配的结果。业务结果类型仍只包含图片字节。渲染进程在 PNG 编码和 IPC 期间持有令牌，拒绝重复操作，并丢弃因会话结束、捕获替换或遮罩重置而失效的结果。主进程每个会话同时只接受一个保存操作。保存结束时只释放自己的待完成操作，并且只在会话仍归自己所有时恢复遮罩。

## Alternatives considered

- 只检查发送窗口，无法区分池化窗口复用前后的捕获。
- 只禁用工具栏按钮，无法覆盖键盘提交或主进程的准入检查。
- 放慢自动化操作或强制原生焦点，会掩盖归属竞态。

## Consequences

取消捕获会使其待完成导出失效。旧保存操作结束时，不能在新捕获的原生面板上重新显示遮罩，也不能清除新保存操作的待完成状态。取消保存后可以重试。原生对话框归属和普通捕获交互保留现有契约。本修复不能证明所有已报告截图卡住问题的成因。

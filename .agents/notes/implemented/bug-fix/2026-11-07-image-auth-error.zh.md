# Agent Note：脱敏图片服务商认证错误

Status: implemented

[English](2026-11-07-image-auth-error.md) | 中文

## 问题

回归用例 MP-92 返回包含 `Incorrect API key provided: <测试密钥>` 的模拟 HTTP 401。图片错误弹窗直接显示凭据，没有提供本地化认证提示。共享服务商错误脱敏器识别 `api_key` 字段，却漏掉自然语言的 `API key` 和 `API key provided` 标签。

## 决策

在现有共享敏感文本匹配器中加入这两个标签，使服务商错误序列化在 IPC 和展示之前移除对应值。图片错误的 HTTP 401 或现有 `auth` 分类映射到已有本地化提示的 `REQ_ERROR_TOKEN`。其他服务商诊断和静默取消行为保留。

## 考虑过的替代方案

- 只隐藏图片弹窗中的凭据，会让序列化服务商错误仍携带该凭据。
- 将所有服务商错误替换为通用失败，会丢失余额不足和服务故障的有效诊断。

## 影响

共享脱敏器也会保护使用这些标签的其他服务商错误消费者。这是针对性修复，不保证能够识别任意没有标签的秘密。图片认证失败使用已有翻译，无需新增语言键。

## 验证

- 回归 — 两种自然语言凭据回显和图片 HTTP 401 提示在修复前失败，修复后通过。
- 回归 — 共享脱敏、服务商错误、主进程错误序列化、图片错误处理和图片生成的 155 项测试通过。
- MP-92 保留 HTTP 请求、凭据不泄露、余额提示、失败后恢复空闲及成功图片持久化断言，用于完整应用验收。

# Agent Note: 将右侧面板的展开状态绑定到实例

Status: implemented

[English](2026-10-31-right-panel-presentation-identity.md) | 中文

## 问题

共享右侧面板容器在切换智能体任务时保留展开标志和所选面板 ID，导致新浏览器实例继承前一个任务的可见状态。如果新建的空工作目录让文件面板变为不可用，容器又会选择第一个就绪的功能面板，通常是浏览器。这两条路径都没有工具请求，因此关闭浏览器自动打开设置也无法阻止它们。参见 [issue #23185](https://github.com/CherryHQ/cherry-studio/issues/23185)。

## 决策

展开请求归属于所选面板已有的 `instanceKey`。实例身份改变、面板被移除或变为不可用时，展开意图失效，面板收起。容器不会为了维持展开布局而选择无关的功能面板。

同一实例处于等待状态时保留展开意图，直到就绪。环境暂时隐藏面板时，只要实例身份仍然有效，也保留该意图。明确的打开操作绑定当前解析出的实例；动态面板仍可在同一个 React 批次中创建并请求打开。初始默认值和明确的默认面板操作仍可选择可用的默认面板。

连续性由现有实例身份的归属决定：浏览器属于会话，文件属于工作目录，经典布局的资源导航保留稳定身份。该修复位于共享容器中，也适用于聊天面板。工具触发的浏览器打开仍遵循已有设置。

## 考虑过的替代方案

- 每次切换会话都重置整个容器：会丢失仍然有效的工作目录文件状态，并收起经典布局的任务导航。
- 关闭浏览器自动打开或为浏览器添加特殊处理：无法解决失效的展开意图，也无法解决其他功能面板之间的自动回退。
- 为每个会话记忆展开状态：会引入独立的恢复策略，本次修复不需要它。

## 影响

切换会话会关闭归属于会话的面板；返回原会话不会自动重放旧的展开意图。工作目录身份保持不变时，文件面板保持展开。某个功能面板变为不可用时，即使另一个面板已经就绪，侧栏也会收起。用户可以明确打开下一个面板。该修复不引入新设置、持久化状态或浏览器运行时生命周期。

## 验证

- Regression — `src/renderer/components/chat/panes/Shell/__tests__/RightPanel.test.tsx`：实例替换和不可用状态会收起面板，不回退，也不在稍后自动重新展开；稳定身份保留内容；等待状态和动态面板保留预期行为。
- Regression — `src/renderer/pages/agents/components/AgentRightPane/__tests__/AgentRightPane.test.tsx` 和 `src/renderer/pages/home/components/__tests__/TopicRightPane.test.tsx`：验证会话浏览器状态、过期结果、文件编辑、资源导航，以及资源面板不可用时的行为。
- Regression — `tests/e2e/ondemand/specs/agent-panel-intent.ts`：关闭浏览器自动打开后，通过真实 Electron 的新建任务按钮验证浏览器在新任务中收起、旧系统工作目录的文件面板不会回退到浏览器，以及共享用户工作目录的文件面板保持展开。

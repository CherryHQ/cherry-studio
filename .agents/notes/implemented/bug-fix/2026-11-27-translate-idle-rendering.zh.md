# Agent Note: 翻译输出队列为空时停止逐帧调度

Status: implemented

[English](2026-11-27-translate-idle-rendering.md) | 中文

## 问题

翻译页的输出渲染在等待文字时会持续请求动画帧，页面空闲时也是如此。取消或失败的请求不发出用于停止循环的完成事件。这个问题是在排查 [#25525](https://github.com/CherryHQ/cherry-studio/issues/25525) 时发现的。

## 决策

共享的流式输出渲染仅在有待显示的字素时调度动画帧。队列清空后，新到的文字会重新启动渲染。请求开始时间独立于动画帧记录，首个 token 的等待时间仍可用于调整缓冲。翻译页根据请求生命周期，在成功、取消或失败后显示已接收但尚未渲染的文字。

## 考虑过的替代方案

- 轮询空队列会让渲染器在没有文字可显示时继续请求动画帧。
- 移除平滑显示也会去掉流式响应间隔中的输出节奏。由队列驱动的调度保留了这个行为。

## 影响

队列清空后，翻译输出停止调度动画帧，并保留停止前已收到的文字。提供商请求、模型参数和路由保持原样。本地测量只验证了渲染调度行为。

## 验证

- Regression — `src/renderer/hooks/__tests__/useSmoothStream.test.ts`：验证空闲调度、队列耗尽后的续传、重置和完成时显示剩余内容。旧实现无法通过新增的回归断言。
- Regression — macOS Electron 使用本地 SSE 提供商：每 1.2 秒内，空闲回调从 70 次降至 0 次，停止后的回调从 67 次降至 0 次。完整泰文译文和停止前收到的部分文字均保持可见。

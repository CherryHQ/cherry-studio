# Agent Note：保留网页查找以外的组合快捷键

Status: implemented

[English](2026-11-07-webview-find-shortcut-modifiers.md) | 中文

## 问题

网页视图挂载后，Ctrl/Cmd+Shift+F 会同时打开全局搜索和网页查找浮层。网页查找处理器只匹配主修饰键和 F，没有排除 Shift 或 Alt，其搜索输入框可能抢走全局搜索的焦点。完整 MP-129 运行观察到焦点落在全局搜索对话框外的 Search 输入框。

## 决策

网页查找仅在没有 Shift 和 Alt 时处理 Ctrl/Cmd+F。从网页子进程重放的按键也遵守相同的修饰键规则。现有面板归属判断以及普通查找、Enter 和 Escape 的行为保持不变。

## 考虑过的替代方案

在 E2E 测试中重新聚焦全局搜索输入框，或更改测试的快捷键，会掩盖产品处理器之间的冲突。移除网页查找则会丢失正常的浏览器搜索功能。

## 影响

带附加修饰键的查找组合保留给其所属功能，普通网页查找继续工作。

## 验证

- 回归 — 四项输入框焦点回归测试在修复前失败、修复后通过，覆盖 Ctrl/Cmd 分别与 Shift 或 Alt 组合的情况。网页查找、键盘重放及 Mini App 消费方的 59 项定向测试全部通过。真实 MP-122 → MP-129 顺序也已通过，覆盖保留网页视图后打开全局搜索的情况。完整桌面及托管环境验收仍由 PR 跟踪。

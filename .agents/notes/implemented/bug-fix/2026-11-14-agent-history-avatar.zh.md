# Agent Note: 历史消息使用智能体当前头像

Status: implemented

[English](2026-11-14-agent-history-avatar.md) | 中文

## 问题

消息快照保存生成消息的作者头像。始终使用快照，会让仍然存在的智能体在修改资料后，其历史消息仍保留旧头像。软删除也会保留会话中的智能体 ID，而查询失败时可能继续保留缓存的智能体资料。

## 决定

智能体适配器提供按作者 ID 索引的当前头像。共享消息头优先使用匹配的当前头像，否则使用消息快照。名字和模型身份仍使用历史资料。普通助手不提供这项覆盖。图片捕获使用同一适配器。

领域查询 hook 将明确的 DataApi NOT_FOUND 视为不存在，即使缓存资料仍在。临时错误继续保留缓存，成功读取后智能体重新可用。复用现有错误判断，不改变 DataApi 缓存语义。

## 考虑过的替代方案

- 重写历史快照会丢失原头像，并需要遍历写入历史消息。
- 不匹配消息作者 ID 而直接使用会话头像，可能错误归属其他作者的消息。
- 将所有查询失败都视为删除，会在临时故障期间替换头像。

## 影响

仍然存在的智能体，其历史消息头像跟随资料修改。智能体删除后，消息保留原头像。快照文件引用和数据库格式保持不变；不增加迁移、额外的资料查询或镜像状态。

## 验证

- Regression — MessageHeader 和智能体适配器测试覆盖头像修改、图片切换为 Emoji、作者 ID 隔离、快照回退及历史名字保持不变。
- Regression — useAgent 测试覆盖临时错误下的缓存、确认删除和成功恢复；现有标签同步测试覆盖该 hook 的一个消费者。
- Regression — Electron 测试 fixture 使用真实消息组件、智能体查询和头像 IPC，验证即时头像更新与删除回退，没有调用外部模型。

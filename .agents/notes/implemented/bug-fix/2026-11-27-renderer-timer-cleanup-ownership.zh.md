# Agent Note: 将渲染进程定时器清理限定到对应的注册

Status: implemented

[English](2026-11-27-renderer-timer-cleanup-ownership.md) | 中文

## 问题

调度同名定时器时会替换先前的注册。先前调用返回的清理函数仍会按名称清理，因此可能取消替换后的任务。

## 决策

调度调用返回的清理函数只在对应句柄仍注册于该名称时清理定时器。显式按名称清理的操作仍清理当前定时器。

## 考虑过的替代方案

- 单靠名称无法区分返回的清理函数属于哪次注册。

## 影响

调用方可以清理先前的调度而不会取消替换后的工作。一次性和间隔定时器仍各自使用独立的名称空间。

## 验证

- Regression — `src/renderer/hooks/__tests__/useTimer.test.ts`：验证旧清理函数不会取消替换后的定时器，当前清理函数和显式清理仍可停止任务。

# Agent Note: Codex 审批详情

Status: implemented

[English](2026-10-22-codex-approval-details.md) | 中文

## 问题

Codex App Server 可能只在 `item/started` 中发送命令或文件变更。后续审批请求仅通过标识关联该操作，不重复详情。用审批请求替换工具输入，会让用户看不到待审批的操作。

## 决策

在当前连接和轮次中，按原生操作 ID 保留命令和文件项。构造审批输入时，先合并操作详情，再应用请求自身字段和原生决策选项。操作结束后删除详情，下一轮开始前清空。没有匹配操作项的请求继续使用自身参数。

## 考虑过的替代方案

- 仅使用审批请求参数：丢失用户需要审查的实际操作。
- 跨轮次保留详情：操作 ID 重用时，可能展示旧操作。

## 影响

无需修改数据库、IPC 或权限策略。原生审批决策及其作用范围保持不变。

## 验证

- Regression — `src/main/ai/runtime/localAgent/__tests__/connections.test.ts`：命令和文件审批保留操作详情及原生请求字段，返回准确的原生决策，后续轮次不复用旧详情；两个新增用例在修复前均失败。
- Electron — Codex 0.162.1 展示待审批文件路径和内容，准确创建已批准文件，拒绝或取消后文件不存在，取消后的迟到审批被拒绝，后续对话成功。

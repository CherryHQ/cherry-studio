# Agent Note：更新行内拖拽的插入位置

Status: implemented

[English](2026-11-07-drag-insertion-position.md) | 中文

## 问题

回归用例 MP-54 将第二个置顶会话拖到第一个会话上方，但插入线仍留在目标下方，持久化顺序没有变化。分组列表只监听 dnd-kit 的 `onDragOver`，该事件仅在目标 ID 改变时触发。在同一行内从下半部移到上半部，不会更新插入位置。

## 决策

同时通过 `onDragMove` 和 `onDragOver` 更新现有落点状态，复用几何计算、权限检查和状态相等判断。松手后仍使用可见插入线的位置，也保留现有的分组末尾追加行为。

## 考虑过的替代方案

- 让测试直接跳到目标行上方会避开正常用户拖拽路径，掩盖问题。
- 仅在松手时重新计算会使显示的插入线与最终排序不一致。

## 影响

插入线能够跟随目标行内的移动。排序 API、持久化格式和跨组权限均无需变化。

## 验证

- 回归 — 测试在保持目标 ID 不变时，将拖拽项从目标下半部移到上半部，并验证插入线和最终排序参数；修复前失败。
- 回归 — 修复后 GroupedSortableVirtualList 和 ResourceList 两个文件的 90 项测试全部通过。
- 完整应用中的拖拽及重启后持久化仍由 MP-54 验收。

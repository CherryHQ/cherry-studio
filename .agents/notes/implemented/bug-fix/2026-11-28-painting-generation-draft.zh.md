# Agent Note: 生成图像期间保留草稿编辑

Status: implemented

[English](2026-11-28-painting-generation-draft.md) | 中文

## 问题

图像生成期间，用户仍可编辑输入区。生成结束时，应用用提交请求时的快照替换当前草稿，导致等待期间更改的图像参数和提示词丢失。

## 决策

生成请求和文件持久化使用提交时的快照。生成结束后，按图像记录 ID 核对当前草稿，并将终态和结果文件合并到最新草稿。

## 考虑过的替代方案

- 生成期间禁用输入区。这样用户无法在等待期间为下一次请求做准备。

## 影响

生成期间的编辑会保留在输入区。其他图像记录的结果更新其历史记录，当前草稿继续停留在原记录。

## 验证

- 回归 — `usePaintingGeneration.test.ts` 在图像生成期间修改尺寸和质量，并验证生成结束后保留新值和返回的文件。

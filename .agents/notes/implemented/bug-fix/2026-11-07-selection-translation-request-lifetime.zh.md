# Agent Note: 让划词翻译请求随输入变化

Status: implemented

[English](2026-11-07-selection-translation-request-lifetime.md) | 中文

## 问题

划词翻译的 effect 依赖一个回调，而语言检测与语言查询刷新时会改变该回调的引用。因此，即使选中文字没有变化，也可能取消首次请求并重新发起请求。在 MP-127 中，受控服务收到了两次相同请求，首次完成的响应却没有显示。

## 决策

仅在选中文字、初始化状态或目标语言代码变化时自动发起翻译。通过 Effect Event 读取最新翻译回调，避免把回调引用变化作为请求触发条件。用户点击重新生成仍会发起新请求，新的操作窗口会话仍会重新挂载组件。

## 考虑过的替代方案

- 延长 E2E 等待时间无法恢复已取消的首次响应，也无法消除重复的服务请求。
- 删除依赖但保留闭包中的回调，可能使用过期的语言检测与查询函数。

## 影响

回调刷新会保留正在进行的翻译；选中文字或语言组合变化仍会重新翻译。无需修改持久化、服务协议或操作会话归属。

## 验证

- Regression — 组件测试使用真实翻译 hook 挂起请求，刷新检测回调后完成首次响应。修复前可见结果断言失败，修复后通过；随后修改选中文字，也能显示新的翻译结果。
- Regression — `ActionTranslate.test.tsx`、`useTranslate.test.tsx` 与 `ActionWindow.test.tsx` 共 36 个测试通过，覆盖语言选择、结果显示、取消请求与操作会话行为。
- Regression — 本机真实 MP-127 流程以 31.4 秒通过，包含选区捕获、解释、翻译与复制断言。

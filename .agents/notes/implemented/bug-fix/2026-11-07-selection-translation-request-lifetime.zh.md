# Agent Note: 让划词翻译请求随输入变化

Status: implemented

[English](2026-11-07-selection-translation-request-lifetime.md) | 中文

## 问题

划词翻译的 effect 依赖一个回调，而语言检测与语言查询刷新时会改变该回调的引用。因此，即使选中文字没有变化，也可能取消首次请求并重新发起请求。在 MP-127 中，受控服务收到了两次相同请求，首次完成的响应却没有显示。

如果快捷模型比已保存的语言组合更晚加载，首次检测可能失败，并永久停留在备用目标语言。忽略回调引用刷新时，模型辅助检测仍须将模型就绪视为语义输入。无条件订阅模型变化也会导致无关快捷模型加载或切换时，取消离线 `franc` 翻译。

## 决策

选中文字、初始化状态或目标语言代码变化时自动发起翻译。`llm` 和 `auto` 检测还由快捷模型 ID 变化触发，`franc` 则忽略该值。通过 Effect Event 读取最新翻译回调，避免把回调引用变化作为请求触发条件。用户点击重新生成仍会发起新请求，新的操作窗口会话仍会重新挂载组件。

## 考虑过的替代方案

- 延长 E2E 等待时间无法恢复已取消的首次响应，也无法消除重复的服务请求。
- 删除依赖但保留闭包中的回调，可能使用过期的语言检测与查询函数。
- 完全移除快捷模型就绪依赖，会使模型辅助检测的延迟加载及目标语言纠正行为回退。

## 影响

回调刷新会保留正在进行的翻译；选中文字或语言组合变化仍会重新翻译。模型辅助检测中，快捷模型晚到时会重新计算目标语言；同一模型记录的刷新仍保留当前请求。离线检测在快捷模型加载或切换时保留当前翻译。无需修改持久化、服务协议或操作会话归属。

## 验证

- Regression — 组件测试使用真实翻译 hook 挂起请求，刷新检测回调后完成首次响应。修复前可见结果断言失败，修复后通过；随后修改选中文字，也能显示新的翻译结果。
- Regression — 较早的本机真实 MP-127 流程以 31.4 秒通过，包含选区捕获、解释、翻译与复制断言。

- Regression — 操作组件、语言检测 hook、翻译 hook 与操作窗口共 60 个测试通过。真实检测 hook 的回归用例在加入模型 ID 依赖前失败、修复后通过：模型晚到会将中文备用目标纠正为英文备选，无需点击重新生成。

- Regression — 离线检测用例在模式限定前失败：快捷模型加载后完成原请求，结果仍未显示且控件保持禁用。修复后原结果可见，且退出 streaming。最近一次完整 MP-127 运行观察到重复请求，但没有记录快捷模型过渡；其确切触发因素仍未被观测到。MP-127 在 `b4005546bf` 的七用例 Electron 集中复测中以 20.1 秒通过，所拥有运行资源清理成功。完整验收仍需单独完成。

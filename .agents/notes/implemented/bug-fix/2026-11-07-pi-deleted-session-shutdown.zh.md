# Agent Note: 删除会话后关闭 Pi 运行时

Status: implemented

[English](2026-11-07-pi-deleted-session-shutdown.md) | 中文

## 问题

Agent 导航 smoke 完成界面断言后无法关闭 Electron。运行时清理之前，会话已被删除或移入回收站。Pi 关闭流程发出用户停止操作，其中的权限查询要求会话仍处于活动状态；查询抛错后未执行运行时关闭，资源仍然存活。

## 决策

会话仍处于活动状态时，保留根任务和子任务的用户停止语义。仅在会话明确不存在时直接关闭运行时：shutdown 中止并排空原生根任务与子任务，不再查询已删除的权限记录。其他数据库错误仍会抛出。

## 考虑过的替代方案

- 跳过全部用户停止调用会改变重新打开后的子任务续接行为，现有测试捕获了该变化。
- 忽略所有中断错误会掩盖原生关闭失败和数据库故障。

## 影响

软删除和永久删除的会话均可释放存活的 Pi 运行时并完成工作区清理。现有运行时测试继续验证活动会话的续接行为。

## 验证

- 回归 — 真实 SQLite 的软删除和永久删除测试在修复前均报 Pi interrupt: native-error。
- 回归 — 40 项 PiRuntimeConnection 测试全部通过，包括活动子任务关闭和重新打开的契约。
- Electron — `69da843698` 的完整 smoke 运行中，Agent 导航用例通过界面断言并正常退出；所有测试拥有的运行目录与进程均已清理。

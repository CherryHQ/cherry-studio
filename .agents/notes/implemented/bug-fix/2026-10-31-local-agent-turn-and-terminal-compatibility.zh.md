# Agent Note: 本地 Agent 轮次结束与终端兼容

Status: implemented

[English](2026-10-31-local-agent-turn-and-terminal-compatibility.md) | 中文

## Problem

Claude 在 SDK 迭代器结束返回之前宣布轮次完成，导致立即进入的下一轮可能被上一轮发送函数结束。CodeBuddy 在 ACP `terminal/create` 中只传整段命令而未传参数数组；把整段内容当作可执行文件会出现 ENOENT，并丢失诊断信息。ACP 内部错误封装还会隐藏可操作的嵌套详情，失效的已保存模型也会作为非法选择发送给智能体。

## Decision

先关闭 Claude 迭代器和查询，再发布完成事件并允许下一轮进入。不使用定时延迟限制后续轮次。

终端参数数组保持字面执行。只有包含空白且未传参数数组的命令，在用户批准该完整命令后，且工作目录路径与执行环境均无法将整段内容解析为程序时，才通过 Shell 执行。这保留了含空格程序路径的直接启动方式。启动错误纳入终端有容量限制的输出。

保留 ACP 文本错误详情，不转发任意响应数据；对密钥脱敏并保留协议错误码。缺模型、缺密钥时补充本地化配置指引。非空模型目录中不存在已保存模型时，在请求切换前报错，不静默替换模型。OpenClaw 启动错误保留日志尾部，并优先呈现 stderr 而非启动 stdout。

在 POSIX 上，向进程组发信号遇到 `EPERM` 时，短暂等待自有子进程退出；仅确认退出后忽略错误。子进程仍运行时继续报告权限错误。

## Alternatives considered

- 延迟下一轮 Claude 请求：隐藏竞态，无法明确资源所有权。
- 所有终端请求都启用 Shell：改变字面参数语义和转义行为。
- 手动解析 Shell 语法：重复实现平台解析规则，并破坏合法命令。
- 从智能体文本猜测缺失的工具结果或失败：会伪造协议结果。

## Consequences

完整终端命令可以执行审批中已展示的 Shell 语法；这是对仅传命令请求的兼容，不改变参数数组执行方式。未知模型目录仍保持未知。上游智能体将模型失败返回为成功终态的问题，仍须由上游修复。

## Verification

- Regression — Claude 测试阻塞迭代器清理，验证完成事件等待清理后发出，并立即发送下一轮。
- Regression — ACP 子进程测试覆盖 Shell 命令、字面元字符、含空格程序路径、启动诊断、失效模型拒绝及嵌套错误脱敏。
- Regression — OpenClaw 测试将维护错误放在启动噪声后，验证错误仍能保留。

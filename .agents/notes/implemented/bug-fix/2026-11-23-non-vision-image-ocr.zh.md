# Agent Note: OCR 回退失败时继续发送非视觉模型的对话

Status: implemented

[English](2026-11-23-non-vision-image-ocr.md) | 中文

## 问题

非视觉模型的图片 OCR 回退返回空文本或失败时，附件路由会拒绝整个模型请求。路由也会重新对保留的历史图片执行 OCR，导致旧图片可能阻止后续纯文本消息发送给模型服务。Issue #24143 和 #24989 记录了这一故障。

## 决策

继续对最后一条用户消息中的应用内图片附件尝试 OCR。有识别文本时沿用附件预算。空结果或处理器失败时，向模型发送一条包含图片名称的说明。历史图片直接生成模型不支持图片的说明，跳过 OCR。取消仍向调用方传播。视觉模型仍接收原生图片。

## 考虑过的方案

- 跳过所有图片的 OCR 会丢失本轮提示中有用的识别文本。
- 重新识别历史图片会给无关的后续消息增加重复工作。

## 影响

不支持图片的模型会收到明确的限制说明，仍可回答提示中的其余内容。后续轮次不会自动识别历史图片中的文字。已存储的消息和文件保留原始附件。

## 验证

- Regression — 附件路由测试覆盖 OCR 空结果、失败、取消和成功，以及历史中带图片的纯文本后续消息。

# Agent Note: 从资料库移除缺失的翻译原件

Status: implemented

[English](2026-11-28-remove-missing-translation-originals.md) | 中文

## 问题

翻译历史仍持有可选的来源引用，导致用户无法从资料库移除已经缺失的 PDF 原件。

## 决定

用户显式移除资料库条目时，FileManager 直接检查原件路径。路径缺失且所有持久化引用均为翻译历史的来源引用时，删除外部文件条目会通过外键级联清除这些可选引用。引用注册表声明可选来源的例外。文件系统探测在全局路径锁之外运行，删除事务复核路径和受保护的引用，并保留翻译历史及其必需的译文。

## 考虑过的方案

要求用户删除翻译历史会丢掉有效记录，译文也会进入可清理范围。允许移除所有缺失的外部条目可能破坏依赖持久化引用的其他功能。

## 后果

历史记录保留原文件名，译文 PDF 仍可打开或导出。移除后，该历史记录无法打开原件或恢复并排预览。

## 验证

- Regression — `src/main/services/file/internal/entry/__tests__/lifecycle.test.ts`：移除缺失原件后，翻译历史和译文均保留。仍在磁盘上的原件以及另有持久化引用的缺失原件仍受保护。探测期间可以执行其他路径修改，而在此期间加入的引用会阻止删除。

# Agent Note：富文本编辑器加载时保留当前文本输入焦点

Status: implemented

[English](2026-11-07-rich-editor-autofocus.md) | 中文

## 问题

N-01 偶尔在输入笔记名称与按 Enter 之间丢失重命名输入框。延迟加载真实富文本编辑器模块后可复现：编辑器挂载时抢走重命名输入框的焦点，触发失焦保存并卸载输入框。

## 决策

共享富文本编辑器在创建或恢复可编辑状态后自动聚焦前，检查其他文本输入框或可编辑区域是否持有焦点。保留正在输入的控件；没有其他文本编辑控件获得焦点时，继续正常自动聚焦。

## 考虑过的替代方案

在重命名前等待笔记编辑器加载完成会掩盖真实交互竞争。完全取消自动聚焦则会降低新建笔记的体验。

## 影响

编辑器加载较慢时不再打断正在进行的重命名或其他文本输入。用户显式触发的聚焦操作保持不变。

## 验证

- 回归 — 两个使用真实编辑器的组件用例在修复前失败、修复后通过，覆盖挂载和可编辑状态变化。相关 31 项富文本编辑器测试全部通过。
- 桌面 — 相同的延迟模块加载 Electron 复现中，重命名输入框从被移除变为保持可见且持有焦点。完整回归与托管平台验收继续在 PR 中跟踪。

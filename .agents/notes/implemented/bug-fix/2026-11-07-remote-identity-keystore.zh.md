# Agent Note: 读取已有明文设备身份时先于钥匙串检查

Status: implemented

[English](2026-11-07-remote-identity-keystore.md) | 中文

## 问题

MP-141 已提供有效且属于测试配置的明文设备身份，但启用网络访问时 Electron 主线程阻塞在 SecItemAdd。loadDesktopIdentity 在发现已有身份不需要钥匙串操作之前，就检查了 safeStorage 的可用性。

## 决策

先读取已有身份文件。仅在解密已有加密身份，或为新建身份选择存储方式时检查钥匙串。

## 考虑过的替代方案

修改用户钥匙串或全局禁用加密会超出修复范围。生成替代身份会使已配对设备失效。

## 影响

已有明文身份保持不变，并避免无关的交互式钥匙串访问。安全存储不可用时，加密身份仍会拒绝加载；新建身份继续遵循现有加密策略。

## 验证

- Regression — `deviceIdentity.test.ts` 在重新加载已有明文身份时模拟需要交互而失败的钥匙串检查。修复后身份保持不变，该用例在修复前失败。加密创建及钥匙串不可用的分支仍有覆盖。

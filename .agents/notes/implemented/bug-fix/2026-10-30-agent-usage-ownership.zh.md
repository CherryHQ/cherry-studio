# Agent Note: 原生智能体用量归属

Status: implemented

[English](2026-10-30-agent-usage-ownership.md) | 中文

## 问题

提供商请求完成与原生助手消息发布是相互独立的。若在响应 ID 找到消息归属前将已完成的调用记录保留在内存中，进程退出会丢失用量。若把所有调用都归到当前根会话回复，则会错误归属延迟的子任务续写和原生辅助请求。

## 决策

调用完成后立即持久化，同时保留请求时的会话、来源、价格和凭据快照。原生响应 ID 后续可补充消息关联，并将会话归属细化到子任务归档。同一事务也重建消息用量投影。此操作不能修改金额、token、价格、凭据或来源，不能新增一笔费用，也不能替换已有的消息归属。

没有原生助手消息的调用保留会话归属。桌面端发起的 Pi 摘要和验证请求在经过网关前捕获发起方归属；子任务摘要携带子任务会话，不借用父会话消息。捕获令牌仅限内部使用、绑定会话，并在请求结束后释放。追加迁移保留现有记录，其未知的会话归属保持为空。

## 考虑过的替代方案

- 等待原生关联后再写入记录：不采用，因为进程丢失会导致已完成的提供商用量被丢弃。
- 将辅助用量归到最后一条可见消息：不采用，因为先后顺序不能证明归属。
- 归属到达时重新计算或插入调用：不采用，因为延迟关联不能破坏请求时价格和单次计数。

## 后果

金额和请求时归因保持不可变；原生消息关联仅允许有限补充。会话总量可以包含消息总量中没有的辅助调用。历史记录不按猜测回填。此机制仍然只是尽力记录可观测用量的分析系统，不是提供商账单对账系统。

## 验证

- Regression — `AgentSessionUsageAttribution.test.ts` 覆盖立即持久化、两种关联顺序、子任务消息投影、仅按会话查询、关闭、延迟完成和重复绑定不产生额外费用。
- Regression — `ApiGatewayService.test.ts` 覆盖延迟归属、子任务摘要归属、跨会话拒绝、凭据限制和捕获释放。
- Regression — 两种 Pi 桌面连接测试将首次输出和续写的原生子任务响应 ID 关联到子任务自己的产品消息。
- Regression — `agentUsageOwnershipMigration.test.ts` 升级已有数据的生产迁移链，并保留历史费用字段。

# Agent Note：知识库笔记导入随目录变更刷新

Status: implemented

[English](2026-11-07-knowledge-note-tree-refresh.md) | 中文

## 问题

MP-63 在创建笔记前打开导入选择器，创建后再次打开仍可能显示空状态。目录镜像原地修改同一个根对象，而选择器只按根对象引用和路径缓存投影；重命名和删除也可能保留旧列表。

## 决策

在文件列表投影的 memo 依赖中加入目录订阅版本，与其他目录树消费者一致。选择和导入逻辑保持不变。

## 考虑过的替代方案

- 在 E2E 中重启应用会掩盖选择器过期问题。
- 每次打开对话框时重建目录订阅会增加文件系统工作，并丢弃已有的实时镜像。

## 后果

目录变更后，新增、重命名和删除会反映到可选笔记列表。无需修改数据库或笔记文件格式。

## 验证

- Regression — 在同一个根对象上依次创建、重命名和删除文件，检查选择器中的可选文件；新增测试在修复前失败。
- Regression — 修复后 AddKnowledgeItemDialog 的 35 项测试全部通过。Electron MP-63 的实时目录变更流程复测通过。

# AGENTS.md — Implemented Agent Notes

Implemented notes describe shipped reality in the present tense. Keep paths, symbols, defaults, ownership, failure behavior, and verification current in the same change that alters them.

An Agent Note preserves rationale; it is not authority over a better or corrected implementation. Factual realization may be updated in place. Reversing the decision or rationale requires a new note and cross-link instead of rewriting history.

When a final implementation layer completes a proposed Spec, move both language files and the sidecar together, rewrite `Proposal` as `Decision`, replace acceptance/risk planning with `Consequences`, and map each `AC` to actual evidence under `Verification`.

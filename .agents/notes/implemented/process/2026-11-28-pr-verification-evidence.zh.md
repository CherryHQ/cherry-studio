# Agent Note: 要求 UI 修复和性能优化提供证据

Status: implemented

[English](2026-11-28-pr-verification-evidence.md) | 中文

## 问题

审阅者需要看到 UI 修复前后的表现，并根据测量数据评估性能改善。仅列出通过的检查无法证明这两种对比结果。

## 决策

[PR 模板](../../../../.github/pull_request_template.md)在 `Verification` 小节定义这两项要求。[创建技能](../../../skills/gh-create-pr/SKILL.md)在 PR 进入待审状态前收集适用的证据。明确要求创建草稿时，可以列出待补的证据。[审阅技能](../../../skills/gh-pr-review/references/pr-review.md)根据审阅范围核对证据，并在 PR 层面报告缺口。

## 考虑过的替代方案

- 由审阅者自行决定所需证据，会造成要求不一致，也会把索取证据的时点推迟到审阅阶段。
- 增加 CI 门禁需要另行判断图片或视频是否展示了受影响的行为，以及测量是否支持所声称的改善。

## 结果

同时修复用户可见的 UI 行为和优化性能时，作者需要提供两类对比。审阅者可以在继续代码审阅的同时报告证据缺口。

## 验证

- Regression — 定向检查 PR 模板、创建和审阅流程，覆盖仅修复 UI、仅优化性能、两种要求均适用以及证据缺失的情况。

# Agent Note: 在 Computer Use 工具调用旁显示目标应用

Status: implemented

[English](2026-11-10-computer-use-app-icons.md) | 中文

## 问题

Computer Use MCP 调用能标识工具，却未显示实际操作的应用。通过前台窗口推断身份会错误标注后台操作。

## 决策

读取生产端写入 MCP `_meta` 的 `com.cherrystudio.computer-use/app` 条目。生产端解析实际目标，提供名称、可选 bundle identifier 和可选 64×64 PNG。显示前校验名称、PNG MIME 类型和不超过 65,536 个字符的 base64 数据，使用共享 Avatar 组件展示。保留工具内容；图标缺失或加载失败时使用带应用名称的回退图标。

Claude Code 仅在消息中恰有一个工具结果时保留消息级 MCP 元数据。实时观察和原生历史恢复采用同一归属规则。桌面端展示装饰器独立转换截图块，不将其与应用图标混合。

固定版本的 Pi SDK 补丁将 MCP `_meta` 保存在仅供宿主使用的工具 details 中，继续将它排除在代码模式的结构化结果和模型内容之外。Pi 桌面端装饰器读取这些 details；原生执行、发现和销毁仍由 SDK 管理。

## 考虑过的替代方案

- 从工具名称或前台状态推断身份可能显示错误应用。
- 将图标数据放入文本或截图内容会向模型暴露展示数据。
- 将消息级元数据分配给多个结果会错误标识它们的目标。

## 影响

没有有效应用元数据的工具维持原有界面。macOS 生产端必须提供新元数据；本次不升级内置运行时、不迁移数据库，也不增加 Windows/Linux 生产端支持。已存储且不含元数据的结果无法追溯补充图标。

## 验证

- AC1 — 共享 schema 和渲染器测试覆盖有效目标、格式错误或超限数据、目标切换及回退行为。
- AC2 — Claude 投影测试覆盖实时及历史元数据归属，并拒绝有歧义的结果批次；桌面端测试验证截图内容得到保留。
- AC3 — 原生 Pi SDK、MCP 传输与 QuickJS 测试验证应用图标到达展示层，同时不进入代码模式结果或模型上下文。
- Electron 和打包运行时的视觉验证仍待执行。

# Agent Note: ACP 会话累计费用

Status: implemented

[English](2026-10-22-acp-session-cost.md) | 中文

## 问题

ACP 上报原生会话的累计费用，而 Cherry 的用量账本记录单次服务商调用。如果把每次 ACP 更新都加入账本，同一笔费用会被重复计算。上报币种也可能超出账本目前支持的范围。

## 决策

在现有 `agent_session_message.data.localSessionCost` JSON 中保存有类型、由主进程写入的快照：原生会话 ID、上报时间，以及原始金额／币种或费用未知标记。更新直接替换金额，包括下调修正和明确的零费用。缺失或无效上报保留最后已知值。原生会话变更时替换为未知标记；复制分支历史时移除此快照。

共享缓存传递实时状态。只读 DataApi 资源从持久化历史恢复最新快照，无需启动 CLI。用量详情将会话费用与上下文占用、单次调用计费分开展示，并保留上报币种。极小的正数费用显示金额下限，避免被显示为免费。

## 考虑过的替代方案

- 将累计金额写入 `ai_usage_record`：违反单次调用的归属语义，并重复计算费用。
- 推导调用费用差值：原生历史、金额下调、币种变化和缺失上报使结果不可靠。
- 增加表或列：现有消息 JSON 可以保存这一可选快照，无需迁移。

## 影响

无需修改数据库结构或换算币种。现有消息费用投影与统计保留原有语义。渲染进程的消息写入不能伪造或清空快照。尚无任何消息时，费用仅保留在运行时；首次助手消息持久化时保存。此功能展示 Agent 提供的信息，不将其视为账单。

## 验证

- Regression — 协议子进程测试覆盖创建／恢复时上报、重复／下调／零金额、扩展元数据、缺失／无效费用及其他会话。使用生产迁移的 SQLite 测试覆盖替换、消息写入保护、分支隔离，以及与调用记录的分离。
- Regression — 渲染进程测试覆盖历史恢复、读模型通知、实时更新、会话切换、未知／零金额和极小正数金额。
- Electron — 使用可控 ACP 进程验证费用显示、页面重载、连接释放／恢复及应用重启。这是无模型推理的协议与界面验收，并非真实服务商账单验证。

# Agent Note: Fortytwo 内置服务商

Status: implemented

[English](2026-11-05-fortytwo-built-in-provider.md) | 中文

## Problem

Fortytwo 用户此前需要自定义 OpenAI 兼容连接。内置服务商需要在普通聊天和 Pi Agent 请求中提供正确的模型能力、价格和来源标识，同时不改变共享标准模型或无关服务商。

## Decision

全球版包含 Fortytwo 预设，通过 https://api.fortytwo.network/v1 使用 OpenAI 兼容 Chat Completions。初始模型将 qwen/qwen3.8-27b 映射到已有标准模型，并配置服务商独有的限制和价格。此预设范围不表示 Fortytwo 不提供其他模型。解析后的元数据支持文本和图片输入、工具、严格结构化输出，以及 `none`、`minimal`、`low`、`medium`、`high`、`xhigh` 和 `max` 七种 reasoning_effort 值。保留显式 `none` 和 `medium`；未设置时省略该参数，使 API 默认值仍为 `medium`。

仅源码的 `--provider fortytwo` 生成器模式重新生成显式服务商记录，不获取远程补充数据，也不改变标准模型或其他服务商记录。普通聊天和原生 Pi 使用已有的集中服务商执行及内部网关路径，包括不含凭据的内置应用请求头策略。不恢复已删除的 Pi 模型注入架构。请求头覆盖优先级、自定义服务商隐私、凭据、网关与会话规则及字面请求头转义保留原有契约。交付内容包含官方浅色和深色图标、当前全部 17 种语言标签及生成的消费端。不增加新运行时、存储结构、通用认证改造或后端日志变更，也不声明中国版可用。

服务商元数据记录上下文窗口 262144、最大输出 235929 个 token。标准每百万 token 价格为输入 USD0.425、缓存输入 USD0.085、输出 USD2.55，并显式设置零缓存写入费率。服务商独有的零费率取代原型中的未知/null 处理，而非继承标准模型费率；其他服务商的价格不变。来源为[模型契约](https://docs.fortytwo.network/docs/models)和[价格](https://docs.fortytwo.network/docs/pricing)。实施变更期间及发布前需要重新核实这些外部事实；临时账单促销不替代目录标准价格。

## Alternatives considered

自定义连接可以使用，但不提供易于发现的内置预设。完整目录刷新会引入无关远程数据漂移。仅针对 Fortytwo 添加 Pi 请求头分支会重复已有的内置和自定义服务商策略，而恢复旧模型注入文件会重新引入已删除的架构。修改共享标准模型会将本服务商的价格或能力错误归属给其他服务商。因此实现保留已有共享所有者，仅添加服务商特定数据和受限的仅源码生成模式。

后续本地验证候选版本基于上游 `71d95e86b4a787704cfce976781306dcee6f5c03`，加上已评审的服务商变更、UI 引用及目录包 changeset，通过十个文件中的 302 个主进程过滤测试，包括 29 个 Doctor 用例。这些本地结果与早先的 273 个测试及托管 CI 分别记录。缺失的发布元数据通过 `@cherrystudio/provider-registry` 的 minor changeset 修复；配置中忽略的 `@cherrystudio/ui` 刻意不列入。Doctor 流式测试响应已由上游提交 `195e7f6bf7bdedf5d73ac85ca3f28a39895f295d` 修复；该修复通过当前基线继承，而非复制进服务商变更。

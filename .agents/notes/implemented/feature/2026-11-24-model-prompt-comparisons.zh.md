# Agent Note: 按模型对比系统提示词

Status: implemented

[English](2026-11-24-model-prompt-comparisons.md) | 中文

## Problem

多模型回合原先对所有回复使用同一个助手提示词，无法对比模型与提示词的组合，也无法在助手发生变化后复现组合。

## Decision

普通聊天在选择多个模型时显示可展开的模型提示词对比区。每个覆盖值按完整的供应商与模型 ID 绑定，而不是按列表位置绑定。未勾选时使用当前助手提示词，勾选但留空表示有意使用空的用户系统提示词。

Main 在创建消息前检查重复 ID 和未选中的模型 ID。对比回合把所有选中模型的提示词（包括继承值）保存到回复的回合参数中，各分支只读取自己的条目。没有覆盖值的普通请求继续使用现有助手查询，之后的新回合不会隐式继承上次对比。

覆盖值只替换用户编写的助手提示词，不移除引用、MCP 或其他运行时说明。复用现有的提示词变量解析器；Anthropic 缓存按实际覆盖值检查易变变量。

排队草稿、草稿缓存、重新生成、重试、工具批准续接、编辑后重发都会保留绑定。历史回复头可按模型查看保存的提示词。历史编辑期间不显示覆盖编辑区，重发保留原回合配置。临时聊天和 Agent 会话在写入前拒绝此普通聊天功能，而不是静默忽略。忙碌时的显式插话拒绝提示词对比，输入框队列可等到空闲再发送。

## Alternatives considered

- 提及助手会扩大到助手与 Agent 统一的范围。
- 把说明放入用户文本会丢失系统角色语义。
- 重新生成时再读取继承提示词会让助手修改影响原对比。
- 替换完整系统字符串会删除运行时与工具说明。

## Consequences

不新增数据库表、偏好或网络服务。提示词保存在本地回复记录中，并作为正常系统说明发送给所选模型的供应商。简体与繁体中文提供中文标签，其他语言的新标签使用英文。现有每个模型只选择一次的限制保持不变，不新增同模型重复执行。

## Verification

- 真实数据库回归测试覆盖模型独立分发、继承提示词快照、助手后续修改、重新生成、写入前拒绝非法绑定和后续普通回合无泄漏。
- 提示词组装测试覆盖变量、空覆盖值、继承值及 MCP 说明保留。
- 渲染层回归覆盖排序后字段独立、历史查看、重试转发和多模型编辑重发绑定。
- 浏览器检查使用实际编辑组件和模型样例，验证英文浅色宽屏及中文深色窄屏；未运行原生 Electron 或付费供应商请求。

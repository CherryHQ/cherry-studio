# Agent Note: Fortytwo built-in provider

Status: implemented

English | [中文](2026-11-05-fortytwo-built-in-provider.zh.md)

## Problem

Fortytwo users previously needed a custom OpenAI-compatible connection. A bundled provider needs correct capabilities, pricing and attribution through ordinary chat and Pi Agent requests, without changing the shared canonical model or unrelated providers.

## Decision

The global edition includes a Fortytwo preset using OpenAI-compatible Chat Completions at https://api.fortytwo.network/v1. Its initial model maps qwen/qwen3.8-27b to the existing canonical model with provider-owned limits and rates. This preset scope does not imply that Fortytwo serves no other models. Resolved metadata supports text/image input, tools, strict structured output and reasoning_effort values `none`, `minimal`, `low`, `medium`, `high`, `xhigh` and `max`. Explicit `none` and `medium` are preserved; an unset effort is omitted so the API default remains `medium`.

The source-only `--provider fortytwo` generator mode regenerates the explicit provider without remote enrichment or changes to canonical and sibling-provider records. Ordinary chat and native Pi use the existing central provider execution and internal gateway routes, including the credential-free built-in app-header policy. The removed Pi model-injection architecture is not restored. Caller-header precedence, custom-provider privacy, credentials, gateway/session policies and literal-header escaping retain their contracts. Official light/dark artwork, all 17 current locale labels and their generated consumers are included. No new runtime, storage schema, general authentication redesign, backend logging change or China-edition availability claim is introduced.

Provider metadata records a context window of 262144 and maximum output of 235929 tokens. Standard per-million-token rates are USD0.425 input, USD0.085 cached input and USD2.55 output, with an explicit zero cache-write rate. The provider-owned zero replaces the prototype's unknown/null treatment rather than inheriting a canonical rate; other providers' rates remain unchanged. Sources are the [model contract](https://docs.fortytwo.network/docs/models) and [pricing](https://docs.fortytwo.network/docs/pricing). Recheck these externally owned facts during implementation changes and before publication; temporary billing promotions do not replace standard catalogue prices.

## Alternatives considered

Custom connections work but do not provide a discoverable bundled preset. A full catalogue refresh introduces unrelated remote drift. A Fortytwo-only Pi header branch duplicates the existing built-in/custom policy, while restoring obsolete model-injection files revives a removed architecture. Changing the shared canonical model attributes this provider's tariffs or capabilities to other providers. The implementation instead preserves the existing shared owners and adds only provider-specific data and a bounded source-only generation mode.

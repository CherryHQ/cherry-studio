# Agent Note: 终端目录历史

Status: implemented

[English](2026-10-31-terminal-directory-history.md) | 中文

## 问题

终端仅记住上次的工作目录，在多个项目之间切换时需要反复选择文件夹。

## 决策

本地智能体终端弹窗在 `feature.code_cli.configs` 中，将每个工具的 `directoryHistory` 与 `directory` 一起保存。启动时将所选目录移到最前，避免重复记录。旧配置没有历史字段时，以已保存的目录作为初始历史项；显式保存的空历史保持为空。

输入框的下拉列表可以选择目录或逐项移除历史记录。移除操作立即保存，不改变当前选择，也不操作磁盘文件。取消弹窗不会撤销用户明确执行的历史移除操作。目录和终端选择仍在启动时保存。

## 考虑过的替代方案

- 全局历史会混合不同智能体的项目，因此沿用现有的按工具保存设置的归属。
- 单独的偏好设置或数据库表会为终端设置已经拥有的列表增加存储机制。

## 影响

无需数据库迁移或新增偏好设置键。再次使用已移除的目录启动时，该目录会重新加入历史。

## 验证

- Regression — `LocalAgentTerminalDialog.test.tsx`：选择历史目录后在该目录启动，将其移到最前且不重复记录。
- Regression — `LocalAgentTerminalDialog.test.tsx`：删除旧配置的历史记录后，重新打开仍保持删除结果，不改变当前目录或其他工具的设置。
- Regression — Electron：选择并移除包含空格的中文路径，重新打开弹窗，并检查明暗主题；临时测试设置已恢复。

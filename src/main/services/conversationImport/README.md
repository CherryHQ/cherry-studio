# 本地会话历史导入

- `ConversationImportService.ts` 管理窗口归属、只读预览、取消和逐会话提交。
- `claudeCode.ts` 解析 Claude Code 2.1 系列的 UUID／父链 JSONL 布局。当前夹具版本为 2.1.284。未知布局须报告，不代表已验证全部发布版本。
- `files.ts` 限制输入体积。预览快照只留在内存。
- 跨进程契约位于 `src/shared/ipc/schemas/conversationImport.ts`。来源身份由数据服务写入，界面不能提交数据库记录。
- Pi 历史初始化位于 `src/main/ai/runtime/pi/importedSessionHistory.ts`。失败后保留可读历史，禁止空上下文续聊。

首版只支持 Pi 目标。保留原时间；时间倒退和未来时间在预览及提交前拒绝。
来源文件不写入。每个会话单独使用同步事务。复制清除会话级导入身份，备份恢复保留身份。

测试位于 `__tests__/`。数据库用例使用生产迁移和真实 Pi 历史；模型输入用本地网关夹具捕获。
产品方案见 [本地历史导入方案](../../../../.agents/notes/proposed/feature/2026-11-02-local-agent-history-import.md)。
打开导入弹窗后自动扫描来源默认目录，支持环境变量覆盖；找不到时可手动指定。Claude 候选与预览优先显示来源标题，否则显示第一条非命令用户正文。无法确定是否有用户任务时，仍保留候选；没有可用标题时用来源名称和日期。Claude 命令标签、ANSI 控制码和工具 JSON 转为可读历史文本。旧导入记录通过消息读模型显示相同格式，不覆盖持久历史。
导入窗口只保留“导入选中对话”主按钮。点击后自动校验，再提交同一快照；逐条跳过阻塞项并保存有效会话。界面保留成功结果，重试时只提交未成功的选择。全选作用于当前搜索结果中显示的最多 100 项，保留其他已选项且批次仍不超过 100。标题单行截断，完整文字可悬浮查看。
错误在独立弹窗中按失败会话分组，合并重复原因。仅可修复的问题提供分支、目录和重试操作。含不可恢复错误的会话只显示失败原因，移出待重试选择，也不显示无效的目录或分支建议。关闭错误弹窗保留选择。外部应用与本地应用使用两个设置卡片。
工具内容以静态文本持久保存。读模型将工具标记转为已完成的展示工具项，复用“已处理”折叠区；工具项不请求审批或执行历史工具，也不改变续聊历史。连续的历史过程记录在显示层共用一个“已处理”，遇到正文或用户消息即断开。保留原消息 ID，多选和截图仍按原记录处理。旧记录同样适用。
导入消息的名称和头像使用当前智能体，模型信息保留来源快照。完整历史加载后，以首条真实用户消息为显示起点，隐藏之前的项目指令、环境信息等前置信息。分页尚未到开头时不截断。原始消息及续聊上下文保留；图片导出使用相同显示规则。
去重只查询未归档会话，在每个同步写事务中复查。归档副本保留来源信息，不阻止新导入。查询索引不设唯一约束，恢复旧副本时允许与新副本并存；重复导入仍命中已有活动会话。custom SQL 在启动及备份恢复时替换旧唯一索引。

发现阶段排除已确认的非对话会话，单列原因和数量。Claude 仅在已核对的 2.1.207、2.1.211、2.1.284 布局中，完整父链和全部分支均无真实用户任务时排除。图片、文档、短提问和混有任务的设置会话保留；自定义命令、未知版本、未知记录及损坏历史保留待校验。选中纯设置分支但另有任务分支时，要求选择有效分支。预览复查后被排除的记录返回 filtered，不计入成功或失败，不提供强制导入或重试。提交仍核对指纹；排除不写库、不初始化 Pi，不改来源文件或已有会话。

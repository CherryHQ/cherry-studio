# Reply illustrations / 回答插图

This glossary names the concepts used when generated illustrations accompany an assistant's reply.
本术语表定义助手回答中生成插图所涉及的概念。

## Language / 术语

**Reply illustration / 回答插图**:
A generated image that illustrates a particular passage of an assistant's reply.
与助手回答中某一段内容对应、用于帮助表达或理解的生成图片。
_Avoid_: painting / 绘画作品, MCP image / MCP 图片

**Illustration intent / 插图意图**:
The description of an illustration that the assistant includes in its reply.
助手在回答中给出的、描述所需插图的内容。

**Illustration placeholder / 插图占位**:
The place reserved for an illustration while its result is unavailable.
插图结果尚未就绪时，在回答中为其保留的位置。
